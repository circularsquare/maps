## 2. Causes

Tiered: **measured**, **mechanism known but not counted**, **guess**.

### A. Truncated gzip written by Safari 16.4-16.5 (measured; origin likely)

- How: WebKit's CompressionStream stopped early when the flush output filled its buffer (WebKit 254021, fixed in
  Safari 16.6). The first bad file is exactly a 10-byte gzip header plus 16,384 bytes. That Safari wrote it is the
  11-15 note's inference; nothing ties the third game (rev 37) to Safari.
- Versions: game up to v0.3.4.
- Fixes, all shipped: v0.3.5 (bfe58c54, 11-15) bundled pako with a byte-for-byte round trip before any write; the
  server's full check (shonei-server 4623fde, deployed 11-18); the game checks before upload and keeps a good copy
  (7cd2f5ac, T-3395 stage 2). **Stage 2 is live**: it is an ancestor of the v0.4.0 publish commit, v0.4.0's changelog
  has "preserve the last undamaged copy of a corrupted save", and the live bundle (index-BpG_b-IG.js, clock.worker-DXx86OMH.js)
  carries its strings and the `:good` backup key. T-3395's Context ("ships with the next publish") was out of date and
  is corrected.
- Reach: 3 games in 2 accounts in the cloud; local copies unknown. Safari 16.4-16.5 is a tiny share now.

### B. A saved game that fails to load drops the player into a new empty game (mechanism known; not counted)

- How: `clock.worker.ts` start (around line 4022): if loading the stored game throws inside the worker (damaged, a
  Rust panic, or an allocation that fails as an error), the worker keeps the slot untouched, copies it under
  `unreadable-<at>:<slot>`, starts a fresh game in a new slot ("Game N") and sends `loaded` with the error. The page
  (`clockClient.ts` "loaded", around line 1242) shows the error as a notice and carries on with the new game: an
  empty playable world. The old game is still on the start menu, but the player is standing in an empty world, which
  reads as "my save is gone". A crash of the whole worker or page is different: it ends on the startup failure screen
  (`loadFailed`), as 1795097335-fa20c413 did, and puts nobody in an empty game.
- Versions: all. T-3478 (11-16) made a failing New game end on the menu, not a failing load of a saved game.
  Anita's words then: "if we fail, we should end up on the menu".
- Fix: none yet. Filed **T-3773**.
- Reach: unknown. The 11-15 Discord report of an empty January 27 world fits it; no inbox report shows it for certain.

### C. Browser storage cleared, for players with no account (mechanism known; not counted)

- How (T-3397 rows 5 and 6, sourced): Safari deletes a site's storage after 7 days of Safari use without a visit;
  private windows; clearing history; full disks (it happened to Anita, T-1214); a Home Screen web app on iOS keeps its
  own storage apart from Safari, as does another browser or device.
- Versions: all. Code can't prevent it. The game asks `navigator.storage.persist()` at the first save and shows "Saved
  only in this browser" with a tip to sign in or download.
- Reach: roughly 70% of daily players are not signed in (11-18: 4,533 signed-in accounts against 14,707 browsers; one
  account can play in several browsers). Potentially the biggest; no report names it. The Twitter player may be one.

### D. The account copy stops updating, so another device shows an old game (mechanism known; not counted)

- **Save over 4 MB**: `cloud.ts` never sends a save over 4 MB (the server's cap). T-3757 measured a player's save at
  3.99 MB, grown by per-day money ledgers (99 MB of header after 57 game years). Its fix (305b446c, folds old days into
  months: 3.99 -> 0.72 MB) is on master, **not shipped**; v0.4.3 carries it. T-3771 trims further.
- **A valid save refused as damaged**: the server's check reads every block the game writes, and each save level the
  game adds needs a server change. a46c2e9 was one valid case read as corrupt (caught before deploy). A refusal answers
  422; v0.4.0+ then keeps the copy local and does not resend the same bytes, so the account sits on its last good copy.
  Whether any valid save has been refused is in the quarantine records' reasons and levels: box only.
- **A newer save level than the server knows**: stored "unverified", never refused; the pinned copy stays on the
  older save until the server learns the level (T-3498). Levels 20-27 came in three days; the server was brought up to
  26 on 11-19, master is at 27.
- Reach: box only (the 3 MB+ bin and the quarantine in section 5).

### E. Fixed (shipped or landed)

- One unreadable record hid every save in the browser (T-3610): v0.4.1.
- A manual save overwritten by another tab's autosave (T-3611): v0.4.2.
- Tram and single-track saves broken by v0.4.0's rule change (T-3647): v0.4.2.
- Stop edits lost on large saves (T-3731, df82464f): landed after the v0.4.2 publish, ships in v0.4.3.

### F. Guesses, not checked

- A power cut or OS crash can roll back the last autosaves (IndexedDB's relaxed durability, T-3397 row 3).
- Deleting a game's card deletes every version on every device, for good. Accidental deletes would look like loss;
  the box's tombstones per day would show a jump (section 5).

## Appendix: save_health.py (copied from the file)

```python
"""T-3772: read-only summary of cloud save health on the account server. Prints ids and counts only.

Run from Anita's machine, on her yes (it reads, never writes):
    Get-Content -Raw save_health.py | ssh root@5.161.112.237 "python3 - <words>"
Optional words look up logins and names: 5 letters or more inside them, shorter ones as the whole login or name
(prints matching account ids and the matched login, then that account games: ids, revs, sizes, check, pin; never game names).
"""
import glob
import json
import os
import sys
import time
from collections import Counter

TW = os.environ.get("TW_DIR", "/opt/shonei/trainworld")
NORI = os.environ.get("NORI_FILE", "/opt/shonei/noritetsu/accounts.json")
NOW = time.time()
SINCE = NOW - 14 * 86400


def load(p):
    try:
        with open(p, encoding="utf-8") as f:
            return json.load(f)
    except Exception as e:  # noqa: BLE001
        return {"_error": str(e)}


def day(t):
    return time.strftime("%Y-%m-%d", time.gmtime(t))


# 1. Scan reports
print("== scan reports")
names = sorted(n for n in os.listdir(f"{TW}/scans") if n.endswith(".json") and n != "state.json") \
    if os.path.isdir(f"{TW}/scans") else []
print("reports:", names)
for n in names[-3:]:
    r = load(f"{TW}/scans/{n}")
    print(n, json.dumps({k: r.get(k) for k in ("checkV", "pass", "stopped", "passDone", "newDamage", "run",
                                                  "passSoFar")}))
    for k in ("corrupt", "missing", "unreadableIndexes", "noIntact", "unresolved", "races"):
        if r.get(k):
            print("  ", k, json.dumps(r[k])[:3000])
st = load(f"{TW}/scans/state.json")
print("state:", json.dumps({k: st.get(k) for k in ("pass", "cursor", "lastAt", "totals")}),
      "found", len(st.get("found") or {}), "known", len(st.get("known") or {}), "alerted", len(st.get("alerted") or {}))

# 2. Quarantine records (refused uploads and scan copies)
print("\n== quarantine")
qs = []
for p in glob.glob(f"{TW}/games/*/quarantine/*.json"):
    r = load(p)
    v = r.get("verdict") or {}
    qs.append((r.get("at", 0), r.get("account"), r.get("game"), r.get("foundBy") or "upload", r.get("rev", 0),
               r.get("accountRev"), r.get("bytes"), v.get("status"), v.get("level"), v.get("track"),
               (v.get("reason") or "")[:100]))
for q in sorted(qs):
    print(day(q[0]), *q[1:])
print("records:", len(qs), "by status:", dict(Counter(q[7] for q in qs)), "by foundBy:", dict(Counter(q[3] for q in qs)),
      "accounts:", len({q[1] for q in qs}), "games:", len({(q[1], q[2]) for q in qs}))
print("by reason:", dict(Counter((q[7], q[10][:50]) for q in qs)))
print("by level:", dict(Counter(q[8] for q in qs)), "by day:", dict(sorted(Counter(day(q[0]) for q in qs).items())))

# 3. Every account's games: checks, pins, sizes, deletions
print("\n== games")
checks, sizes, tomb_days, no_pin, big, saved_recent = Counter(), Counter(), Counter(), 0, [], 0
games = accts = 0
for idx in glob.glob(f"{TW}/games/*/index.json"):
    acct = os.path.basename(os.path.dirname(idx))
    ix = load(idx)
    if "_error" in ix:
        print("unreadable index", acct, ix["_error"][:100])
        continue
    accts += 1
    for gid, m in (ix.get("games") or {}).items():
        games += 1
        checks[m.get("check") or "(none)"] += 1
        b = m.get("saveBytes", 0)
        sizes["<1MB" if b < 1 << 20 else "1-2MB" if b < 2 << 20 else "2-3MB" if b < 3 << 20 else "3-4MB+"] += 1
        if b >= 3 << 20:
            big.append((acct, gid, m.get("rev"), b, day(m.get("savedAt", 0))))
        if not m.get("pinned"):
            no_pin += 1
        if m.get("savedAt", 0) >= SINCE:
            saved_recent += 1
    for gid, at in (ix.get("tombstones") or {}).items():
        if at >= SINCE:
            tomb_days[day(at)] += 1
print("accounts", accts, "games", games, "saved in 14 days", saved_recent)
print("current rev check:", dict(checks))
print("games with no pin:", no_pin)
print("save sizes:", dict(sizes))
print("3 MB and over (upload cap 4 MB):", big)
print("games deleted per day (tombstones, 14 days):", dict(sorted(tomb_days.items())))

# 4. Optional login / name lookup: a word of 5 letters or more matches inside a login or name, a shorter one only
# the whole login or name; at most 10 accounts are printed in full
words = [w.lower() for w in sys.argv[1:]]


def matches(s):
    s = (s or "").lower()
    return any((w in s) if len(w) >= 5 else (s == w) for w in words)


if words:
    print("\n== lookup", words)
    hits = {}
    f = load(NORI)
    for a in f.get("accounts") or []:
        for login in a.get("logins") or []:
            if login.startswith("pw:") and matches(login[3:]):
                hits.setdefault(a.get("id"), []).append("login " + login)
        if a.get("boardName") and matches(a["boardName"]):
            hits.setdefault(a.get("id"), []).append("noritetsu board name " + a["boardName"])
    pl = load(f"{TW}/players.json")
    prof = pl.get("players", pl) if isinstance(pl, dict) else {}
    for aid, p in (prof.items() if isinstance(prof, dict) else []):
        if isinstance(p, dict) and matches(p.get("name")):
            hits.setdefault(aid, []).append("trainworld name " + p["name"])
    print("accounts matched:", len(hits))
    for aid in sorted(h for h in hits if h)[:10]:
        print(aid, hits[aid])
        ix = load(f"{TW}/games/{aid}/index.json")
        for gid, m in (ix.get("games") or {}).items():
            print(" ", aid, gid, "rev", m.get("rev"), "saved", day(m.get("savedAt", 0)), "bytes", m.get("saveBytes"),
                  "check", m.get("check"), "pinned", (m.get("pinned") or {}).get("rev"),
                  "backups", [(x.get("rev"), x.get("check")) for x in m.get("backups") or []])
        for gid, at in (ix.get("tombstones") or {}).items():
            print(" ", aid, gid, "deleted", day(at))
        print("  quarantine:", [q for q in qs if q[1] == aid])
```
