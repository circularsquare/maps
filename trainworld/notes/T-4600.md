# T-4600 Tasks sized by tokens

Her 11-28: size agent tasks by tokens from measured data, 200-500k, a note at 400k.

- Record: notes/agent-tokens.jsonl, one line per top-level agent of an orchestrating session. Built by tools/agent_tokens.py
  (sync, stats, add); reports.py's SubagentStop hook adds each agent as it stops. tokens = the largest context one call
  reached (what the 400k note watches); kind = the budget row from the brief's "Kind:" line, "unknown" for briefs
  before T-4421 (about 1,000 of 1,075 first records).
- brief.py prints a "Size:" line: median and highest of finished agents of the same row (the task's LINES line if 3 or
  more share it), and "split it" when a third or more ran past 500k.
- .claude/hooks/orchestrator.py agent_budget: a subagent of an orchestrating session gets one note at its next tool
  call after its context passes 400k. Tested with sample payloads (derived path, explicit path, once only, small, no
  agent_id, other session, missing file). The real payload's transcript_path for a subagent was not seen: the hook
  accepts agent_transcript_path, an agent's own transcript_path, or derives the path from the session's.
- First numbers (median tokens, highest): Trip figures, sim 227k/574k (n=18); App logic 148k/442k (17); Tooling 72k/109k (11);
  Edit speed 346k/625k (7); Loading, memory 202k/585k (7); UI, text, CSS 87k/199k (3).
