# T-3774 Feedback reports carry the save state

Agent savestate, 2026-11-19, tree `savestate`. Follows T-3772 (notes/T-3772.md) and T-3773 (the open-failure record).

## What changed

A feedback report's context gains one key, `saves`, built by `saveStateReport(active)` in `app/src/game/saveState.ts`
and added in `ui/FeedbackPanel.tsx` (`reportContext` is now async). `countUnreadable()` is new in `workers/saveFile.ts`.
One line, counts and short codes only (each reason cut to 80 characters; no names, contents or account ids):

    slots 2; damaged 1; playing local only; unreadable copies 2; signed in no; persisted no; open failures 1, last slot: clockWorker.saveDamaged (dev)

- `slots`, `damaged`: the slot list (`listSlots`, readable from the start menu too).
- `playing`: the active slot's sync state: `sync error: <reason>`, `synced`, `local only`, or `none` (start menu).
- `unreadable copies`: keys `unreadable-*` kept aside.
- `signed in`, `persisted` (`navigator.storage.persisted()`, `?` if unsupported).
- `open failures <count>, last <from>: <error code or key> (<build>)`: T-3773's `tw-open-failures`. The last entry is
  dropped once that slot opens fine (the count stays).
If the slot list cannot be read: `slots unreadable: <error name>`.

## Server and reader

shonei-server `feedback.go` stores `context` as an opaque map (48 entries, 64-char keys, 8192-char values): no server
change. `tools/ops/feedback.py` prints every context key as `key: value`, so `saves: ...` shows as one readable line;
no change needed.

## Proof

Scratch probe (scratchpad/savestate/probe.mjs, Vite 6154, network stubbed so nothing is sent): start menu fresh
(2 slots, 1 unreadable copy planted) -> `damaged 0, open failures 0`; after a forced failed open of a cut-short slot
(`?slot=`) -> `damaged 1, unreadable copies 2, open failures 1, last slot: clockWorker.saveDamaged`; playing a good slot
-> `playing local only`. Not exercised: a real sync error (the field is the SyncRecord's `error`). Typecheck clean.
No smoke, no changelog item, no in-game strings.
