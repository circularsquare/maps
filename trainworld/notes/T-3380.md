# T-3380 delete ghost on single track (bugs1, 2026-11-16)

Fixed. Cause: `strokesFromParts` drew the red delete highlight with the default lane (255 = two tracks drawn apart), so
it straddled a single track. Now `deleteHover` (app/src/map/tools.ts) passes lane 0 for a single-track edge, 255 otherwise.
Check: checks/t3379-single-fixes.mjs (preview strokes' lane is 0 over single track).
