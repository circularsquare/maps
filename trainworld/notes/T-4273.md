# T-4273 rename station shortcut

F2 is taken (hide the interface, HIDE_UI_KEY), so the key is R (RENAME_KEY in ui/toolKeys.ts, free of every other key).
NameEdit takes an optional hotkey; StationInspector passes it, so it only works while a station panel is open and the name is not already being edited.
Ignored in text fields (keyIsTheirs), with modifiers, held keys, and under a dialog or the start menu.
Help panel Keys list: new row "R" - "Rename the open station", before the hide-interface row. en.json and context.json only.
Run: new game NYC, a three-station line, selected the middle station, pressed R: name box open and focused, typing "rx" went into the box, Esc closed it. Typecheck clean.
