# T-3835: a station on a loop line says it turns trains (agent looptag, 2026-11-20)

The report (Discord, via her pad): a pink tram loop in Dallas, McKinney & Harwood's dot says "turning at 80% of capacity,
12/15 trams per hour", "is this a technical limitation". Screenshot `artifacts/trainworld/board/20261120-001620-7aa8.png`.
The player's save was not seen, so the cause below is one confirmed way to get that hover, not proof it was theirs.

## What the hover is

"turning" is capacity wire kind 3, a `ResKind::Terminus`, pushed only by `capacity::turn_at` in `build_nodes`: where a run
turns back partway (`turns_back` between two path entries), or at the last node of a run of a line that is no circle.
So it was never only the label: the sim counted a turn there, and a turn without a terminal takes 15 an hour, which caps
the whole line.

## Cause

A loop line starts both ways. Run 1 (the return run) is built from `Network::back_run_of`: the path run backward when every
piece allows it, else the stops routed in reverse order. Where some of the loop is one-way track (set, or one way by its
joins, as a tram street pair often is), run 1 cannot go round the other way, so the route search gets to its stops either:

- by going round again (a lap is cheaper than `REVERSAL_SEARCH_S`, 600 s): run 1 several laps long, no turn;
- or by turning back at a station partway (a lap dearer than 600 s): a Terminus there, for run 1's trains only. The map
  draws the line straight through that station, both sides, which matches the screenshot.

Plain loops (two-way track, rail or tram, double or single, made-up track or street tram drawn with the track tool and
closed with "Right click to close loop") were all circles with no turn anywhere.

### Reproduced

- Rust, single-track triangle A B C, closed line both ways: AB one way -> run 1 nodes `[A, C, B, C, A]`, TERMINUS at B,
  users `[(line 0, run 1)]`. All three one way -> run 1 `[A, B, C, A, B, C, A]` (round twice), no turn.
- In game (Dallas sandbox, play.mjs, my Vite 6218): a 6 km tram ring of double track with one side single and set one way,
  five stations, line closed and left both ways, 60 trams: run 1 went round to the far station and turned back there.
  Hover on that station: "turning at 100% of capacity / 15/15 trams per hour", the line held to 15 trams an hour, round
  trip 4,230 s. Screenshot `artifacts/trainworld/t3835_before_turning.png`.
  The same ring at 1 km a side: run 1 four laps long (18.5 km against 4.6 km), round trip 3,718 s, no turn dot.

## Fix (sim)

`Network::runs_once(l, stops, path)`: a loop runs once round, one way, when set so (T-2981) or when its return run cannot
go round as run 0 does (`back_laps`): the path run backward runs (cheap check, every ordinary loop stops here), or the way
`back_run_of` finds turns back no more often than run 0's path and passes the first stop no more often. Derived on every
build, never stored: the line's setting stays both ways, undo and saves are untouched, and making the track two-way again
brings both ways back.

- Used by `build_on` (`LineSvc::one_way`), `line_runs_once`, `stretch_runs_once` and `line_stretch`, so `check_line`,
  `back_only_edges`, the world's reroutes, twin and snapshot all agree the line has no return run.
- `back_lines` keeps such a loop by its setting alone (`set_once`), so track built anywhere that gives it a way back
  rebuilds it, as before.
- `oneway_plan`: setting track one way that leaves a two-way loop no way back is no longer refused for that loop
  (`OneWayNoWay`); it runs one way.
- Balloons and branch turns in run 0's own path are untouched (a balloon's first stop still turns: the stem end).
- A loop whose return run has track of its own (a split double's other leg, one way each) still runs both ways.
- `TrackApi::line_one_way_by_track`, `LineStats.oneWayByTrack`: the line panel's Both ways is greyed out with the hover
  "Part of this loop's track runs one way".

Rates change: an affected line runs one way with all its trains on run 0 (any count, one lap), so its trains an hour and
round trip change, in old saves too, on load.

Test: `sim/src/track/wasm/loop_way_tests.rs` (one edge one way, all one way, a split double's two legs, a balloon).

## After the fix (same 6 km ring, 60 trams asked)

| | before | after |
|---|---|---|
