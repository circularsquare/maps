# T-3899 ramp ends in the track level view

Code: `M_RAMPEND` marks (shape 8) made by `rampMarks(pts, tier, out, tracks)` in map/markData.ts at the first and last
point of every ramp run, only where the height is a whole level (an edge boundary partway up a ramp gets none).
Level is the fractional z/8, so the colour blends like the stroke's. Tier slot: 0 built, 1 blueprint, +2 double track.
Drawn by the existing grade marks pass (gradeMarks.ts), one more instance per end, only when `opt.byLevel` and the ramp
marks setting is on, from zoom 11 (the ramp marks' zoom).

Sizes: length 9/8 of the track's drawn width (built or blueprint, single or double, from `rampEndSizes` in
rendererDraw.ts, which repeats the stroke shader's width rule: single = line width * mix(0.71, 1, grow); double =
max(line width * mix(1.24, 1, grow), G * (1 + share)); blueprint adds its rails). Thickness 1/8 of the built double
width, at least 1 device px. Colour: the level colour mixed 30% toward the mark ink, 90% opaque (the track is that same
level colour at the end, so the plain colour would only show past the track edges).

Not covered: tram track (no ends), high-speed track's 1.25x width at low zoom, a ramp passing a whole level between
edges. Previews while drawing get none. Checked in the real save with a fixture of built and blueprint, single and
double ramps near (-73.946, 40.70), shots in artifacts/trainworld/T-3899/.
