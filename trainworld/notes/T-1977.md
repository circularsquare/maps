# T-1977: zone_outlines over `--jobs` and cached by window (2026-11-02, agent t1977)

Folds in T-1218. Code: `pipeline/zone_outlines.py` (load, cut and simplify, output) and
`pipeline/zone_water.py` (sea tiles, zone polygons, windows, per-zone finish, cache). `world_run.py`
passes `--jobs` to the step. Check scripts (throwaways) were in the session scratchpad `t1977\`.

## What runs where

- **Load** the boundary files over the pool as (n, 2) integer arrays; `cut_points` finds where the set of
  zones holding a segment changes with numpy (each segment's holder set is two 64-bit sums over its
  zones' random numbers, fixed seed), so the simplification of each zone is one pool task. Output equals
  the old `outline_rings` on the world's rings and on list-of-tuples input (realms.py's path).
- **Sea tiles** (4,412 whole-degree tiles, 1,425 with sea): read over the pool into WKB files in the
  cache folder, once per sea file.
- **Zone polygons** over the pool, kept by the hash of the zone's id, rings and latitude; a zone's coast flag
  (within 400 m of sea) is kept with it, per sea file.
- **Windows** (368): each is a pool task given only its coordinates; workers hold every zone polygon (WKB)
  and read the sea tiles near the window from the tile files. Results go back as WKB and into one file each.
  The zones near a window and the tiles in it are taken in ascending order (the old code took the
  spatial tree's order); the output is byte-identical anyway.
- **Per-zone finish** (the band into its own land): a pool task per zone with sea, kept by the hash of the
  zone, its pieces and the zones near them.
- Spawned processes everywhere (Windows), also under `world_run.py step` (`python -I`).

## Cache (`data/work/zone_outlines_cache`, 53.5 MB: sea tiles 30 MB, zones.pkl 12.8, finals.pkl 4.7, win/ 5.4)

A window's key hashes the code version (zone_water.py's text and the shapely, GEOS, numpy and scipy
versions), the sea file (size and mtime), its coordinates and every zone whose grown box meets its extent
a degree wider (a whole-degree sea tile exists when any zone's grown box meets it, so zones that far
away change what the window sees). That is wider than the zones the window uses, so a changed zone
redoes the windows within about a degree and a half of it. A full run prunes what it did not use; a
`--box` trial does not. `--no-cache` keeps nothing.

The window work is 860-960 CPU seconds and scales to 4 jobs; its cost is `owner_cells` 37%, the reach
buffers 21%, the owners' points 8% (profile of 8 busy windows, `prof5.py`). A cold full run under 3
minutes needs that code cheaper, which is T-1992.
