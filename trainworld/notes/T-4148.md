# T-4148 Construct and the select tool shown at the click (agent editpieces, 2026-11-23)

## What changed

- **game/pieceAhead.ts (new)**: `pieceShow(op)` guesses what an edit draws from the world at the click; `aheadEdit(op, send)` sends it through
  `ahead()` (game/pending.ts). game/world.ts `edit()` calls `aheadEdit`, so every caller gets it: Construct (a line, all, a pick, a
  station's), blueprint off/on, level, track count, remove (pick), rebuild (level and track count), piece speed limit and one way.
  Cash comes off from the edges' own prices (US$, /1e6); a station's price is not in the guess (the worker's charge covers it).
- **workers/clockWordPieces.ts**: reads the edge table (`edges_info`) before and after the apply. Word: edges built, track count, level (single-level
  only); `removePieces`: edges gone from the table and the stations asked for; `blueprintOff`: the edges still blueprint with the new off state.
- **Blueprint drags** (`dragAhead`): node drag (map/nodeDrag.ts), box move (map/blueprintBox.ts) and point drag (map/edgeEdit.ts) draw the preview's
  strokes as blueprint at the release and hide the edges they move until the network holds the move. A refused preview draws nothing.
- **Panels**: ui/Blueprint.tsx and ui/inspector/PieceLimit.tsx read the pending speed limit and one way through `withShown`.
- Construct of a station draws it built from the network's own station buffers (blueprint flag off), no geometry from the worker.

## Stage 2 (agent editpieces, 2026-11-24): track type, double up, rebuild, one way, a station's off look

- **Track type** (`edgesKind`) and **rebuild**'s kind: `EdgeLook` has `kind` (the track model's number: 0 rail, 1 high speed, 2 street tram, 3 tram, 4 busway),
  which `withLook` (map/lineAhead.ts) turns into the strokes' high speed / tram / busway flags (a line over the edge takes a tram's look, not high speed's).
  The guess is from the op (game/pieceAhead.ts: blueprint double track that is not already that type; rebuild: built pieces with the op's level, type, track count).
  The word for `edgesKind` is each named edge's type read after the apply (`edge_kind`), no edge table.
- **Double up**: no guess (the new pair's shape is the model's). The word carries the new edges' points (`pieces`, from `drawnEdgeNow` in workers/clockMain.ts: the model's own points in local units, read again because the word is built before the dirty edges' kept points are dropped), and the page draws them as blueprint (`strokesFromPieces` in map/network.ts). The pair is drawn without the network's leg shifts and tapers, so it is near but not exactly the final one.
- **One-way chevrons**: `EdgeLook.oneWay` (with `ends`, the edge's end nodes). The renderer (`buildAhead`) replaces the one-way track chevrons with the network's minus those lying on the named edges' strokes, plus new ones laid by `oneWayTrackRuns` on the strokes of the edges set to run one way, clear of stations and junctions only (the network also clears marks). In a probe on the NYC save the six chevrons of a 1.7 km piece were drawn at 0 ms and the network's were the same six at the same places; one way off took them away at 0 ms. The word gives each edge's stored way (`edge_way`); the page keeps the guess's `ends`.
- **A station's off look**: `blueprintOff` with stations draws the station again from the network's buffers with the off flag (8) set or cleared, its own hidden (`restyledStations`, which also builds Construct's built stations).
- Edge table reads (`edges_info`, two per edit, 35 ms on Asia) are only for Construct, level, track count, off, remove and Double up now: rebuild, track type and one way read nothing of it (rebuild: the guess only, so a partly refused rebuild keeps its guess until the network).
