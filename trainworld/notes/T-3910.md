# T-3910: boarding cost at every train and tram station (agent boarding, 2026-11-20)

Anita: "i feel like maybe the 2 minute penalty for boarding via stairs is a bit harsh and incentivizes steret level stuff too much. maybe we can just add it even for street level? just like a general boarding cost. its simpler that way. we can remove it later if we find a better way to nerf trams".

## Built
- `sim/src/demand/network.rs`: `pub const STAIRS_AT_GRADE: bool = true` and `Network::pays_ends(k)` (true for every stop while the constant is true, else only stops not at grade). `kernel/search.rs` `build_graph` calls `pays_ends` instead of `!at_grade`. Set the constant false to bring the T-3888 exemption back. Levels, `gradeStops`, `set_stairs` and the cluster slicing are untouched.
- Trip explorer: `trip.stairs` in en.json "stairs" -> "boarding" (key and `id: "stairs"` kept; the other locales have no `trip.stairs` yet, so nothing orphaned; translations at publish).
- Docs: SPEC section 3 line, docs/demand-mode.md, demand-plain.md, demand-worldwide.md, wiki waiting-and-changing (how-people-choose never stated the rule). DECISIONS line in the main tree. Changelog c049 reworded.
- Tests: `a_train_trip_pays_its_way_in_and_out` asserts every stop pays (and the old exemption under the false branch). `agent_cargo.py test`: 704 passed. `t3888-cluster-stairs.mjs` tests only the plumbing, so no expectation changed; passes. Typecheck passes.

## In the game
Real NYC save, trip 198 -> 200 on line 5, both stations level 0: `ride:4:ends=4`, term "boarding" = 4 (before: 0). A level 0 to level 2 pair gave `ends=2` under the old rule and 4 now.

## Friction
The first real-save run (before any restart of Vite) gave 12,664,384 and `ends=2` for the at-grade end: the old rule, although the tree's WASM was rebuilt first. Restarting Vite and the game gave the new rule. After every `agent_cargo.py wasm`, restart your Vite before a measure.
