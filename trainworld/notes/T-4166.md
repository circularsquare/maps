## Choices (and why)

- **Code**: `git archive` of the commit's app/ and sim/ (plus the main tree's uncommitted app/src/game/*.json, as
  agent-tree.mjs does) with the main tree's tracked tools/, checks/, cores.py and the NYC save: about 23 MB a tree,
  uploaded per run, deleted at the end. The tools come from the main tree so a fix to the bench reaches old commits.
- **Data**: only what the saves read, cached in S3 under a hash of (path, size, mtime): uploaded once per change
  (10 s for 56 MB here), then reused. Storage 0.06 GB = about $0.001 a month. The whole data (6.8 GB packs +
  0.76 GB terrain) would be $0.17 a month and a long upload, for nothing nyc reads.
- **No machine image**: a snapshot would bill about $0.40-0.80 a month idle and go stale; installing each run costs
  about 6-8 minutes (under a cent at spot price).
- **Type**: m8a.xlarge (4 vCPUs, each a full core on AMD's 7a/8a, 16 GB; NYC's tab peaks 2.4 GB). Spot was
  $0.065-0.067/h on 11-24; on-demand $0.243/h; cap $0.25/h. c8a.xlarge and m7a.xlarge allowed by `--type`;
  m8a/c8a/m7a.large (2 vCPUs) allowed only as a flow check while the quota is short (the scripts drop to the
  machine's core count).
- **Cost of a run, estimated** (no run yet): setup 8 + build 10 + perf nyc 5 + edit nyc 10 = about 35-40 min.
  Spot: 0.65 h x ($0.066 + $0.005 IPv4 + $0.003 disk) = **about 5 cents**. On-demand fallback: about 16 cents. With
  `--base` (second build, compare runs twice): about 60 min, 7 cents spot. Her 50 cents came from elsewhere.
- **The cutoff**: Budgets' own "stop EC2 instances" action needs instance ids fixed in advance; each run makes a new
  machine, so the deny policy blocks new ones and the timer (3 h at most, $0.75 worst case) ends a running one.
  S3 stays allowed so a run past the line can still send results and clean up.
- **Numbers stay apart**: the machine writes its ledgers on the machine; results come home to
  artifacts/trainworld/awsbench/<run>/, never into notes/*-ledger.jsonl (Linux + SwiftShader numbers).
