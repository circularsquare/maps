# T-4205 mode icon colours

Table: MODE_ICON_COLOURS in app/src/game/palette.ts. Read by the station tool's kind buttons (ui/ToolBar.tsx) and the placing tag's icon and trips-near bar (map/toolMarks.ts, CSS var --kind on .size-bar, style.css).

| mode | hex | note |
|---|---|---|
| train | #2f6fd6 | blue |
| high speed | #3c4fc4 | dark blue; not a station kind, in the table for later |
| tram | #4aaee6 | light blue |
| bus | #8a5cc8 | purple; not a station kind |
| BRT | #a35fc4 | a step more magenta than the bus; used for the BRT station kind |
| ferry | #139d94 | blue-green; used for the port kind |

Existing colours looked at: TRACK_TYPE_COLOURS (rail teal #0a819d, hsr #5a5fc8, tram orange #c0603a) and CLICK_MODE_COLOURS (bus olive, ferry #16716f). They colour the track tool's aura and a different thing, and tram orange contradicts her ask, so the new table is separate and the old ones are unchanged. "Auto" keeps the default icon colour.
