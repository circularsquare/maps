# T-3808: Type as a sortable Lines tab column

Anita, 2026-11-19: "i dont want that to be the default case. i want you to be *able* to sort by type. like have type as a column and can sort by it."

- Type is an ordinary column in the Lines tab, always shown: each line's type icon (a group shows its most common type), header "Type" after Fleet and before Near, 38 px wide. Click sorts train, high speed, tram, bus, ferry; click again reverses.
- Default sort is unchanged: `lineSort` starts on Riders, biggest first (game/ui.ts); it is not stored anywhere.
- `beside` in SortHead stays: Near still uses it while it has no column.
- The column adds 46 px, so the `@container lines` thresholds in style.css that hide Money and City went up by 46 (13 rules).
