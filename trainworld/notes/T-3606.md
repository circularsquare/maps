# T-3606: station ghost matches the placed station

Cause: the placement ghost (tools.ts, `boxGhost` and the pending mark after a click) called `stationShape` without the tram
flag, so a tram stop's ghost was a full rail box (the placed one is TRAM_BOX = 0.7 of it, and its one-track bar is sized from
that). It also never knew the track under it, so a station placed on one way single track (drawn as one bar on its outside,
network.ts `single` / ST_ONE_MID) was a full box as a ghost. And its outline was a 2px stroke centred on the box edge, a pixel
wider each side than a built station's rim, which is drawn inside the edge at `stationRing(zoom)`.

Change (worktree tw/ghostmatch, app/src/map/tools.ts only, uncommitted):
- `ghostShape(...)`: the one place that builds the ghost's `StationShape` (ghost, quad twin, pending mark). It passes
  `{ tram, mid }` as the built station's `stationShapeAt` does, so `TRAM_BOX`, `oneBar`, `ONE_END`, `ONE_BUMP` and the box
  width rule all come from stationGeometry.ts like a placed station. Tram and mid are kept in `lastBox` for the pending mark.
- `outsideSide(...)`: the single-track case. Same rule as network.ts: every track under the platform single, none a crossover,
  and the station not splitting (`splitsAt`, terminalBays.ts: two-way single track splits through a station, so it stays a
  full box); then the side comes from the same `stationOutside`. Part way along an edge the new node is -1 with the edge's two
  halves either side (join bits split a/b). Net result: a ghost on one way single track, or single track that joins a double,
  is one bar on its outside; on two-way single track it is a full box, as placed.
- `ghostPath(...)`: path drawn half a rim in, stroke width = `stationStyle.ringPx`, so the outline sits where the rim does.
  It also removed the slanted ramp the old ghost drew at a one-track bulge.

Passing tracks: not a placement matter. A new station has no passing upgrade (it is bought on a built station afterwards,
`UPGRADE.passing` on double track), so a ghost and the station it places are both without; nothing to match. Waiting rooms and
other upgrades are likewise not drawn on the ghost.

Tram, one track, z17 (coordinator's question): checked at 3x. The ghost's bar and bulge are the same width and depth as the
placed one's (the old ghost looked taller because it was a rail-width box).
