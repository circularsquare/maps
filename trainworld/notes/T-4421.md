# T-4421 brief.py

`venv\Scripts\python.exe trainworld/tools/brief.py <task id> --kind <row> --model <m> --tree <name> --port <n> --ids <ids> [--decisions "..."] [--todo "<text>"] [--out <file>]`

- Reads TASKS.md, notes, TODO.md and board-live.json from the main tree (first `git worktree list` entry), since a worktree has no board and its TASKS.md is not edited.
- --kind: ui, logic, edit, sim, loading, or any part of a row's name; the row is parsed from the CLAUDE.md budget table and quoted as written. `tooling` means no game runs. No match lists the rows and exits 1.
- Notes link: notes/<id>.md if it exists, else the task's Other: link, else notes/<id>.md (new).
- Other agents: every other agent on the board, with their tree's first 6 dirty files (git status -uno).
- Scratchpad: found from the orchestrator id on the board under %TEMP%/claude/*/<id>*/scratchpad/<tree>; placeholder if not found.
- --todo: the one short-term TODO.md item containing the text, with its indented lines; 0 or 2+ matches exit 1. Untested on a real item (short-term is empty today).
