# T-4279 fixes from Gemini's review of batch 16c

Typecheck clean. No game run: every fix follows from the code.

## T-4243 speed dial
1. Held train clicked while paused (or first frame): real, left. The dial has no lag history on mount, so it cannot tell a held train from one making up lag; fixing it needs the guard to keep a per-trip lag rate. Cosmetic and brief while running (one guard tick); only a paused click shows full timetable speed.
2. mph descender clipping: unsure, not a bug found by reading (3 px under the baseline at 12 px); left.

## T-4251 BRT stations on busways
1. Stale ghost on first hover: real. brtRoads' onLoad was landed(), which only serves the track tool's search. Now it redraws (the station tool's place()). Fixed in streetSnap.ts.
2. Hidden-level busways still snap: real. buswaysOf(overlay, true) leaves out busways wholly on a switched-off level, for the station tool's instance only (the bus route tool keeps all busways). Memo keyed by the hidden mask. Fixed in buswayLines.ts.

## T-4257 bus routes by speed
1. Duplicate callbacks while WASM loads: real (harmless in effect, but N setBusSpeeds/onLoad calls and a version bump each). Added an asked flag in BusRoads.need. Gemini's remark that tram/rail/brt instances do not need the speeds is true but they share the graph code; left (the load is one module, loaded once).
2. A failed WASM load cached forever: real, reachable on a flaky network. busSpeeds() now clears its cache on null so the next ask retries.

## T-4259 rename stations
1. Esc from a button or non-input inside the panel closed the whole line panel: real. Esc is now handled on the .rename-stops container, so it closes only the boxes.
2. Focusing an unbound station's box lit its whole complex: real, small. Now only that station is lit; bound rows still light their complex.
3. Safari IME Enter (keyCode 229): real in principle, one-word guard added.
