# T-056 basemap place names in Zen Maru Gothic

Done 2026-10-09. Every basemap label (places, water, roads, airports, countries) is drawn in Zen
Maru Gothic Regular from glyph tiles we generate and host beside the app. Screenshots at 1440x900,
Manhattan at zoom 12.5: `T-056-before.png` (Positron's Noto Sans), `T-056-after.png`.

## How it works

- `app/src/map/basemap.ts` owns the basemap style: it loads OpenFreeMap Positron with
  `map.setStyle(url, { transformStyle })` and rewrites the JSON before MapLibre commits it (the
  faint repaint that used to run on `style.load` in mapView.ts, the hidden railways and shields,
  the fonts), so nothing draws in Positron's colours or fonts first. `mapView.ts` calls
  `loadBasemap(map)` and re-exports `setBasemapLabels`.
- `glyphs` points at `fonts/{fontstack}/{range}.pbf`, made absolute from `document.baseURI`, so it
  works under `/trainworld/` on serve.py and on any later host.
- Every symbol layer gets `text-font: ["Zen Maru Gothic Regular", "Noto Sans Regular"]`. MapLibre
  fetches one file per font stack and range (the URL has the whole stack, comma-joined), so with
  static files the fallback cannot happen in the client: each shipped file already holds Zen Maru's
  glyphs and, for codepoints Zen Maru lacks, OpenFreeMap's Noto Sans Regular glyphs (the font the
  labels used before). Zen Maru wins wherever it has the glyph.
- Regular only. Zen Maru has no italic, so Positron's italic layers (water, neighbourhoods, states)
  are upright now; its bold layers (capitals, countries) are Regular too, which suits the faint
  look. A Bold stack is one more combination line in `pipeline/glyphs.py` if the world view wants
  that hierarchy back.
- Labels stay `#a9abad` with a land-coloured halo (memory `feedback_faint_basemap_labels`).
- Also in basemap.ts, both from memory `reference_maplibre_rtl_and_name_en`: the RTL text plugin
  (lazy, 0.2.3; Arabic shapes and joins on MapLibre 6) and the guard that turns OpenFreeMap's
  name_en "T" back into "Türkiye".

## Size

Zen Maru itself does not draw larger than Noto in the glyph tiles: at the 24 px glyph size its
Latin advances are a little narrower (n 12 vs 14, M 18 vs 21) with the same cap height, so the
style's text sizes are unchanged. On screen the labels read slightly lighter than Noto's. Zen
Maru's glyphs sit about 0.1 em lower than Noto's, visible only where one label mixes the two
(e.g. a Thai name next to Latin).

## What ships, what downloads

- `app/public/fonts/Zen Maru Gothic Regular,Noto Sans Regular/`: 52 ranges, 3.76 MB on disk (14
  of them contain Zen Maru glyphs: Latin, Latin extended, Greek, Cyrillic, punctuation, symbols).
  The OFL texts sit beside them: `OFL-ZenMaruGothic.txt`, `OFL-NotoSans.txt`.
- Left out on purpose:
  - kana, kanji, hangul and the rest of MapLibre's `localIdeographFontFamily` set. MapLibre never
    fetches those; it draws them in the browser (the system's Japanese font on Windows). So no CJK
    ranges are shipped, and Japanese place names render, but not in Zen Maru (follow-up T-057).
  - ranges neither font has. A missing file is a 404 and MapLibre draws the codepoint locally (with
    a one-time console warning); an empty file would make the character vanish, which is what
    OpenFreeMap's empty files do today.
- A New York session (zoom 9.5 to 15.5 checked) downloads one file: `0-255.pbf`, 81 kB as
  served by serve.py (29 kB gzipped). Before: Noto Sans Regular and Noto Sans Italic `0-255`, 43
  and 48 kB gzipped from OpenFreeMap. The UI's Google Fonts woff2 files are unchanged.
- Checked headless (real GPU): Cairo (Arabic, joined), Tokyo (kanji drawn locally), the Black Sea
  at zoom 4.5 (Cyrillic, Greek, Georgian, Armenian, Arabic, "Türkiye") all render; no glyph errors
  in the console.

## Regenerating

    cargo install build_pbf_glyphs --locked
    ..\venv\Scripts\python.exe pipeline\glyphs.py

- The tool is Stadia Maps' `build_pbf_glyphs` 1.5.1 (sdf_font_tools, Rust; same SDF layout as
  fontnik: 24 px, 3 px buffer). On Windows its bundled FreeType build fails on `zlib.h`; set
  `CFLAGS=-I%USERPROFILE%\.cargo\registry\src\index.crates.io-1949cf8c6b5b557f\libz-sys-1.1.25\src\zlib`
  (any libz-sys version in the registry) before `cargo install`. `--tool <path>` if it is not on
  PATH.
- The script downloads `ZenMaruGothic-Regular.ttf` and the two OFL texts from google/fonts and
  OpenFreeMap's 256 Noto Sans Regular ranges (34.6 MB, 256 requests) into `data/raw/glyphs/`
  (cached, gitignored), renders and combines in `data/work/glyphs/` (deleted afterwards), and
  rewrites `app/public/fonts/`. About 2 s once the inputs are cached.
