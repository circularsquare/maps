# T-826: Run in background

Anita, 2026-10-21: a setting that keeps the game running at full speed while its tab is hidden.

## How it was measured

Chrome 155 on Windows, driven over raw CDP (Playwright's focus emulation keeps every page
"visible", and headless Chrome never hides a page). A real window off screen with
`--disable-backgrounding-occluded-windows`; the game's tab is hidden by opening another tab in front
(`Target.createTarget` / `Target.activateTarget`), as a player switching tabs does. Minimizing the
window was tried first and dropped: Windows restored the off-screen window by itself after about
50 s on the second minimize. The real save imported into `?debug=1&new=1&paused=1`, given a slot
with "Save as a copy" so it autosaves, demand final and the clock released before timing.
Scripts (scratch, not kept): `measure.mjs` and `cdp.mjs` in the agent's scratchpad `t826/`.

What a hidden tab gets from this Chrome (a probe page): animation frames 0/s (60 visible); a 50 ms
main-thread timer chain 1/s (19 visible); the same chain in a dedicated worker 15/s (19.5 visible).
Chrome's intensive throttling (main-thread chains once a minute after 5 hidden minutes) was not
reached by anything that matters, since nothing time-critical runs on main-thread timers.

## Before (setting off, which is the old code path)

The game clock froze on `visibilitychange` (`GameClock.setHidden`), the clock message went to the
worker with rate 0, and `liveMoney` stopped settling. Nothing half-ran: hidden, the game paused.

| speed | visible, game min per wall min | hidden, game min per wall min | cash while hidden | solves |
|---|---|---|---|---|
| 1 (60x) | 60 | 0 | 0 | 0 |
| 2 (240x) | 240 | 0 | 0 | 0 |
| 3 (960x) | 960 | 0 | 0 | 0 |

Measured twice: on the pre-change code (120 s hidden a speed, minimized window; 60x and 960x clean,
the 240x try spoiled by the window restoring itself) and with the setting off after the change
(60 s hidden a speed, tab hiding; all three rows 0). No autosave while hidden beyond the one written
as the tab is hidden (`flush`).

## After (setting on)

| speed | visible, game min per wall min | hidden, game min per wall min | cash while hidden (US$M) | autosaves while hidden | solves |
|---|---|---|---|---|---|
| 1 (60x) | 60.01 | 60.01 | +351 over 120 game min | yes | 0 |
| 2 (240x) | 240.05 | 240.02 | +820 over 480 game min | yes | 0 |
| 3 (960x) | 960.23 | 960.08 | +2,414 over 32 game h | yes | 0 |

120 s hidden at each speed. While hidden the shown minute stays put (no frames); at the first frame
back it jumps to the clock (124, 496 and 1,985 minutes after hiding, 3 s after return).

**Seven minutes hidden** at 60x (past the 5-minute intensive throttling): 60.01 game minutes per
wall minute throughout, an autosave each wall minute (lastSaved moved at 180, 240, 300, 360, 420 s),
cash settled throughout.

**Money against a visible run**: the same loaded game run at 960x for 100 wall s, once hidden the
whole time and once visible: 26.67 game hours each, 21 whole hours compared, fares US$2,050.91M
and running costs US$931.39M in both, worst difference in any hour's fares, running cost or rides
5e-16 (rounding). No demand solve in either (nothing time-driven re-solves demand).

## What runs where while hidden

- Clock worker (keeps running): money settling (`liveMoney`, 4 a second), autosave and backups
  (`tick`, once a second), from the last clock message extrapolated on wall time. No change was
  needed in `clock.worker.ts`.
- Main thread (stops with frames, catches up at the first frame back): the shown minute and the
  effects on it (day of week, demand level, stations full), the render epoch and so the worker's
  trips and boarding hour for the hour in view. Hours that pass wholly hidden have no boarding hour,
  so their fares land evenly within the hour; the hour totals are the same (table above).
- Station faces and sounds: stopped while hidden whatever the setting (`stationLife.ts`).
- If Chrome freezes the whole tab (Energy Saver, long-hidden tabs), the worker stops too; on return
  the clock and money catch up in one step (settling takes up to a year at once).
