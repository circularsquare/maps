# T-1052: the Europe pan's long tasks (2026-10-23)

**What they were.** Not the game. `t975-realms.mjs` moved the view with
`page.evaluate((c) => window.tw.map.jumpTo(...))`; `jumpTo` returns the map, so Playwright serialised
the whole MapLibre object back to Node after each of the 8 jumps: one 2 s task each, 8 / 16.8 s on
my run (14.8 s in the brief). T-1039 had met the same thing in its own check. With the arrow
returning nothing the same pan has no long task at all. Nothing loads there either: France and
Germany are hidden in a Tokyo game, so the pan fetches no packs.

**Fixed in the checks only**: `void` before the map call in every `evaluate` arrow that returned
the map (47 lines in 25 checks, among them the lag checks t1008, t348, t496, t675, and smoke); the
rule is in docs/code-map.md's browser checks. No app code changed, so figures and drawing are as
before (`t975-t1052-{before,after}-*.png` in artifacts/trainworld/).
