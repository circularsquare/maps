# T-152: university attendance

Implemented 2026-10-12 as a fourth optional NYC everyday purpose. IPEDS 2023 directory and Fall
Enrollment inputs yield 260 active degree-granting reporting institutions and 831,384 eligible
degree/certificate-seeking undergraduate plus graduate students. The importer excludes 96,653
exclusively distance-education students, child/merged/inactive records, nondegree undergraduates,
and unknown invalid enrollment. An IPEDS structural blank counts as zero online only when the
field is marked not applicable and reported non-distance enrollment equals the cohort total.

Each UNITID contributes one enrollment budget at its directory coordinate; system totals are not
copied to branches. All records matched existing cells without snapping. Adult origins use block
population times ACS 2023 tract age-18+ share. Runtime uses a provisional 60% attendance factor,
6 km decay, sixteen deterministic home samples, and a 65/27/7/0.9/0.1 outward and
4/42/42/11/1 return period split. The existing 150 m exclusion and walking-first mode model apply.
The UI calls it University (metro IPEDS), colours it amber, and states the coverage limits.

Pack audit: every pre-existing array, including schools, retained the same SHA256 content; the
repack is idempotent. The new pack is 13,326,324 bytes. Real-pack native validation reports
498,665.97 attendance outings / 997,331.94 legs, 6.98% walking and 9.58 km mean distance while
prior-purpose generation remains identical. Production WASM validation confirms purpose timing,
far-end and bubble reconciliation and old-pack optional compatibility. The existing school
production check and the full production WASM/TypeScript/Vite build pass.

The source-focused Python tests were written and passed in the data agent's configured environment.

failure, not a failed assertion. `pipeline/enrich_universities.py`,
