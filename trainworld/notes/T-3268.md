# T-3268 zoom buttons, account links

## Zoom buttons
- `ui/ZoomButtons.tsx`, mounted in main.ts beside the trouble list: plus and minus as `btn icon`, stacked at the map's right edge, halfway down (`.map-zoom` in style.css). The corners are taken (sky and debug top right, trouble button and attribution bottom right, search top left), the right edge is empty.
- `map.zoomIn()` / `zoomOut()`: one step, MapLibre's own easing. Checked: 11.2 -> 12.2 -> 11.2.
- `display.zoomButtons` (default true, no settings-version bump: a missing key takes the default). Settings > Map checkbox "Show zoom buttons". Unchecked: 0 buttons, stored false.
- Hidden with the rest of the UI (`ui-hidden`) and on the start menu (`.choosing`).
- No hover (it would repeat the label); aria-labels only.

## Account panel links
