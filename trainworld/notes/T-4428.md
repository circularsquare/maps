# T-4428 orchestrator guard (hook)

Code: .claude/hooks/orchestrator.py (subcommands code-guard, post; post runs reply-nudge and intake). Registered in .claude/settings.json: code-guard under PreToolUse (Edit|Write|MultiEdit|NotebookEdit|Bash|PowerShell); post is the existing PostToolUse "reply-nudge" command; agent-guard (PreToolUse Agent) resets the intake count.

## What fires for calls inside a REPL script (measured 11-27)
- PreToolUse and PostToolUse fire for each inner Bash, Read, Edit, Write (also for the globals edit() and write()), with the inner tool_name and tool_input. Their tool_use_id starts with "repl_". The REPL call itself fires too.
- PostToolUse for REPL has tool_response {code, result, stdout, stderr}: result is what the script returned (this is what enters context). Inner Post responses carry the full output, but it never reaches the context unless returned.
- Subagents share the orchestrator's session_id. Only agent_id tells them apart: absent on the orchestrator's own calls. A session id match alone would block every agent, so the guard requires no agent_id.
- prompt_id changes with each user prompt (used for "Anita wrote"; not verified for a message queued mid-turn: it only makes a reminder rarer).

## Behaviour
- Block: orchestrator (sid on an Orchestrator line, no agent_id) editing a path matching (trainworld|isochrone)/(app|sim|pipeline|checks)/, except .md/.txt. Also trees (.tw-trees/x/trainworld/app/...). Shell: redirects into those paths, or sed -i, tee, Set-Content, Out-File, git apply, patch, cp, mv, rm, Copy/Move/Remove-Item naming them. Running a check, grep, agent-tree.mjs finish: open. Shell heuristics are not airtight (a script file can still write); the Edit and Write tools, including inside REPL, are.
- Exception: create <TEMP>/claude-orchestrator/<sid>.allow-code (30 min). The refusal text says so.
- Reminder: INTAKE_LIMIT = 40000 chars of non-inner tool output (REPL: result+stdout+stderr) since the last agent start or new prompt_id; repeats only after another 40k and 5 min (INTAKE_GAP). Agent, SendMessage, Poll, Monitor, Skill outputs do not count. Never blocks.
- Fails open: main() swallows every exception (prints nothing); tests with garbage stdin, null, corrupt state file and an unwritable TEMP all exit 0 silently.

## Tests
