# T-3898 movable node highlight off its square

Cause: `.pi-mark` was 9 px (border-box) with margin -5, so its centre sat 0.5 px up-left of the whole pixel it is
placed at (`placeAt` rounds). `.pi-mark.hot` (T-3897) was 11 px with margin -6.5, centre 1 px up-left. The hot
square is the same element as the plain one, so the light-up moved 0.5 px up-left of it on hover, and both sat off
the node. Odd sizes cannot centre on a whole pixel.

Fix (ui/style.css): plain 10 px / margin -5, hot 12 px / margin -6. Both centre exactly on the placed pixel.
Remaining error is `placeAt`'s rounding (up to 0.5 px), identical for both states.

Measured (cic, blueprint end node, select tool, zoom 15 and 17.3, dpr 1 and 2, identical at all four).
Offsets of the box centre from the node's screen point, CSS px (dx, dy):
- before: plain (-0.5, 0), hot (-1, -0.5)
- after: plain (0, +0.5), hot (0, +0.5)  (+0.5 = the same rounding on both)
Ink-pixel centre in the crops, plain vs hot: before differ by 1 px each way, after 0.
Light/dark: same CSS box in both themes (colours only); dark not captured separately.
Images: artifacts/trainworld/T-3898/pair.png (top before, bottom after; plain left, hot right, dpr 2, zoom 15,
crosshair = placed pixel, 16x per CSS px).
