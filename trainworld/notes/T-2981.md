# T-2981 One-way loops

Agent oneway, 2026-11-10, tree `.tw-trees/oneway`. T-798 L3's stage, for trains, buses and ferries.
Decisions in DECISIONS.md (2026-11-10, T-2981); rules in docs/track-and-service.md 6.3 "Loops", 6.7, 6.9.

## How it works

- `LineData::one_way` / `Network::line_one_way`; `LineSvc::one_way` is the flag on a line that is a loop.
  `TrackApi::set_line_one_way` (an `Op::Line`, so undo is free), `line_one_way`. App op `lineOneWay`,
  `LineStats.oneWay`, `loopHalves(st)` in game/types.ts for the places that halved a loop's round trip or fleet.
- Run 1 off: `Service::lattice` gives `off` = infinity on a one-way loop, and `stretch_points` returns no
  departures for run 1 then. Everything that reads departures follows: trips, hand-over, the boarding account,
  `track::span` (run 1's phi is 0, which demand's `build_graph` reads as no train due, `rn_tph` 0, T-842). The
  eras keep the infinite `off`, so a toggle lets run-1 trains already out finish, and the ERA2 save carries it.
- Capacity: every per-run loop in `capacity.rs` takes `live_runs()` (7 one-line edits), so run 1 has no users.
- Round trip: `LineSvc::round_trip_of`: one lap one way. Fleet: `paired()` (a loop both ways) keeps the even count
  in `fleet`, `auto_counts`, `trim_auto`, `settle_counts`. Delay counts run 0 only. Running cost (sim
  `running_cost_in`, worker `regionLines`, app `today.ts`, `stretchMoney.ts`) one way's train-km. `line_dwell_split`.
- Save: `LOW1` (level 11) lists lines set the other way from their mode (`one_way_default` in save.rs).

## Where service.rs and the lattice were touched (for merging with trainflow, T-2972/T-2973)

- `LineSvc`: field `one_way`, methods `paired`, `live_runs`, `round_trip_of` (after `is_loop`); `fleet` uses `paired`.
- `stretch_points`: the first `if` also returns None for run 1 when `lat.off[lev]` is infinite.
- `Lattice` doc comment: one clause on the infinite `off`.
- `build_line`, `build_bus`, `build_ferry`: one line each setting `ls.one_way`.
- `update_scoped`: the round trip line calls `round_trip_of`; the delay line skips run 1 one way.
- `probe_trips`: calls `round_trip_of`.
- `Service::lattice`: inside the `off` closure, `if ls.one_way { return f64::INFINITY; }` first.

## Riders on a test loop (checks/t2981-oneway.mjs, new game in New York, weekday)

| Loop | Both ways | One way |
|---|---|---|
| Train ring, 4 stations round 2.4 km square, Crown Heights, 8/6/4 trains | 58,078 a day, 1.39 stops a ride, 50% on run 1 | 49,037 a day (-16%), 1.82 stops a ride, 0% on run 1 |
| Bus loop round a Manhattan block, 1.35 x 1.45 km | 39,011 a day, 1.54 stops a ride | 19,690 a day (-50%), 2.07 stops a ride |

The ring keeps its 8 trains one way, so they run twice as often; its riders fall 16% and ride a third further
(the long way round). The bus loop one way has half the buses of both ways (a headway line), and half the riders.
