# T-3635 the row of dates in the top bar (feedback 1794744778-ef2051d1)

Not reproduced (no free cores in the ledger, 14 of 14 claimed); reasoned from code.

## What it is

Not a "when saved" list and not a feature. Each item in the row is a copy of the top bar's clock box
(`.clock` in `Clock()`, ui/TopBar.tsx: time, date, weekday, with the 1px left border that draws the bars).
The 160px ja width of `.clock-text` (style.css) matches the item spacing in the screenshot. The dates are game
dates (Dec 24 Friday, Nov 23 Tuesday, Sep 23 Thursday: the game's 2021 calendar), not real save times.

## Why it appears

Nothing in the current code renders more than one clock: `<Clock />` is mounted once (TopBar.tsx line 325),
nothing else calls `dateName` with `clockTime` (only MoneyHistory hovers, which are not in the bar), and no code
appends to #topbar. SavesPanel's version list (`savedWhen`) uses real dates and is a panel. So the extra items
are leftover DOM nodes from earlier clock renders, kept in the page (each stopped at a past game time; several
are Japanese holidays, 02:00 or 01:00). A likely cause is something outside the game rewriting the clock's
nodes so Preact re-inserts a new one instead of updating (a page translator or similar extension; Chrome on
ja is the usual suspect), but that is a guess. Unconfirmed either way.

The squashed red/green/blue bar is a knock-on: #topbar is a nowrap flex row, `.split` takes whatever is left
(`.bar-box` min-width 60px, shrinking further), so the extra clocks eat its width and push the speed buttons off
the right edge. It is not mobile-only; the screenshot is desktop width (mobile uses a grid, style.css ~1669).

## Smallest fix (not built)

1. To find the cause: ask the player for their extensions, and whether it appears in a fresh Chrome profile
   (or with page translation off). Reproduce in a headless Chrome once a core is free by loading a save in ja and
   running the clock to late December at ~1500px; count `.clock` elements in #topbar.
2. Defensive, tiny: give `.clock` a stable identity (`translate="no"` on `#topbar` and `<html lang>` already
   set, so add `translate="no"` to the clock box) and let `.split-row` keep a minimum width by letting
   `#topbar .clock ~ .clock { display: none }` hide any duplicate. The hide rule is a band-aid.
3. There is no player setting to hide a "saved" time because there is none; nothing to add.
