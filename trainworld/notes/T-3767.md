# T-3767: five service periods for new lines, buses and ferries (agent periods5, tree tw/periods5, 2026-11-19)

Anita, 2026-11-19: "do the auto headways for new lines work with 5 period schedules? they should. currently it just
says "14 min, 22 min and 85 min" even if u have 5 intervals" and "the 5 intervals should work for buses/ferries too".
Follows T-3542 (notes/T-3542.md, stages 0-2).

## What changed

### New lines' default headways

- A default (`SaveHeader.newHeadway`, per kind) is three numbers (high, medium, low) when set from a line of three
  rows, else five, one per period morning to night (`headwaysOfRows`). Three-row games write the header as before.
- Read for a line of `n` rows (`game/newLine.ts` `headwaysIn`, through `headwaysFor(kind, set, n)`): three values
  spread as high, high, high, medium, low (a copy, as the switch up copies); five values joined per row as the
  shortest headway of its periods (as the switch down). The tool's own bus and ferry headways (8/15/30, 20/30/60 min)
  go through the same path.
- The window's list ("Headways for new ... lines") has one headway per row of the selected line; Set as default
  takes every row (`rowHeadwayShown`, `rowHeadwaysOfTrains`, `setRowAuto`), Use default sets every row
  (`world.ts` `setRowHeadways`, any number of rows).
- New lines (clock.worker.ts): a rail line gets `set_line_row_headways` with one value per game row when the game has
  four or five, else `set_auto_headway` as before. A bus or ferry line is made at the three (`set_bus_line`,
  `set_ferry_line`, which now start midday and afternoon at high's, `Extra::of_high`); where the default's midday or
  afternoon differ from that, a second edit (`newLineRows`) sets every row; its charge is summed with the weekend
  edit's (`newLineWeekends` takes a `Made`).
- `sharedSave.ts` accepts three or five per kind; `cleanNewHeadways` likewise (an older build drops a five).

### Bus and ferry lines take 3, 4 or 5 periods and their hours

- Sim: `Network::rows` and `Network::hours` no longer special-case bus and ferry lines; `set_line_periods`,
  `set_line_hours` accept them; `rows_ops` moves them with the game's switch (without that a switch to five would
  leave them no midday or afternoon service). Everything else (places, slots, `Mix`, settle, money) was per line
  already. T-3704's settle: a bus or ferry row edit lands in `t.schedules`, so it settles at once (Rust tests below).
- Window: the bus and ferry window (`BusBody`) shows Periods and the Hours column as a rail line's; still no board,
  no track limits, 360 px wide (fits: screenshot).
- **Save level 28 to 29** (no new block; built as 26 to 27, renumbered on the rebase over T-3759's 27 and T-3758's
  28): a save of level 28 or older whose game had other than three rows (read in `LPD1`) or moved hours (`LHR1`)
  gives each bus and ferry line following the game three rows and the default hours of its own
  (`save::pin_old_buses`, `OLD_BUS_ROWS = 28`, via `decode_at` with the header's level from `set_load_level`), so it
  runs as it ran. Other old saves are untouched.
- shonei-server's save check: `twSaveLevel` 29 (no block or layout change); until then saves from this build read
  "unverified" and are not pinned as the recovery copy, as with every level bump. The exact change is under "At
  landing".
