# T-234: no homes in prisons and jails

Done 2026-10-13. Anita's TODO: "why are there homes on rikers island?" The 2020 census counts
people where they are held or cared for, so Rikers Island's four blocks had 3,772 residents, and
LODES put 676 job holders there. Both fed Homes bubbles (everyday outings, school and university
homes, medical and airport origins, the commute home end).

## What changed

- `pipeline/group_quarters.py` (new): the 2020 redistricting file (PL 94-171) table P5, group
  quarters population by major type per block, from each state's summary file on www2.census.gov
  (the Census API answered "Missing Key" to keyless requests on 2026-10-13). It keeps a small
  per-state block table, `data/raw/pl2020_p5_<fips>.csv.gz` (P1_001N and P5_001N-P5_010N). Rules:
  - `remove`: a block's `pop` = census population - institutional group quarters (P5_003N adult
    correctional, P5_004N juvenile, P5_005N nursing/skilled nursing, P5_006N other institutional;
    their sum equals P5_002N, asserted). `pop_census` and `gq_inst` are kept beside it. TIGER
    POP20 equals P1_001N on every block (asserted).
  - `cap_job_holders`: on a block with any institutional group quarters, LODES RAC job holders
    are capped at the residents left (`rac_lodes` keeps LODES's figure).
  - `apply <city>`: the same on a finished pack, in place. `pop` and `commute_home` are re-spread
    from the block table exactly as `build_city.py` spreads them (the old figures are re-spread
    first and must equal the pack's arrays bit for bit, which they did in all nine), a cell left
    with no people and no jobs is dropped from every per-cell array (as a build drops it), then
    `enrich_schools`, `enrich_universities` and the gravity (`pack_gravity`) run again. Every other
    array is unchanged.
- `build_city.py`: `blocks_for_state` returns the population less institutions (so `intercity.py`'s
  Mercer blocks get it too), `main` caps job holders after the RAC merge; the pack's sources name
  P5. The county population check still compares the census figure.
- `intercity.py` rerun: the market's sites take the new cell populations (and Mercer's).
- Docs: SPEC 4, docs/demand.md 4.1, docs/demand-worldwide.md (Homes), docs/adding-a-city.md,
  DECISIONS 2026-10-13.
