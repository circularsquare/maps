# T-3750 Renamed station shows its old name at some zooms

Player report (Twitter, 2026-11-19): "C St Northwest" renamed "Lincoln Memorial-GWU", "Kalorama Rd Northwest"
renamed "Adams Morgan", "their names don't agree at different zooms". Screenshot: close in a narrow white floor
with a grey rim and "C St Northwest" to its right; farther out "Lincoln...".

## Cause (two)

Reproduced in a new Washington game (two runs 40 m apart near Foggy Bottom, stations placed with the tool, renames
through the panel and the Stations tab; probes in the scratch folder `stnames/scen.js`).

1. **Station buildings kept a copy of a station's name.** `add_building` with no name stored the first typed or
   constructed member's name at that moment. A later rename of the station or complex never reached it. The
   building's name replaces its stations' labels from zoom 13 in (`stationLabels.placeBuildings`, beside the floor
   when it doesn't fit inside), so close in showed the old name and below 13 the station label showed the new one.
   This is the screenshot exactly (floor and label to its right). Before: building "H St Northwest" at z17 and z14,
   "Lincoln Memorial-GWU" at z12.5.
2. **A typed name and an untyped one in one complex.** T-3288 let untyped stations follow only the oldest
   *untyped* station, and a rename of one station opened alone (or a Stations tab row with "Show stations
   separately", or a station named before a neighbour joined) typed only that one. The complex then had two names:
   the Stations tab row took the typed one (`leadOf`), the map's far label took whichever won the collision (more
   lines, then save order), the panel the clicked station's. Before, "single": list "Adams Morgan", map "H St
   Northwest" at every zoom.

## Fix

- One rule for the complex's name (`game/complexLead.ts` `nameSource`): the oldest typed name, else the oldest
  station's. `StateRows.foldNames` applies it to every untyped station and keeps it per station
  (`complexName`); the complex-view rename, the cycle button and the Stations tab row rename go through
  `complexRename` (the name source keeps its typed flag as it was).
- Station buildings store only a name the player gave (empty = none; `add_building` with "" stores ""; a rename to
  blank clears it; `building_named`). The worker's state gives an unnamed building its complex's name, part before
  any slash (`shownBuildings`, members found by the app's own rule, kept while rows and outlines stay the same).
  `building_name` still answers the track model's default for Rust callers.
- Saves: LEVEL 23 -> 24 (a new meaning of building names; master took 23 for LPD1 first, and its saves still copy names). Level 23 and older load with every building unnamed
  (`OLD_BUILDING_NAMES`), since copies and typed names can't be told apart (a heuristic matching a member's own
  name missed the reporter's case: the station whose name was copied had been renamed). A typed building name in
  an old save is lost; it then shows the complex's name.

- Typing a station's own (hidden) name over the complex's name it shows now marks it typed
  (`type_station_name`, sent by the worker when the name equals the stored one and the station is following):
  before, the same name sent back was taken as no typing, so a station could never be given back its own name.

Decision recorded in DECISIONS 2026-11-19 (reverses T-3288's "a single-station rename names that station alone").

## Checked

After the fix, each path shows one name in the stations' rows, panel title, Stations tab, building, and map
labels at z17, z14 and z12.5: rename alone then a neighbour joins; complex rename with a building; a station opened
alone and renamed; Stations tab row (joined and separate); complex view with a typed station clicked; the cycle
button with a building; an untyped neighbour with its own name. Same after export and import of the save. A save
written before the change (building holding "H St Northwest", stations renamed) opens showing
"Lincoln Memorial-GWU" everywhere. A typed building name ("Grand Hall") stays through a station rename.
