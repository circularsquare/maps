# T-3602 Use default in place of Clear default

Branch tw/usedefault (tree `.tw-trees/usedefault`). Not landed.

## What changed
- Schedule panel default row (`ui/inspector/schedule.tsx`, `DefaultHeadways`): Clear default is gone. A button "Use default" sits beside "Set as default", same class and height (26 px); it is disabled (never hidden) when the kind has no default or the line's headways already equal it.
- `game/newHeadway.ts`: `clearDefaultHeadway` removed; `applyDefaultHeadway(id)` sends the kind's default through `setHeadways` (new, `game/world.ts`), which calls `queueHeadway`, the path every headway edit takes (one `setHeadway` edit, one undo step; a line on counts is switched to Headway by it).
- Strings: `schedule.defaultReset` ("Clear default") dropped, `schedule.defaultUse` ("Use default") added in en.json and context.json. Other languages still carry `defaultReset` (orphan faults in i18n.mjs, cleared by the next translation round).
- The default row only appears in the schedule panel (the timetables window); the line panel has no such row.
- Check `checks/t3543-default-headways.mjs` updated: Use default off with no default and when matching, on for a line on counts and for a line with other headways, gives [300,480,900], one undo each way.
