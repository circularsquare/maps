# T-144: station rendering

Anita wants stations rendered as boxes along the track, including placement ghosts. Demand sizing should be an explicit special mode with much larger, translucent circles rather than small indistinguishable station circles. Preserve understandable picking and selected/blueprint/constructed states.

## Implemented 2026-10-11

Station symbols are now white boxes with dark outlines, aligned to a track tangent. Physical length follows platform length; screen minimum remains readable at regional zooms. For an ordinary station, minimum total length/width are 9.36/3.38 CSS px at zoom 9, 17.28/6.24 at zoom 12, 25.2/9.1 at zoom 15, interpolated between and clamped outside. Transfer stations use larger minima (12.6/4.55, 22.32/8.06, 32.4/11.7). Actual projected platform length can exceed this minimum at any zoom. Width still spans the drawn line bundle. Selected boxes enlarge by 1.35; blueprint opacity remains 0.6. Boxes stay straight along the nearest track tangent, including at curved tracks; this is a symbol, not a physical platform footprint or complex.

Geometry is built with the existing clock-worker network buffers. Junctions choose the connected edge with the most distinct lines, then lowest edge id to break ties deterministically. The half-platform vector uses the station latitude's Mercator scale. Placement ghosts use the configured platform length and the same minimum dimensions, aligned to the snapped track; changing length updates the ghost.

Station demand circles is now an explicit analytical display option (off for fresh settings; remembered boolean preserved). It draws blue translucent circles behind platform boxes, with 22% fill and 48% edge alpha. Area is proportional to daily boardings plus alightings up to 150,000; capped radii are 18/40/56 CSS px at zoom 9/12/15. Zero/no demand and blueprint stations have no circle. Nearby platforms no longer suppress each other's circle sizes; this replaces T-094's crowding shrink. This remains station demand, not combined station complexes.

Select, delete and add-line-stop picking use the platform box geometry, including its physical length, screen width, selection scale and drawing order. Halos do not enlarge the hit target. Trains retain priority over stations. All changes are read-only rendering/UI, with one extra station-axis buffer transferred from the clock worker; no simulation, save or demand worker changes.
