## What changed

  in data/work (solved packs in order, packs, time, home packs), `data/work/pair_files.index.json`,
  an entry kept while the file's size and modified time hold. `intercity.joint_files` and
  `cross_everyday.unit_files` list from it.
- `market_zones.Groups(reg, only)`: with named ids, parses only the joint files holding a pair from a
  named pack that no newer file replaces, and the everyday files that are the newest draw of some
  pack and hold a pair from a named pack; keeps only the named packs' pairs. `airports_by_zone(reg,
  only)`: the direct-flight lists were rebuilt per (zone, other zone) pair (8M set unions, 16 s);
  now once per airport, and only for the named zones. `world_run.group_files` lists from the index too.
- `market_rows.inputs.json`'s `code` is now a sha1 of the sim crate's sources (`simbin.source_sha`), not
  of the market_pack binary: every run's sim copy builds its own binary with other bytes, so the
  first market step of each run redid every row (223 s against 12 s, measured on hoc).
- `pair_files.py unused [--move]`: the files that give no registered pack or plan row a pair.
- T-1986 in `world_run.py`: `heal_market` reads every registered market pack (no 400 km radius);
  `ROW_CACHES` has `data/terrain/{id}.terrain`; `check_port` runs in `go()` before anything else
  (and before each gate, as before).

`checks/runner_fixes.py` (about a minute, nothing live written): 5 of 5 PASS: `Groups` for named
packs as for every pack and a rewritten file read again (made-up files); `clear_row_caches` clears
`zzq.terrain` and keeps lookalikes (a temp root); with Okinawa's `oka` taken out of a copy of the
registry, `heal_market` picks Kagoshima's `kgs`, 659 km away (the 400 km rule missed it); `go()` on
