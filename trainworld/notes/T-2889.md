# T-2889: Portuguese (pt)

Language code `pt`, as `es` is plain (one neutral Spanish): Intl's plain `pt` is Brazilian Portuguese, and
Portuguese browsers (`pt-PT`) also map to `pt`. Write Brazilian Portuguese (pt-BR spelling after the 1990 accord:
"ação", "ótimo", "equipe", no "facto"), the much larger player population; where Portugal differs
(comboio/trem, autocarro/ônibus, ecrã/tela), use the Brazilian word.

## Voice

- Full sentences address the player as `você` in the imperative ("Escolha uma cidade", "Construa uma linha"),
  or with no pronoun. Never `tu`, never `vós`, never the formal "o senhor".
- Buttons, labels and toggles: the infinitive ("Construir", "Excluir linha", "Mostrar cores das linhas"), the way
  Brazilian software words them. Tool names are infinitives or plain nouns.
- Plain, short, a little cute, like the English. No "gerenciar", "otimizar", "experiência" as filler.
- Numbers are formatted in code (Intl pt: 1.234,5 and compact "763 mil", "1,2 mi"). Percent has no space (85%).
- Periods only on full sentences; phrases, labels and hovers end bare.
- Kept as written: km, m, mi, ft, km/h, mph, m2 and the money symbol.
