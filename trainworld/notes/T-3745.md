# T-3745: hide flat junction marks no line uses

Anita, 2026-11-19: a flat junction or merge no line uses causes no capacity impact, so hide it?

## Answer from the code

Right, with one refinement: what costs capacity is a pair of moves that cross, both run by lines.

- Junction (`capacity::build_nodes`): a resource is made for a move only if some move a line runs crosses it
  (`at_node.iter().any(crosses)`). No line, one line on one move, or lines on moves that only merge or diverge:
  no resource, no wait, no capacity dot. Merges and diverges never count as crossings.
- One line using both branches: its two directions are two different moves and can cross each other (a Y has one
  crossing pair). So that line alone can load the junction. The mark stays.
- A line straight through the main track without taking the branch: only the main-line moves, none cross. No cost.
  A second line on the branch is what brings the crossing pair.
- Flat crossing (`build_crossings`): the sim already holds nothing unless a line is on the other edge too
  (T-1805); both edges need a line. A line over both edges (a loop crossing itself) counts. A tram crossing a
  train route: the tram's resource is loaded by train passes, so a line on each edge is still needed.
- Freight: none in the game. Buses: skipped by both `build_nodes`/`build_crossings` and `move_conflicts`.
- Unused or blueprint track: no running line, nothing built.
- `spacing.rs` (lines sharing track or a flat junction do not leave together) only acts between lines.

## Change

- `capacity::conflict_nodes` (nodes where `move_conflicts` finds a pair) and `capacity::edges_in_use` (edges of ok,
  non-bus lines).
- `nodes_info` flag 2 (the badge) now needs a conflict pair on built junctions; `crossings_info` drops a built flat
  crossing without a line on both edges. Bad crossings (red X), blueprint and unbuilt marks, and the drawing
  preview are unchanged: they plan track before any line exists.
- `line_marks` (line inspector rows, Marey rules): a junction only where one of the line's own moves is in a
  crossing pair (any run, so the other direction counts); a crossing only with a line on its other edge.
- Uses "ok" lines, not "running", like the train guard: the mark returns when a line is drawn over it, even
  before its track is built or trains are bought.
- Docs: track-and-service 6.2, ui-map marks, ui-inspectors line panel.
