# T-4046 click again cycles through bus routes too

Change: app/src/map/pick.ts. The cycle block in `pick` became `cycleShared`; it ranks train/tram lines as before, then appends bus/BRT/ferry routes under the pointer (`BusLayer.linesAt`, i = -1, no stroke). The track step only exists when a rail line is there. `pick` calls it from the rail branch (as before) and from the bus-only branch (after the stop and track checks). Rail-only behaviour is the same code path with the same order.

Checked with play.mjs on a fresh New York game (Bed-Stuy, straight tram track with Snap off):
- Tram T + Bus 1 + Bus 2 on one stretch: clicks go Tram T, Bus 2, Bus 1, track, Tram T, ... each opens its panel.
- Two bus routes alone: 1, 0, 1, 0 (wraps, no track).
- Two train lines on shared track: A, B, track, A, B (unchanged).
Picture: artifacts/trainworld/t4046/bus-under-tram.png (Bus 2 selected from under the tram, panel open).
No hover hint for the cycle exists in the game, so no string changed. No wiki page states the rule. Docs: ui-map.md "Picking". Changelog: routecycle-1.
