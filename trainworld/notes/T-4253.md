# T-4253 — A line's fare multiple up to 10x

Anita (2026-11-25): raise per-line fare multiple maximum to 10x, rejecting a multiple if the base fare times it is over US$1,000.

## What changed and why

- **`app/src/game/fareCurve.ts`**: raised `LINE_FARE_MAX` from `3` to `10`. Every clamp (`tidyLineFare`, `LineFare`'s stepper, `loadFares`, `setLineFare`) already reads `LINE_FARE_MAX`. `FARE_MAX` (`1000`, US$1,000) is reused as the base-fare-times-multiple cap.
- **`app/src/game/fareDefault.ts`**: added `baseFareIn(f, city)` returning the exact base fare in US$ charged in a zone (or its country when `byCity` is off, using `roundedDefault` when untouched, matching `MoneyTab.tsx`'s `chargedAt`).
- **`app/src/ui/inspector/LineMoney.tsx` & `app/src/ui/style.css`**:
  - Computes the line's highest base fare in US$ across its stops (checking both `stationsById` and `busStopsById`, so rail, tram, bus and ferry lines all resolve their country/city).
  - Refuses any increase (`next > mul`) where `baseUsd * next > FARE_MAX + 1e-6`: returns `false` so `Stepper` shakes and plays the refusal knock, and shows a short red alert (`Base fare can be at most {max}`, formatted via `moneyWhole(FARE_MAX)` in the player's currency) under the row for 5 seconds (cleared on line switch or valid edit).
  - Lowering a multiple that is already over the cap (from an old save or a later base-fare increase) is still allowed, including stepping down and clicking Back to 1.00x.
- **`app/src/workers/clockFares.ts`**: `setLineFare` enforces the same `v > cur && base * v > FARE_MAX + 1e-6` check using `lineFirstStops` and `baseFareIn`. `loadFares` only applies `tidyLineFare(v)` (0-10) so old saves keep their multiples.
- **`sim/`**: no changes needed; `check_fare_mul` only checks `v.is_finite() && *v >= 0.0`, with no upper bound.
- **`app/src/i18n/messages/en.json` & `context.json`**: added `"lineMoney.fareCap": "Base fare can be at most {max}"`.
- **Docs & wiki**: updated `SPEC.md`, `docs/track-and-service.md`, `docs/demand-worldwide.md`, `docs/demand-plain.md`, `wiki/fares.md`, and `wiki/read/fares.md`.
- **`checks/t3567-line-fare.mjs`**: updated the cap assertion from `5 -> 3.00x` to `15 -> 10.00x`, reload check to `10.00x`, and added the US$1,000 refusal check (plus a `--quick` mode on a new NY game).
