# T-4068 Shift+click deletes without asking

Her 11-23 note: some players want to delete without the question; Shift+click, said in the hover in grey.

## Every delete that asks (all go through `ask` in game/ui.ts, shown by ui/ToolNotes.tsx)

Covered (Shift+click skips the question, the edit is the same one a Yes sends, so undo works as after a confirmed delete):

| Control | Code | Hover line |
|---|---|---|
| Delete tool, click on track / station / flyover / bus line / station building on the map | map/toolDelete.ts `deleteClick` -> `removeThing(h, shift)` | on the tool's button: "Shift+click to delete without asking" |
| Remove station / Remove port (station panel) | StationInspector `remove` | "Shift+click to remove without asking" |
| Remove building (station panel) | StationInspector | same |
| Remove in the selection bar (blueprint pick, also constructed track) | ui/Blueprint.tsx -> `removePicked(shift)` | second line of its hover |
| Delete line (bus line panel; asks only for a constructed bus route) | BusInspector `remove` | "Shift+click to delete without asking" |
| Remove fare area (Advanced fares) | AdvancedFares `remove` | second line of its hover |

The big-delete question (a long stretch of track) and the "this changes lines X, Y" lists are skipped as well: Shift is the player saying yes to all of it.

Left asking:
- Saved games: delete game, delete version (typed station count), account delete, feedback delete: not undoable (storage or server).
- Not deletes: Guide close, side switch, new-game switch, fare "use simple curve", weekend share for all, fare zone move, one-way and rebuild questions, schedule periods, leaving a viewed network.
- Train line delete (Lines tab / line panel) never asks (T-2919), so no line.
- Delete / Backspace keys and the selection bar's key still ask: a key press has no Shift click to read, and Shift+Delete is a different gesture on Windows.
- Touch: no Shift, so the grey line is dropped on phones and tablets (`mobileDevice()`), and the touch delete path passes shift false.

## Hover line

`tipMuted(text)` / `tipMutedLine(text)` in ui/tip.ts: a hover line starting with control char 8 is drawn in `.tip-muted` (opacity 0.7, 2 px above), as the key hints are. Messages `common.shiftDelete` and `common.shiftRemove` (en.json and context.json only; other languages are not mine). The delete tool's hover gets it through `toolEntry`'s new `note` argument.

## Run

A plain click still shows the question. Screenshot of the delete tool's hover: artifacts/trainworld/review/shiftdel.png. Typecheck passes. No sim change, no smoke.
