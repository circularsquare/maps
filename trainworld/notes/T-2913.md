## 2. History or fresh

- Trainworld commits: 1,208 of 1,425 in maps, all by "anita chen", first on 2026-10-09 (one month). Maps `.git` is 2.8 GB packed.
- `git filter-repo --subdirectory-filter trainworld` keeps all of it, rewrites paths, drops other maps' history. Rough result 110-150 MB packed. About 113 MB is blobs touching trainworld/ even compressed: `market-rows.json` alone is 53 versions, about 12 MB compressed, and `world_plan.json` repeats too. `notes/` history is 6.4 MB.
- What the history holds that argues against carrying it: every notes/ file, TODO.md, handoff, and commit messages written for her own use, with player quotes; deleted files stay reachable (the AWS pages, feedback tooling). A filter-path pass could drop notes/, TODO, artifacts, tools/aws, but each removal rewrites hashes anyway and the commit messages (one sentence, task id) would cite `T-nnnn` ids pointing at notes no one can read.
- For history: contributors can see why things are as they are; blame works; 1,208 small commits is a nice story.
- Recommendation: fresh. One first commit of the lean tree (the public repo starts at v0.1), and keep the full history private in maps. Reasons: a clean tree cannot leak by deletion, nothing to scrub twice, repo is 15-20 MB not 150, task ids in messages mean nothing outside. If she wants history later: filter-repo with `--path` allowlist on app, sim, pipeline, docs, checks, plus `--replace-message`; about a day with checking. The other agent's secrets review decides whether even that is safe.

## 3. Can a stranger run it

- What they get from `git clone` + `npm install --prefix app` + Rust (stable + wasm32 target + wasm-pack) + `npm run wasm --prefix app` + `npm run dev --prefix app`: the page and a map (OpenFreeMap tiles are free and keyless), but no game: city packs are not in git (gitignored data/packs, 5.8 GB locally). `app/src/game/registry.json` names the cities; each needs `.json`, `.bin`, `.boundary.geojson`, `.market.json` etc., plus terrain, `world.water`, `market-drives.bin`, `outlines.json`.
- Data source for them: the published R2 copy, `https://data.anita.garden/trainworld/<version>/` (about 1 GB, 4,000 files, versioned and immutable). `dataBase.ts` only reads it when index.html has a `tw-data` meta. I checked R2: it answers a localhost origin with no `Access-Control-Allow-Origin` (CORS allows anita.garden only, notes/T-924.md), so a stranger's dev server cannot read it today. Two ways: add localhost origins to the bucket CORS (R2 egress is free, reads are class B ops at about $0.36 per million; a full game load is a few hundred requests and 50-200 MB, so even 1,000 strangers is cheap, but crawlers and a viral day are unmetered), or a Vite proxy to R2 (no CORS change, her Cloudflare still serves). Pick the proxy: small change in `vite.config.ts`, plus a `TW_DATA` env var.
- Cannot be rebuilt without big raw data: the packs (GHSL, OSM extracts, census files, 28 GB raw plus 26 GB work, hours to days, AWS used for builds), real-rail packs (need noritetsu's extracts). Some countries use gated sources (`docs/data-register.md` G marks). Strangers should treat the pipeline as read-only reference.
- Smallest README: prerequisites (Node 22+, Rust, wasm-pack) -> `npm install --prefix app` -> `npm run wasm --prefix app` -> `TW_DATA=https://data.anita.garden/trainworld/<version>/ npm run dev --prefix app` -> open localhost. Needs: the proxy, a pinned data version (the current one is 2026-11-09b; Anita deletes old versions, so the README version rots: use a `latest.json` pointer file on R2), the Rust toolchain steps tested on a clean machine (CLAUDE.md says shells lacked cargo on PATH). Not tested here.

## 4. Licences

Code (her choice):
- MIT: anyone may copy, change, rehost and sell it, even closed, as long as her copyright line stays. Somebody can put up "their" trainworld with ads. Easiest, most contributors.
- GPL-3: forks may be shared or sold, but their source must be shared under GPL too. Hosting a modified copy without sharing is allowed (a website is not "distribution").
- AGPL-3: GPL, plus anyone running a modified copy on a website must offer its source. Closest to "you can use it but a closed rehost is not allowed", and usual for games and web apps. Contributions are fine; some companies refuse to touch AGPL.
- Source-available, no reuse (for example PolyForm Noncommercial, or "all rights reserved, read-only"): not open source by the common definition; people can read and send PRs but not run a competing site or sell it. Some contributors balk, and GitHub still lets forks exist on GitHub.
- Her art, sounds and name: code licence does not need to cover the name "trainsworld"; say so in a line.

Data and dependencies:
- OSM (ODbL): the packs are a derived database; credits already say ODbL and the packs are fetchable. Any rehost of the packs must keep the credit and share-alike. Not a conflict with MIT or AGPL on the code (the game is a produced work), but the repo must say that data files are ODbL and not the code licence.
- research/release-legal.md (T-1824) lists open items that matter more once public: 9 outlines with EuroGeographics NUTS fills (non-commercial, non-transferable: a fork selling the data would break it) and the unread `nocar` layer (about 15 sources, some unlicensed) in every pack, T-925/T-926. TfL needs "Powered by TfL Open Data" (P1 there, still unfixed as of that note); MTA, Network Rail, IDFM, ASPECT credits missing. These bind the packs, not the repo, but a public repo draws more looking. Do them first.
- Wikidata (CC0), GHSL (EU reuse, credit), Kontur (CC BY), World Bank (CC BY): credit only, already in `Credits.tsx`. GEDTM30: not found named in the credits file I read; check (CC BY 4.0 as I recall, unverified).
- MapLibre, pmtiles (BSD-3), Preact, signals (MIT), earcut (ISC): keep notices; no conflict with any choice. Rust crates: unaudited (`cargo about`).
- OpenFreeMap tiles: free, "may stop any time", credit "OpenFreeMap © OpenMapTiles Data from OpenStreetMap" already shown. A stranger's dev server hits them too: fine, but load is theirs.
- Fonts (Zen Maru Gothic, Noto Sans, Nunito): SIL OFL, texts shipped in `public/fonts/`. Zen Maru is still loaded from Google Fonts at runtime (T-1824 privacy item).
- Sounds: Pixabay licence forbids giving the sound away on its own: a public repo with the files in is "giving it away". Either ship them with a NOTICE as part of the game (probably fine) or leave out and document. `track.wav` unused, unclear source: drop.

## 5. Ongoing cost and layout

How she works: orchestrator in maps commits `trainworld/` paths to master, several agents edit shared files, worktrees land by fast-forward, `.tw-snap` builds 8800 from a commit. PRs need an owner to review, test (smoke is 3 min, needs data) and merge, and agents' edits keep landing under them. Roughly a PR review each time costs her or an agent 15-30 min.

- Option A, move the game out of maps: breaks everything that assumes the maps root (serve.py 8800, cores.py ledger, `.claude/` hooks, `.tw-snap`, `agent-tree.mjs`, venv, `../artifacts`, noritetsu data, `deploy.py` paths, junctions) and the orchestrator/handoff setup. Two weeks of rewiring and a risk to the one active project. Not recommended.
- Option B, one-way mirror: a script (a `tools/publish-oss.py`) copies the allowlist of paths to a separate checkout and makes a commit "sync to <maps commit>" when she says. Contributors PR against the public repo; accepted PRs are applied to maps by an agent (patch apply into `trainworld/`, prefix paths) and show up in the next sync. Cost: about 1-2 days to build the allowlist + sync + README + CONTRIBUTING, then minutes per sync. Recommended, and fresh history fits it.
- Later, if outside PRs become frequent, flip so the public repo is the source (Option A) as a separate project.
