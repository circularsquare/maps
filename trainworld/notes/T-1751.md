# T-1751: real-network saves' service (2026-10-28)

T-1750's fixes 1 and 2, in the seven saves a sandbox starts from (`data/packs/real/{nyc,lon,par,tyo,seo,tor,sdj}.save`).

## What was done

1. **Flat crossings: imported edges are marked separated** (`EdgeData.sep`, `edge_sep`, bit 7 of the edge flags in the
   save; `Network::find_crossings` skips a pair when both edges carry it, a line's own tangled hop included).
   `realsave` sets it on every edge it writes. Not levels per hop: a hop is about 1 km and a ramp is 200 m a level, so
   a line changing level inside hops would sit on ramps, and a crossing over a ramp is invalid (`Bad`). Six levels cannot
   separate central Tokyo's lines anyway (T-1750). The lines keep their one level each, so the bridge and tunnel looks
   are unchanged. The edit code carries the flag (a split, a join, a stub); track the player draws has it off and crosses
   imported track by the usual rule. Test: `two_separated_edges_make_no_crossing_and_the_flag_is_saved`.
   Native result: every save has 0 crossings (before: Tokyo 128 flat, London 791, Paris and Toronto a handful).
2. **Tokyo's peaks** (`pipeline/calib_tyo.py`): TIERS top 24 to 28; `REAL_PEAK` for 12 lines named in T-1750 (Chuo 28,
   Hibiya 27 from MLIT; Yamanote 25, Keihin-Tohoku 26, Sobu local 24, Tozai 27, Marunouchi 26, Ginza 28 (real about 30,
   held at what a section allows), Oedo 20, Den-en-toshi 27, Toyoko 24, Odakyu 28 from the timetables, +-15%). Trips are
   now timed to pass the count point in their schedule hour: before, a line's departures in the peak hours reached Tokyo
   station later, so the peak counted at the count point was diluted (Chuo asked 16.6 for a tier of 24).
3. All seven regenerated: `calib_tyo.py trips`, `realnet.py net tyo`, `geom tyo`, `route tyo` (staged), then
   `realsave --city X --out stage`, `gamesave X`, `ship` for each. This is T-1183's regeneration. `ship` now writes a new
   file: data/frozen/ holds hard links to the saves, and the first run rewrote them in place (restored from the backup
   at once; the frozen stamps are as they were).
4. The wasm was rebuilt (`npm run wasm`).

smoke's real save is `trainworld/T-007-real-nyc.save`, a separate file (109 lines) that no step here touches, so its
12,483,326 rail trips do not move.
