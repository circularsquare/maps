# T-077: remove unused debug refusal export

The app uses `issue_kinds()` for player-facing refusals. `TrackApi.issues()` existed only for
debug formatting and native assertion messages. Moved it into a test-only implementation:
native failures retain detailed diagnostics, production bindings no longer export the method.

Combined library tests: 62 passed, 3 ignored benchmarks. Track WASM rebuild passes; generated
TypeScript no longer exposes `issues()`. Optimised track module shrank from 473133 to 472506
bytes (627 bytes), smaller than the old estimate of a few kB. No player behavior changes.
