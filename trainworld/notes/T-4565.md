# T-4565 Crossing track at another height fails

Request group g191 (two Japanese reports, 11-26 and 11-27; text in notes/board-reports.jsonl ids 1795716802-262a2c39 and 1795755139-1f66826d).

1. "Pressing the crossing button when laying new track does not make a grade-separated crossing." The only such button on the track bar is the ramp switch (toolBar.ramp, "Ramp over track you cross", on by default; ToolBar.tsx -> autoRamp -> RouteAsk.ramp -> set_route_ramp).
2. "Heights differ by 1 but I cannot cross." (with a picture)

## Finding: rule working as designed, no code change

Report 2 is the case T-4379 already analysed (notes/T-4379.md): find_crossings (sim/src/track/net/derive.rs) marks a crossing bad when the height difference at the crossing point is under one level (8 m), so a track still climbing its ramp there is refused even though its ends are a level apart. T-4379 reworded the refusal and the red mark (landed 11-27, after both reports, which were made on version mwxs0pfz). Nothing left to fix; the rule is the 160 m per level ramp floor.

Report 1: one game run on this tree (scratchpad crossfix/cross.mjs, Vite 6162), double main E-W then double cross track N-S on the NYC centre, through the edit API:
- ramp on, main at level 0: accepted, 0 flat crossings.
- ramp off, main at level 0: refused with Crossing (the flat crossing, as designed).
- ramp on, main at level 1, cross track from level 0: accepted, 0 flat crossings.
- ramp on, main at level 1 (second run, other place): accepted, 0 flat crossings.
So the button does its work in the plain cases. Where it cannot (a crossing too near a track end, a station or another ramp, so there is no 160 m per level of straight room; or the other track is itself on a ramp at the crossing) the planner falls back to the flat crossing and the player sees the Crossing refusal, which is the T-4379 text now. The report gives no save or picture, so which of these she hit is unknown.

T-4335 M2 (monorail: no flat crossing with other track) has not landed on this tree, so it is not the cause.

No change to what players can build. If she wants the refusal to say the switch could not find room, that is a text change for her to call.
