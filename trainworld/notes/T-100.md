# T-100: Build menu and construction breakdown

Done 2026-10-10, requested by Anita. Blueprint controls belong together with the build tools;
remove Select's button to make room; explain what the blueprint costs.

## Result

- Build has a fixed footer with the quote, undo, redo and Construct blueprints. Its settings and
  expandable breakdown scroll above it. The dock divider still resizes the whole pane.
- Only Track, Station and Delete have buttons. Existing toggle and Esc behavior still returns
  to selection, and the number keys remain unchanged.
- The map's Toolbar now holds hints, questions and notices only. Its construction bar is gone.
- Track rows group exact pricing intervals by level, single/double track, land/water and ramps;
  each gives length and cost. Stations, junction switches, flyovers and flat crossings have
  separate groups and counts. Ramps display the level whose multiplier prices them.
- New train cars are included in the total after spare cars. A native reversible trial of
  Construct all derives the actual fleet needed after all lines start. Summing planned train
  estimates was insufficient: two lines sharing a short track needed another $50M after their
  capacity delay was applied. Quoting never spends, changes the save or touches undo history.

`cost.rs::track_cost_parts` serves both track pricing and the explanation. The network groups
unbuilt costs, matching `total_cost - built_cost`, including junctions whose third port is not
yet built and crossings with either edge unbuilt. `TrackApi.blueprint_cost_items` adds the
fleet preview. Seven-number rows travel in the clock state and are converted to dollar amounts
for `WorldView.money.blueprintItems`; the main thread only renders them.

## Checks

- Native track suite: 39 passed, one pre-existing ignored benchmark. Tests cover mixed ramps,
  water and single track; partial junction/flyover accounting; quote vs actual charge; repeated
  quotes preserving the save, cash and undo; two lines starting together.
- Track WASM rebuilt with wasm-pack (six build jobs). Type checking and Vite production build
  pass. No demand code changed; its existing module is reused.
- Browser at Anita's screenshot dimensions, 688 x 953: three tools, no Select, no construction
  buttons on the map; active tool toggle and Esc work; undo/redo work; Build has no horizontal
  overflow; resizable panel and fixed construction footer checked visually.
- Three 1 km tracks (ground double, tunnel single, viaduct double), two stations and two planned
  lines: infrastructure $178.40M plus 60 cars $150M; displayed quote $328.40M equals the actual
  charge. Breakdown clears after construction, Construct disables, and it is absent on Lines.
  No page errors. Test games use fresh isolated browser contexts, preserving Anita's autosave.
