# T-3874 remove the decided-change perfOff switches

Removed eleven `?perfOff` switches that each switched a decided change back off: heldLocal (T-3616), realZoom
(T-2748), keepFigures (T-2793), settledHold (T-2773), strays (T-2579), allSums (T-2596), cacheFocus (T-2574),
refineAside (T-2605), regional (T-3503), localKeep and localSkip (T-3512). Each switch and its "off" branch is gone;
the "on" behaviour is unchanged.

Where: demandClient.ts (most), demand.worker.ts and demandProtocol.ts (the `allSums`, `localAll`, `alwaysLocal`
message fields and the worker's `allSums` variable went with their switches), clockClient.ts and today.ts
(settledHold), map/realNetwork.ts (realZoom). perfFlags.ts: names and comment lines dropped, `fareHold` added to the
comment list (it was missing). Unused `perfOff` imports removed in clockClient, today, realNetwork.

Kept: bays and fareHold (t2980 and t3303 pass them), msaa, grow, farChunks, overviewCache, singleWait.

Checks: nothing in checks/ or tools/ passed any of the eleven by default. Two checks (t2773-pending-dip,
t2793-figure-dips) mentioned `TW_PERFOFF=settledHold` / `keepFigures` in a header comment as an optional "before" run;
those comment lines now say TW_PERFOFF takes switches still in perfFlags.ts, so that before-run is gone.
