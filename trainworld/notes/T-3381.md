# T-3381: notice shows the generated name (agent bugs2, 2026-11-16)

The corner notice in the report is "{name} added as a blueprint station." (tools.blueprintStation), said by the Station tool
(map/tools.ts `stationClick`) with the name made for the click. A station placed beside another joins its complex at once and
shows the complex's name (T-3288 `foldNames`), so the notice named something the player then never saw.
Fix: the notice names the station as the world shows it (`shownNameAt`: the station nearest the spot, `stationNames`).
The construct notice (StationInspector `construct`, "{name} constructed for {price}.") had the same slip and reads the shown name too.
Seen in a browser (artifacts/trainworld/t3381-notice.png): Alpha Street built, a blueprint station placed 50 m north with the Station
tool; the notice reads "Alpha Street added as a blueprint station." (before, the made-up name such as "6th Av").
