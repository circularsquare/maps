# T-3527 Help list in the controls panel

The help panel (`ui/HelpPanel.tsx`, docs/ui-panels.md "Help"): common questions above the controls, the plain "?"
button, F1. Seven questions on desktop, eight on a phone (the intercity one is phones only). Shots:
artifacts/trainworld/t3527_more_desktop_light.png (best), _more_desktop_dark, _more_phone_light, _more_phone_dark.

## Where the questions came from

Anita's four (2026-11-17), then three she picked (2026-11-17) from player reports of 2026-11-03 to 11-17
(`feedback.py --hours 336`): edit or delete built track (2 reports: 18669327, 538522b0), four tracks using only two
(2: 66a46515, 900c634c), express line (1: 385d33db), and the game recalculating after every piece (3: 44ac6428,
b68f53c7, 1d19ecd9). That last one points to "Recalculate trips while paused", which is on by default, so pausing
alone does not stop it; she wanted a setting entry only when the default doesn't already fix the problem.

Not added: hiding lines (she said no); "make single track double" (4 reports: 73ff6bb0, 10206e23, 6489394d,
d8ea96ca). All four ask to turn built single track into double, the Select tool's track count plus Rebuild; none is
about the single to double connection bugs. Three predate the track count in the Select bar (2026-11-12 and 13).
73ff6bb0 (2026-11-17) is about tram track. Left out as well: feature requests (weekend timetables, notification list,
directional quad track), known bugs (two single tracks into a double, single-track stations) and complaints about
too few inter-city trips (6 reports), which have no in-game answer.
