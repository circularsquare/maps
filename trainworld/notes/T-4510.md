# T-4510: Offset column behind a toggle, with weekend offsets

Her words: nudge individual trains (that is T-4511); keep the all-trains nudge, but the Offset column toggles with a shift-looking icon button, off by default; and why not separate weekend offsets.

## What was done
- Toggle: icon button (two opposite arrows, one set off the other, `Icon.shift`) in the "Set by" header of the schedule window, class `related-toggle` like the other header icon buttons, pressed state `on`. Kept in `display.scheduleOffsets` (saved per player with the other display settings), default off. Column header, cells and both `lineNudges` queries only run while on.
- Weekend offsets: weekend rows have their own stepper. Storage `Network::line_offset_rest` (offset) and `line_hold_rest` (held phase), read through `weekend_phase_of` over the phase the weekend would run otherwise. Weekday nudges no longer move weekends. `NudgeSet` has `weekend` and lost `rest`; `nudge_op`/`row_nudge`, wasm `nudge_row`/`line_nudges` take `weekend`.
- A line on its weekday pattern gets its own weekend phase only for held slots: `Service::lattice` no longer returns early for it (`any_offset_rest`), `set_cal` notes it, the boarding key hashes it.
- Placing weekends: `Network::placing_rest` makes `offset_at` read the weekend holds while `place_weekend` runs, so spacing keeps held weekend slots; `copy` overlays holds.
- Save: LOF1 extended in place (level stays 43): slot >= 5 is a weekend slot, one more value after the offset (phase bits). shonei-server `trainworld_savecheck.go` and test updated, committed there (3a8e65c), not pushed.
- Timed pairs (coordinator's T-4511 review, finding 4): a weekend-only hold flips `rest_on`, and `timing::retime` skips pairs whose lines differ in `rest_on`. A weekend nudge therefore holds every line timed with the anchor in any slot (`follow_pairs` over all slots), so both flip together. Test `a_nudge_moves_a_timed_pair_together` checks both `rest_on`, holds on both and the local's variants' stop holds unchanged. Left open: a pair formed later, with one line held on weekends and the other not (released separately), is averaged on weekends only.
