## The model

Three layers, each in one place.

1. **Which stations** (`perdir.rs`): `leg_heading(s)` is Some for a station on one-way single track (both pieces
   single and one way; a T-3332 one-track station on double is none). `leg_stop(s, stops)`: such a station is served
   once a round trip unless T-3348 pairs it (a station of its group serving the other way, one way only, that is no
   stop of the line). For a one-way station the group is only stations within `LEG_PAIR_M` = 50 m (complex or not);
   every other T-3348 case (one-track stations on double track) keeps the 300 m walk and the complex.
   `legs(stops)`: per stop, never an end, never on a loop.
2. **Serving** (`perdir.rs`, `service.rs`): `route_legs` (first in `Network::route_hops` and wasm `route_memo`) routes
   through the other stops; a one-way station neither run stops at (off both runs' track, or listed against the
   way its track runs, as a hand order can) is promoted to an ordinary stop, per station; if a promoted one is still
   served by neither, the whole line is routed through every stop (the old way). `match_run` replaces
   `match_stops` where a run's stops are matched to its path: the other stops must match; then each one-way station on the run's path, in the line's order, is stopped at where
   the match still holds (greedy, so a hand order against the track still serves the ones it can). One the run does
   not stop at keeps a place (the path node nearest it between its neighbours) and is a
   pass for that run (`Run::away`, `run.pass`; no dwell, phi -1 for demand, no departures board entry, half dot via
   `line_stop_ways`). `LineSvc::stop_node` gives the real station for it.
3. **Order** (`wasm/legs.rs`): an open line's stops = a skeleton (every non-one-way stop, in the line's order) plus a
   set of one-way stations. `flatten` routes the skeleton both ways and puts each one-way station in the gap where the
   run passing it does: run 0's in its order, then run 1's reversed. One-way stations past the skeleton's ends (or
   with fewer than two skeleton stops) go in by `best_slot` cost in station-id order, tried with the skeleton both
   ways round and the cheaper kept (oriented back to the skeleton's direction), so the line does not depend on which
   way round the clicks built the skeleton. Entry points: `best_insert` (`legs::insert`: a one-way click joins the
   set, any other goes into the skeleton by `best_slot`), `edited_stops` (set_line_with_trains, set_stops,
   add_stop, open_loop; `legs::ordered`, which straightens a skeleton that turns back first), `sort_stops`
   (`legs::sorted`), `stop_passed`, `drop_stop`/`end_line_at` (`dropped`: with one-way stations the path is found
   again rather than cut), and load (`legs::straighten_legs`). Lines ordered by hand skip the ordering but are still
   served once (routing is line-agnostic).

Dropping the partner rule (Anita deciding): `leg_stop` returns `self.leg_heading(s).is_some()`, one line; then
`LEG_PAIR_M` and the `leg` branch in `way_group` go unused (delete them), and `t3565_pair_only_side_by_side`'s first
half (the 40 m pair) changes to expect each served once. About 15 minutes with the suites.

## T-3595 (stage 2): turn back at any track end

Coordinator's decision (2026-11-17): a train may turn back at any track end, a station there or not.
`Network::turn_end(n)` (one constructed end; `bare_end` is now `turn_end` with no platform). Used in
`find_path_side`, wasm `reach_from` and world.rs `way_reroutes` (a broken line that turned back at a node the edit
built past, a station there included when the line does not stop at it, is routed again). `stop_reversals(path)`
(the reversals that must fall on a stop) now leaves out every reversal at a track end; whether a stop is there is read from the match: `build_run` stands a turnaround at a
stop whose node is a reversal (`path_reversals`), and every other reversal is a `Run::ends` free turn (no stop).
`check_one_track` and `way_stops` read all reversals for "turns at this stop". Chosen over a stops-aware
`stop_reversals(path, stops)` (tried first): with that, a route search turning at a dead-end terminus the line stops
at elsewhere gave a path the check refused.

Test changed by the rule: `stop_order_tests::an_order_with_no_route_names_its_hop` (S0's end was a station so no
train could turn there; now S0 - T is one-way single track toward T). `tests.rs a_line_reversing_at_a_bare_track_end_runs`:
a station put at the stub's end is now turned at without stopping (was: the line needs it as a stop).
`built_past_a_headshunt_to_a_station_leaves_the_line_running` (from extendfix) passes, not ignored, and goes on to
build past that station too (the line then turns at the newer end).

## What changed from the first attempt

- `match_run` keeps one-way stations greedily (was all-or-none), and `route_legs` promotes a station by whether a
  run stops there (was: whether a path passes it), so a hand order against the track never leaves a stop unserved.
- Stations past the skeleton's ends are placed with the skeleton tried both ways round (the old cost-only placement
  made LO-first clicks a different line).
- `legs::insert` returns at once for lines with no one-way station (the old one ran `best_slot` twice per station
  on every marker pass).
- Pairing within 50 m only (Anita), new T-3595 rule, idempotence and every-stop-served asserted in tests.

## T-3605 (agent onewayfix, 2026-11-17): no pairing for one-way stations

Her report: with both sides of a split station listed, unassigning side A left A a full dot and B none, and trains still stopped at both. Cause (Rust probe on master): the lone listed B was T-3348-paired with the unlisted A within 50 m, so the return run stopped at A (`line_back_stops` [.., A, ..]) and no half dot was drawn. Fix (tree `.tw-trees/onewayfix`): `way_group` is empty for a one-way station and no group holds one, so `leg_stop` is `leg_heading(s).is_some()`; `LEG_PAIR_M` gone. Test `t3605_side_by_side_stations_are_stops_of_their_own` (each side out, by map click and by drop_stop, both running sides); game: scratch `scen.mjs pair` (click A, B, A: dots and departures match).
