# T-3403: profit map on single track / flyover single splits (agent bugs2, 2026-11-16)

Cause: same blind spot as T-3422. Where a line's return run takes other track (one-way legs of a flyover, one-way single
track), `stretchMoney` placed all of the line's money (both directions) on the forward path's edges only, and an edge's
`lines` (clockClient `edgesOf`) come from the forward path, so the other leg had no line and showed "No trains run here".

Fix (app only): `ClockLine.back` is carried to `LineStats.back` (game/types.ts, workers/clockClient.ts); game/stretchMoney.ts
places run 1's riders' fares and half the running cost on the return path's stretches (`placedBack`), and counts the line
as using those edges for upkeep split and "bare" (`backLines`/`linesOf`). Lines with no separate way back are unchanged.
`edge.lines` itself is not changed (hovers, delete warnings keep their meaning). Typecheck passes; not looked at on the map
(needs a flyover with a running line; the old check t2411-profit-map.mjs was not rerun).
