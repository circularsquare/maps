# T-4195 reserve cores for every session
reserve_cores.ps1 -All: each pass one Get-CimInstance, walks every claude.exe, pins descendants to cores 2-15 below normal; same skip list and typing-path boost per session. -All -Loop takes mutex Local\trainworld_reserve_cores_all; a second copy prints a line and exits 0. One-shot passes (no -Loop) skip the mutex. Without -All behaves as before (-Root, own session).
Trial: one -All pass pinned 81 processes under 3 claude.exe; e.g. bash 12340 aff FFFF Normal -> FFFC BelowNormal. Mutex test: second copy exited at once.
Command: powershell -NoProfile -ExecutionPolicy Bypass -File trainworld/tools/ops/reserve_cores.ps1 -All -Loop 30 (background). Per-session -Root loops started by hand can be stopped (harmless alongside).
