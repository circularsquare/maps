# T-4111 The quad check after every network rebuild (agent quadcheck, 2026-11-23)

## What changed
- map/quadPairs.ts: new `QuadLookup`, the full pass's answer for one edge at a time. An edge's twin is the nearest segment off the 8 m spacing among the segments the full pass's grid would hold for its middle (same 3 x 3 cell window, same tie order); an edge with no twin of its own is the twin of the first edge, in order, whose own twin it is. The edge grid it asks (snapIndex `edgesNear`) is the one the network already carries over edits (T-1030). If that grid cannot answer (reach too wide, not built), it falls back to the full pass. `quadPairs` stays as the reference.
- map/quadTwin.ts: uses `QuadLookup`, cached per network and edge list as before.
- tramSpot (capacityMarkers.ts, TroubleList.tsx): no change. It already reads nearby nodes through a grid since T-4125 (f92fb27e, in this tree's base). Checked against the old every-node scan.
