# T-4169 edit bench: stop clicks measured, --compare reads only the runs it is given (agent editbench, 2026-11-24)

## Cause
- Stop clicks: the game does send an edit message. A map click on a stop in Edit stops posts op `toggleStop` (seen in the
  bench's own event log). The bench only accepted insertStop, dropStop, setStops, stopPassed, so it dropped the message.
  Fixed in tools/edit_bench.mjs (stopOps). No game code touched. A "no sample" note now lists the posts it did see.
- --compare: lines were keyed save|pass|action and picked by build hash, newest line each, across the shared ledger, so
  another agent's run of the same hash (or a partial run) could supply some rows. Every ledger line now has `run`
  (hash@yyyymmddhhmmss-pid); --compare and --show take a run id (printed at the run's end) or a hash (then the newest
  run of that hash, only that run's lines). Old lines without `run` group by hash, label and core mask.
