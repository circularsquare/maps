# T-4040 line panel names the kind's fare multiple

LineFare (app/src/ui/inspector/LineMoney.tsx) read only the line's own multiple (ownLineFare). It now also computes
the kind's multiple with lineFareMul (the function money, demand and the stretch/region sums use) on the fares with
`lines` cleared, so the panel cannot drift from the fare. When it is not 1 (high speed, ferry, bus, BRT) a small grey
"High speed 1.25x" sits before the stepper, hover "Rides on this line pay 1.25x" (kind times own). The stepper still
edits the line's own multiple. Checked in game (newark, local vs high-speed express): screenshot
artifacts/trainworld/review/faremult.png. Typecheck passes. No sim or money change, no smoke.

Strings: new lineMoney.fareKind, lineMoney.farePaid (en.json, context.json).
