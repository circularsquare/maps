# T-3474: partly built lines run their built stretch (agent partline, 2026-11-18)

Port of CinnamonVII's PR 21 on circularsquare/trainsworld (his PR 3 rebased with PR 12's fixes), written by
hand against today's code. The PR was the reference for behaviour. Credit him as co-author when it lands.

## What runs

`Network::line_stretch` (sim/src/track/net.rs). A rail line that `line_constructed` calls whole runs its whole
plan, so a fully built network is unchanged to the bit. Otherwise the line runs the longest stretch (by metres;
ties to more stops, then the earlier one) of consecutive stops that are constructed, joined by constructed track
whose return run (`back_run_of`, T-3348) is constructed too. An unbuilt station, a stop passed twice, or a gap
ends the stretch. A loop's arc is an open line, run both ways. No such stretch: the whole plan previews as before.

`service::build_line` builds the service over that stretch (`build_on`, `Served`) and keeps it in
`LineSvc::part`. If that service fails to build, the line previews its whole plan. Trains turn back at the
stretch's end stations by the usual rules: at a dead end (the unbuilt extension adds no built port) on the
platform's middle, else at the node. The test `a_partly_built_line_runs_as_a_line_planned_over_its_built_part`
checks this: same segs, stop_s, profiles, round trip, trains and cars as a line planned over the stretch alone.

Following the stretch: capacity `live_ports`, `spacing::seed_split` (`LineSvc::runs_on`), the upkeep share
(edges and stations), `line_cars_cap`, `back_lines` (`stretch_runs_once`), the demand snapshot
(`line_run_stops`), the state rows (`stops`/`path` served, `planStops`/`planPath`/`stopStart`/`pathStart`
when part). Staying with the plan: stop edits, `passed_stations`, Construct and its quote, removal effects,
the line tool's lines-on-edge, the line profile, `line_shift` (time zone of the plan's first stop; PR used the
stretch's, no visible difference).

## App

- `planStopsOf(l)` (game/types.ts) for every stop edit: lineActions, tools.ts, stopMarkers, remove.ts,
  LineInspector's lineDraft updates, GroupInspector's diagram (plan cells; turns and boardings mapped by
  `stopStart`).
- LineInspector while partly built: rows are the served stops; remove buttons, dragging, passed-station adds and
  dot clicks are off (PR's lockout: they index rows); the Construct button shows in a callout with no text.
- network.ts draws the whole plan, faded off the served part (`F_FADED`, blueprint where unbuilt), stretch -1
  there; turn-back crossovers at the served ends; train samples over the served strokes.
- trackHover: a faded stroke of a partly built line says "Not running yet" (existing string).
- platformLines / linesOnEdges / clockClient's edge lines use the plan path.
- checks/lib/reads.mjs `lines`: `stops` is the plan, `served` added where part.

  scratchpad partline/figures.mjs, cmp.mjs.

  A-B-C: 4/4/3 trains, round trip 747 s, 251,599 riders a day, no reversals or bare-end turns; plan keeps D. Map
  stop edit removing B gives plan A-C-D, served A-C; undo restores. Screenshot
  artifacts/trainworld/t3474-partline.png: built part solid, C-D faded. Hover on faded C-D says "Not running
  yet", on A-B the riders. Traffic view: C-D thin and faded. At C the train stands mid-platform (dead end).
  The panel's Construct button builds C-D; then all four stops run and list. No page errors.
- cargo test --release: 630 passed (9 stretch tests from the PR's block, adapted, plus the invariant one and an
  unbuilt-station one), then `a_partly_built_line_pays_upkeep_on_the_part_it_runs` (wasm/tests.rs): 4 km and 5
  stations charged to the line (1.4), the rest 1.6. cargo test --release --features demand --lib: 823 passed.
  Typecheck clean. Smoke on 6198: 29 passed.
- Station side: lists of lines at a station (`linesAt`, transfers) read the served stops, so a partly built line
  is not listed at its unbuilt-end stations while drawn through them faded. Chosen: they list lines whose
  trains call there.

## Follow-ups (not filed)

- The panel could keep its own stop edits for a partly built line by mapping rows to plan indexes (+stopStart).
- edgeRiders (track hover in Height/Speed views) drops the riders row on an edge only a faded part covers.
- Twins (T-3333): a partly built parent with the both-pairs switch may run its half of the trains while its
  twin (its own plan, its own stretch) runs none or a different part; untested.
