# T-1344: one-city data sources (umbrella)

Made 2026-10-26 (Anita: the Someday tasks "all seem real, just mostly specific, and don't need
cutting"; fold the one-city data-source tasks into one). Each item swaps a global or tier 0 input for
one city's official source. CLAUDE.md's rule holds: a one-city source is worth it only if very easy,
one for a minor city never is, so take an item when it is cheap or when that city is next tailored.
The folded ids are archived as "folded into T-1344"; their lines as they stood follow.

When to take one: the pack it changes has to be rebuilt for it to land. The Toronto items (T-282,
T-357) fit Canada's build (T-1239), the Seoul item (T-504) Korea's next rebuild, the Paris and London
items the Europe replan (T-1189; Paris and London are metros, so only if their packs are rebuilt
there). TASKS.md "Waits on a rebuild" lists the rebuilds.
