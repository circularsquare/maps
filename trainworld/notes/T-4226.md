# T-4226 line symbol in other languages

Cause: letterOf read the number only from English "Line N"/"Bus N". Fix: lineLetter.ts keeps a pattern made from the shown language's lineActions.defaultName message (i18n/index.ts setLanguage calls setDefaultNameMessage), so "Linie 7", "路線7", "7호선" give "7". Worker keeps English only (bus names are always English "Bus n" from the sim). Typed names unchanged ("Red" -> "R").

Checked: typecheck clean; in a nyc game, new lines in de gave Linie 1-3 = 1,2,3; ja 路線1 = 1; letterOf over all 13 languages' default names for n=1,2,3,12 gives the number; "Bus 4" -> 4. No standing check covers this. In-game strings: none changed.
