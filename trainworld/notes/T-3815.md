# T-3815 install the game as a phone app

Done in tree pwa (branch tw/pwa), not landed.

- `app/public/manifest.webmanifest`: name and short_name "trainsworld" (the page title; branding, not an in-game string),
  `start_url`/`scope`/`id` "./" so it works under /trainsworld/ and on 8800's own path, display standalone (keeps the
  system status bar and back gesture; fullscreen would hide them and the game's own UI sits under cutouts),
  background and theme #fbf7f0 (the pink theme's --bg, the default).
- Icons `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`: the favicon glyph on #fbf7f0; maskable keeps the glyph
  inside the central 60%. Made by a scratch script (Playwright screenshot of an SVG), not kept.
- `app/index.html`: manifest link, apple-touch-icon (192), theme-color, mobile-web-app-capable,
  apple-mobile-web-app-capable, apple-mobile-web-app-title, status bar style default.
- No service worker. Chrome 157 (headless, dev server) reports `Page.getInstallabilityErrors` = [] and no manifest
  errors without one; Chrome has not required a worker for Install since 108 (desktop) and the Android install
  works the same way. Not tested on a real phone. If a phone ever refuses, add a no-op worker with no fetch caching.
- deploy.py: `copy_site` copies every file in dist except packs/, index.html, build.json and the assets/fonts dirs, so the
  four new files go to the website's trainsworld/ unchanged; the /trainworld/ redirect pages are written separately and
  untouched. Not run (dry-run needs a build). GitHub Pages serves .webmanifest as application/manifest+json.
- Weak spot: the theme colour is fixed to the pink light theme; dark or blue/green themes show a cream splash/title bar.
- Check image: artifacts/trainworld/t3815-pwa.png (icon set; the manifest pickup was checked by CDP, not shown).
