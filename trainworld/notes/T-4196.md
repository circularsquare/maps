## How it ran

- Two Gemini calls (gemini_audit.py, Gemini 4 Neon medium), one per part, because the whole brief (36k chars) is over the
  Windows command-line limit (32,767) that `agy -p` is bound by. Each brief inlines her "User-facing text" section and
  trainworld/CLAUDE.md "Player text" in full; llm-isms.md (34k) was only pointed to by path.
- Briefs: artifacts/trainworld/gemini/T-4196-brief-changelog.md, T-4196-brief-strings.md.
- Raw output: artifacts/trainworld/gemini/T-4196-out-changelog.md (2 min), T-4196-out-strings.md (1.5 min). Both answered
  every item in order with the current text copied exactly.

## Things to know

- `changelog.py reword` sets the item's `edited` field, the same mark the board uses for her wording, so the 26 items
  reworded here now list as "(edited)" too. The original agent wording stays in `text`. Some of the 17 earlier
  "(edited)" items look like agent rewords too (c014 was edited 3 minutes after it was added, by agent periods), so
  "(edited)" doesn't reliably mean her wording.
- Docs quoting the old strings, left as they were (brief limited string edits to en.json): docs/ui-inspectors.md
  ("Make boarding only", "Saves one minute for transfers"), docs/ui-map.md ("Reversing here limits ..."),
  docs/ui-panels.md ("Its trips aren't calculated", "This game's trips aren't calculated"), docs/track-and-service.md
  ("A busway joins only other busways."). release-0.4.6.md playtest item 11 also quotes "Saves one minute for transfers".
- Translations of the 21 keys go stale by design until the next translation batch.
- reverseTip / reversalMarks / troubleList now say "turn around" and "Turning around here" instead of "reverse"; the
  context notes already describe these marks as a line turning around.
