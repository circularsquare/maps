# T-4023 Any number of single tracks, Add a track

## For you

- **Quad is 4 single tracks side by side**, each with its own direction, any count up to 16. Two doubles (ABAB) is
  one layout; ABBA or AABB is the same 4 tracks with two directions flipped. Old quad loads as two doubles.
- **Pairing is out of sight**: the game pairs each one-way track with a nearby opposite one (ABAB as 1-2, 3-4; AABB
  as 2-3, 1-4), only as the default track a line comes back on. Stops decide a line's tracks (the track chip).
- **Add a track** replaces Double up on the Select bar, plus a + on each side of the track picture. It runs opposite
  to its neighbour, so two clicks make a double into 4 tracks. A second click on any run picks one track.
- **Refusals** (drafts): "The curve is too tight for another track here.", "Other track is in the way.", "Water is
  in the way.", "A platform is in the way.", "16 tracks side by side is the most.", "A crossover stays a single
  track.", else yours, "Additional track cannot fit here." Several runs: "Added a track on {done} of {total} runs.
  {why}". Bridges, tunnels and ramps don't block it: the new track follows the run's levels.
- **Built work that changes** (track branch only, never shipped): the "4 tracks" button becomes Add a track (new
  stage T-4024); the one-double second click becomes one track (stage 3e).
- **Your call**: does an added track connect at the junctions at the run's ends (as Double up does today), or end
  loose until crossovers are built? I'd connect it, or no line can use it until Build crossovers, two releases on.
