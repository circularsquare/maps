# T-4547: moved trains kept through later edits (stage 5 of 18, T-4511)

Agent shift5, 2026-11-28, tree shift5 (the first shift5 run stopped at its spend limit with nothing in the tree, so this is all new). Sim only; nothing a player sees, no save
change, no strings, no changelog item. A game with no moves runs as before (every new path starts with "no stored moves").

## What is built
- **The key** (moves.rs): `Move.at` is now a time of day (local time) of the pattern's point for the departure, `departure + shift + lead` mod a day
  (`moves::key_of`). `secs` matches a departure to the move whose key is nearest round the clock, within half that departure's headway
  (nearer wins). So a move is "the 7:32" on every day, and a rate change, a reroute or a new stop leaves it on the departure nearest that time.
  Callers pass `lat.shift + lat.lead` (`keep_moved`, `run_deps_as`, retime's `stand lost`). `move_op` writes the key.
- **Stored and running moves** (service.rs): `Service.stored` is what the player made, `Service.moves` is what runs. `set_moves` sets both;
  `TrackWorld::clamp_moves` (start of `retime`) sets the running list: each stored move clamped to its train's room now (`Range::raw_lo/raw_hi`,
  zero always allowed), up to 3 passes since a train's room depends on its neighbours' running moves. Clamped away room comes back by itself.
  `Op::MoveTrain` and every inverse use the stored list.
- **Waiting moves**: a move no departure is within half a headway of runs nothing, stays stored, comes back with its train (`moves_waiting` counts them
  for "Reset N moved trains", stage 14). `move_dep(lat, move, day)` finds the departure a move takes on a reference weekday (`Service::ref_day`:
  after the last era).
- **Op::Nudge** (world.rs `shift_moves`): before the phases are set, each own/partner move whose departure is in a nudged slot of the line (and of its quad
  twins, whose phase follows the parent's) has its key moved by the phase change. The inverse is a batch with the exact old list, so undo is to the bit.
  Weekend sets (`weekend: true`) are not touched (T-4549).
- **Op::Line**: a line removed takes its moves (undo gives them back in the batch); a line whose stops are exactly reversed keeps each move in the other
  direction (run flipped, key unchanged).
- Held rows (`move_holds`) read stored moves through `move_dep`.

## Lies and limits
- A turned-round line keeps the key, so the move follows only if the new direction's departures are within half a headway of it (its `off` can put them
  elsewhere); else it waits and the next edit may bring it back.
- A nudge shifts keys by the raw phase change; a move whose departure no slot of the nudge matches stays (e.g. waiting ones).
- The clamp runs at `retime` (after each settle): an edit that shrinks a train's room shows the unclamped move until its settle; `MoveTrain` itself
  clamps through `move_op`.
- Eras hold the running (clamped) moves from before the edit; a loaded game has no moves yet (stage 8).
