# T-3765 Legacy time speed controls

Settings > Map: "Use legacy time speed controls", off by default. Stored in `display.legacyTime` (the browser's `trainworld-ui`, not the save). `Speed` in `ui/TopBar.tsx` renders the old buttons when on (pause, 1x, 4x, custom with text, double click opens the picker), else today's bar. Both read the same clock signals, so the speed carries over on a switch; comma and period still call `clock.stepSpeed` in both modes (in legacy the third button then shows the stepped speed, like a picker speed; nothing awkward).

Strings restored from 7180fe6b^ in all 12 languages: topBar.normalSpeed, topBar.speed, and the old double-click hover as new key topBar.speedPickLegacy (the live topBar.speedPick says "Click"). New: settingsTab.legacyTime (my translations, merged with l10n.mjs). Changelog c017 (listed as legacyspeed-1 in the tree).

Probe (play.mjs, Osaka): legacy 1x/4x/custom picker change the clock (rate 60, 240, 720); toggling back restores slower/speed/faster; legacyTime true survives a reload; no horizontal scroll at 390 px in either mode. Screenshots in artifacts/trainworld/t3765_*.png.
