# T-3776 graphics lost before the clock client exists

Cause: main.ts registered `onGraphicsGone(() => client.saveBeforeReload())` (and the DemandStopped, NewVersion,
FiguresStopped save callbacks) before `const client = new ClockClient()`. Fix: `earlyClient` (null until the client
is made) and one `saveGame` that skips the save when null; the four callbacks use it. No other early handler in
main.ts reaches `client` or another late const.

Probe (scratch, gfxcrash/probe.mjs): route-injects a 4 s await before the client is made, loses the map's WebGL2
context 1 s after it exists and refuses new ones. Old code: page error "Cannot access 'client' before initialization".
New code: graphics-gone screen, no page error. Late mode (loss after the game loads, saveBeforeReload spied): screen
shown, 1 save, no page error. `npm run check --prefix app` clean.
