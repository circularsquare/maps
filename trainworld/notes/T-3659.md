## PR 24 (caelum418): waiting room, car park and building layout

Ported by hand onto master's facility cache (T-3803 option 3), tree `pr24`. Same output as master everywhere it was
compared. Credit line for the landing commit:

    Co-Authored-By: caelum418 <150506911+caelum418@users.noreply.github.com>

### What changed

- `map/facilityPlace.ts`:
  - The near cells (`FacilityCache.near`) are 32 x 32 tiles of row masks, so marking a complex's square is a word per
    row and `isNear` (the edge pass's hottest line) is one map lookup and a bit.
  - A car park try's segments come from a stamp array (no Set per try); `segHitsRect` clips without making four
    arrays a call (the same arithmetic, so the same answers bit for bit).
  - A try stops scoring once it can no longer beat the best so far. The cells and box it would read are recorded
    first, so a kept complex still depends on everything it would have read.
  - Rooms, lots and station buildings are looked up in a grid (`map/shapeGrid.ts`, new) instead of scanned in full
    for every try and every room spot; the first building holding each complex is a map. Both grids are made each
    build, and kept and re-placed complexes both go in them.
- `map/buildingNet.ts`: one line. The edge loop's `{ id, p, ...e }` made a copy of every edge's box for every
  building; it now reads the box in place.

### What was not taken

- The PR's obstacle cache (keeping the segment grid when nothing moved): master's per-edge grid from T-3803 already does
  that, and finer.
- The PR's grids in `buildingsDrawn`: the one-line fix above, which sits inside the PR's change, is faster on its own
  for the pass with insides, and the grids cost more than they save with few buildings (one process, three arms,
  medians of 31, 2,647 save with synthetic buildings):

  | a build, insides kept | master | PR's grids | one-line fix |
  |---|---:|---:|---:|
  | 442 buildings: outlines pass | 9.8 ms | 1.7 ms | 10.6 ms |
  | 442 buildings: insides pass | 660 ms | 62 ms | 43 ms |
  | 5 buildings: outlines pass | 1.0 ms | 0.6 ms | 0.1 ms |
  | 5 buildings: insides pass | 19.5 ms | 33.9 ms | 5.0 ms |

  The PR's station grid alone would save about 8 ms a pass at 440 buildings and cost about 0.5 ms at our 4; left out
  for now, an easy follow-up if a big builder's save shows it.
- `checks/facility-layout.mjs` as a standing check: no bug behind it. Its cases ran in scratch against the port and
  master (24 cases, the same).
