# T-3851: Light view of another player's map

Agent viewonly, 2026-11-21, tree `tw/viewonly`. Her words in TASKS.md.

## What it does

Community's opened share has a **Calculate trips** tick beside View (only where View is), off by default and
remembered in this browser (`localStorage tw.community.viewTrips`). Off, View reloads the page with
`?load=file&trips=off`: `main.ts` starts no demand pool (`startDemand` is never called), `game/loading.ts` `tripsOff`
is set, and the load ends at the first full state after the clock worker's "loaded" (`networkInWithoutTrips`, called
from `clockClient.takeStateNow`): clock let go, `gameReady`, `startup` ready, so the card goes and the map draws. No
memory check on a light open (`openView(bytes, name, trips=false)` skips `saveRefusal`).

The top bar notice says "<name> isn't saved. Its trips aren't calculated." with Calculate trips and Save; after Save,
"This game's trips aren't calculated." with Calculate trips. Calculate trips (`community.calculateViewTrips` ->
`clockClient.calculateTrips`): a viewed game is written out (`exportForShare`) and opened again through `openView`
with trips, no "won't be saved" question, the memory check first, the share id put back in sessionStorage so the
map's heart stays; a saved game is saved and reopened by `?slot=`.

Places that waited on demand forever, now quiet with trips off: `ui/Spinner.tsx` `demandPending` (the line panel's
rings), `ui/StatusTag.tsx` ("Loading data..." with no figures; a selected city's loading), `game/lineFigures.ts`
`demandCapped` (the 4x clock cap), `map/demandLayers.ts` (striped "pending" trains), the train panel's riders say
"Not available" (reused) in place of "Calculating trips", and `ui/DemandSelector.tsx` `MapTopLeft` hides the demand
bubble row (None/Homes/Destinations/Total) and the station row (Origins/Transfers), which would show nothing. The
demand queries bound in `startDemand` stay unbound; in the light view, with Homes on from before, selecting a
station, a line and a clicked train, and a headway step (+15 s of play), gave no console error, no ring, no clock
cap and no status tag.

Files: `game/loading.ts`, `game/community.ts`, `workers/clockMoney.ts` + `clockState.ts` + `protocol.ts` + `clock.worker.ts` (frozen money), `workers/clockClient.ts` (`openView`, `calculateTrips`, `CHOICE_PARAMS`
gains `trips`, `GameChoice.noTrips`), `ui/StartMenu.tsx` (`choiceFromUrl`), `main.ts`, `ui/Community.tsx` +
`community.css`, `ui/TopBar.tsx` (`SaveNotice`), `ui/Spinner.tsx`, `ui/StatusTag.tsx`, `ui/DemandSelector.tsx`, `game/lineFigures.ts`,
`map/demandLayers.ts`, `ui/inspector/TrainInspector.tsx`, i18n en.json + context.json, `checks/t3257-view.mjs` (sets
the tick on, so it keeps testing the full View). No file under `app/src/workers/demand*` touched.
