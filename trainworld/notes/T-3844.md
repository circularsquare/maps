# T-3844 Paid edits that charged no region

Cause: `chargeShares` (regionMoney.ts) places an edit's cost by what changed in the world (new built edges, bus routes,
new stations, buildings). An edit that buys only trains, or upgrades a built station or piece, changes none of those,
and the `edited` answer carried a `line` only for edits that make a line. The charge stayed in the unassigned region.

Fix: the answer has `paid` (protocol.ts `PaidFor`: line, nodes, edges), made by `paidFor(op)` in clock.worker.ts.
`chargeShares(before, after, line, paid)` uses `paid.line` for the trains' split and, when the world shows no new
track, station or building, spreads the build charge over `paid.nodes` (station region) and `paid.edges` (midpoint
region), equal weight. `line` itself is untouched (it also means "a line was made" for newLineShape etc.).

Named: every op with a `line` (except copyLine); stationUpgrade, flying, stationTracks, stationWay, reverseStation,
stationProps, moveNode(s); edgeLevel, edgesLevel/Kind/Tracks, doubleUp, edgePis, rebuild (edges and stations).

Proof (nyc sandbox, two 3-station lines, line 1 stops [3,4] on 240 s headway, then the stop click), money panel regions'
summed ledger, trains/build:
- before: stop click (insertStop, charge 75): unassigned trains +75; waiting room on a built station (charge 5):
  unassigned build +5, nyc unchanged.
- after: stop click: nyc trains 150 -> 225, unassigned 0; waiting room: nyc build 8215.257 -> 8220.257, unassigned 0.
- setTrainCount 28 -> 40 trains (charge 425): nyc trains +425 (before the fix it had no line either).
- Undo of the stop click charges 0 and refunds nothing (cash and ledger unchanged), as before; station upgrades are
  final edits (clear the undo history), so there is no undo to test there.
Race seen in the "before" run only: a new line's first trains, made in the same batch, were booked to unassigned when
its run shares were not computed yet; not a regression.

Left (same gap, not fixed):
- undo/redo that pays trains (undoing a line removal): the answer has no line.
- game-wide edits that buy trains for many lines (`setPeriods`/`setHours` without a line, `weekendShareAll`).
- a line's trains when the line has no run shares yet (not running): falls back to the build split, empty.
- edits of other kinds that raise built value on a built piece with no named piece: none found.
