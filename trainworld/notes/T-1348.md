# T-1348: the load's first clock state

Done 2026-10-26 (agent t1348). Follows notes/T-1209.md.

## What changed

- **`workers/cityReach.ts`**: `atZero(f, lon, lat)`, whether `distanceTo` would be 0, from a grid
  over the footprint's bbox (side 2 * sqrt(edges), 16 to 512): a cell any edge's box (padded 1e-9 degrees)
  meets is an edge cell; every other cell is wholly in or out, settled row by row on first use by the
  crossings along the row's middle. A place in such a cell is more than 1e-9 degrees from every edge, so
  the cell's answer is the place's; in an edge cell, `atZeroExact` does `distanceTo`'s own arithmetic
  without measuring (inside by the even-odd walk, or exactly on an edge). `cellSays` gives the cell's
  answer alone (null in an edge cell).
- **`game/zones.ts`** `nearestZone` and **`map/coarseOutlines.ts`**' outline lookup (`cityWithin`):
  the first zone at distance 0 always won, so they look for it with `atZero` before measuring any
  distance; only a place no zone holds measures. `around` is `zonesTouching` at `ZONE_REACH_M`.
- **`game/cities.ts`** `zonesTouching`: each margin's widened boxes and their own degree grid, kept per
  margin; candidates from the query's cells, in registry order, tested against the widened boxes. Before,
  every query widened the box by the margin at 85 degrees (most of a region's zones) and called `widenBox`
  per candidate; `around` scanned every zone.
- **`map/coarseOutlines.ts`** `inOutline` (track zones, `zoneHolding`, `hiddenRealmAt`): `cellSays` on a
  footprint of the outline first; the bands of latitude only in an edge cell, now about four edges a band
  (the crossing test is the same whatever the band count).
- **`map/stationLabels.ts`**: whether anything a label is built from changed is a field-by-field compare
  against the last call's, not a joined string key.
- **`game/holidays.ts`** (rail countries) and **`game/trackZones.ts`** (each edge's crossed zones): kept
  per node or edge by comparing fields, not a string key built every state.

Not shared: realms and rail countries already shared `cityWithin`'s cache (T-1209); the region shares
place stops with `placeAt` on the fine boundaries, a different answer, so one pass for all three would
change figures. Each is now cheap instead.
