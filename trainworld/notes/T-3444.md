oh i would have thought we'd hold off on doing AA/BB quad trck until we discussed design fully. ok will type up my notes from the weekend now
but i think we should pause quad track work rn. sorry the below thoughts are disorganized and need more thought / discussion between us, whcih is why i dont really wanna work on this yet.

we do definitely need to preserve simpel stop assignment for simple 2track lines, for casual player ease.

to fix all the weird single/double track joining bugs we might want to rework our system to treat double track as a pair of single tracks in a lot of ways. in terms of how we save it we can potentially keep them joined but after they are drawn they should mostly juts be 2 single trcks in slightly different positions.

we wanna generalize so that people can have like any number of parallel tracks, and any number of platforms between them in weird station configurations. people want to be able to make grand central, with a bajillion tracks and platforms. people want to be able to make spanish solution. they want AABB and ABBA. they want AA above BB. they want triangular or tapering platforms. they want the ability to designate acutal tracks as passing tracks, and in general designate each track at a station to a line with a purpose (like passing track). etcetera. we dont have to support all of these at once but ideally the scheme we come up with shoudl be able to expand to cover all of these.

currently "platforms" are just like built off to the side of a line and they take up no space. i think we wanna maintain platforms that take up no space / can overlap, for ease. however people do want island platforms. so the way an island platform should work is like... if we insert an island platform we should blueprint a reconstruct that shifts the tracks out a bit (curvature determined by target max speed, or maybe even flyover maxspeed) and plops an island in between. perhaps this can give a slight transfer benefit for cross platform transfers but yea thats mostly flavor. 

we might need some sort of actual definition of what a "station" is, for display purposes and such... i think we could potentially just say like a platform is a station. like a platform is what you build when you plop down a station. but that is weird with side platforms (the default case)
another option is we could say parallel platforms that are built as one unit are one station, but then that doesnt include stations where the paltforms are offset longitudinally like in NYC, or multilevel stations like 125th St and Lex in NYC, which feels a bit weird. another option is we could just say mostly parallel platforms. another option is just that a station complex is a station...
not sure which of these makes sense.

also wen we rebuild exact stop ordering, we should make sure that we can specify exactly which platform the selected line should stop at. so i guess we should show a circle for every eligible track we could stop at, and people can pick one. also these circles should be drawn mostly non-overlapping, they can push each other aside if needed (ideally along their platform, so that they dont end up too far from their station/platform). we can also slightly tint the circles by track level/elevation so that overlapping circles are easy to distinguish. if a circle  is selected to be on the line we should show it as like a circle of the same size and position, but with the line color (it should look mostly like a modified version of the normal "this line stops here" in simple stop assignment mode) in the middle, and a number saying which number stop it is on that line, and the outer white part can be tinted by elevation as usual. 

sorry that veered off topic but yeah these are my thoughts
