Nothing comes near GitHub's 100 MB file limit or Pages' 1 GB. Not in the build and not needed:
noritetsu's real-network tiles are already on R2 (`data.anita.garden/noritetsu/`, CORS allows

OpenFreeMap's hosted Positron; the RTL plugin comes from unpkg. Water masks and walk grids are inside
the .bin packs. The packs grow as the China pipeline adds zones; the preflight reads whatever the
build copied.

## How the app finds its data

`app/src/game/dataBase.ts` gives `dataUrl(path)`: the `<meta name="tw-data">` URL when the page has
one, else `packs/` beside the page. Only the deployed index.html carries the meta (deploy.py writes
it), so 8800, the dev server and the Node checks behave as before. Every fetch of a pack file goes
through it: demandClient (packs, market packs, intercity), the clock worker's pack URL (from
clockClient), walks.ts, boundaries.ts, placeList.ts, coarseOutlines.ts, NewGame's real saves and
realSnap's graph folder for the routing worker. Why a meta and not a probe: DECISIONS.md, T-924.

## tools/deploy.py

- Preflight: the build's tree has no uncommitted trainworld changes; dist is newer than the commit;
  the build contains dataBase.ts; every registry zone has its five files; each header's arrays lie
  inside its .bin; intercity, outlines, the realgraph index and every .rgr it lists; file sizes
  against GitHub and Pages limits; no Jekyll-skipped names.
- The data: `rclone copy` of the raw half, then the JSON gzipped (mtime 0) into
  `artifacts/trainworld/publish/<version>/gz/` and copied with `Content-Encoding: gzip`. Every object
  `Cache-Control: public, max-age=31536000, immutable`. Refuses a version already on R2 unless
  `--resume`.
- The website: dist minus packs/ into `website/trainworld/` (old assets/ and fonts/ cleared first),
  index.html through religiondots' `web_wrap` (front matter `sitemap: false` and the analytics include)
  with the tw-data meta added.
- `--verify [--page]`: a .bin answers Range with 206 raw and CORS for anita.garden; a header is gzipped
  and immutable; the realgraph index is plain; with `--page`, the live page names this version and its
  entry script has a JavaScript type.
- `--stage DIR --data-base URL`: the website half into a scratch folder, for a local test.

## Commands for the real upload and push (after Anita's go)

From the maps root, after the orchestrator has committed T-924, rebuilt the 8800 snapshot and run
smoke on it (light and dark):

    venv\Scripts\python.exe trainworld\tools\deploy.py --dry-run --version 2026-10-22
    venv\Scripts\python.exe trainworld\tools\deploy.py --version 2026-10-22 --smoked

The upload is about 967 MB raw, about 700 MB with the JSON gzipped: perhaps 10-30 minutes. It ends
with `--verify` on the data. Then in the website repo:

    git -C ..\website add trainworld/
    git -C ..\website commit -m "anitabuilder"
    git -C ..\website push

and after Pages has built (a few minutes):

    venv\Scripts\python.exe trainworld\tools\deploy.py --verify --page --version 2026-10-22

Then open https://anita.garden/trainworld/ and play a minute. A later release: a new `--version`
(say `2026-10-25`); once its page is live, the old prefix can go:
`rclone purge r2:anitamaps/trainworld/<old> --s3-no-check-bucket`.

**T-547, GISCO NUTS.** The clause (ec.europa.eu/eurostat/web/gisco/geodata/statistical-units): "the
data will not be used for commercial purposes; the source will be acknowledged. A copyright notice
... must be visible on any printed or electronic publication", in the map legend and the introductory
page: "© EuroGeographics for the administrative boundaries". A free game is fine; both notices are in.
Ads, payment or sponsorship would need a EuroGeographics licence or the geoBoundaries fallback.
NUTS decides the grouping of every European zone; its polygons fill 9 outlines where OSM leaves a gap
(boe ceu het aan lis les obe osk pot). Those 9 put non-transferable geometry into files that ODbL
expects to be offered under ODbL: rebuilding their fill from geoBoundaries would clear it.

**Also.** Every pack still carries a `nocar` layer the game no longer reads, with about 15 more
sources, several with no stated licence (AIRIA, Senatran, China's public security ministry, NBS
Nigeria). Stripping it before a release drops them from the credits and some bytes.
