# T-4434: page garbage while trains run (agent framegarbage, 2026-11-27)

Tree `.tw-trees/framegarbage` from master 5bc9cf05b. Driver and profiles: the session scratchpad's `framegarbage/`
(`run.mjs`, `base1-*`, `new1-*`).

## Method

Chromium with the iPad settings (as notes/T-4370.md), dev server, real NYC save imported into a `?new=1` game, final
reached, clock running; the sampling heap profiler (garbage included) on every context for 60 s of the clock running
(no edit). One run each, same machine.

## What allocated (MB in 60 s, base)

| | MB |
|---|---|
| page | 1,457 |
| clock worker | 500 |

Page: `TrainGuard.update` 605 (+ its `push` 70, 22), `PlatformCrowds.update` 92, Lines tab rows (`stretchColour`/`rgb`/`rampColour`
via `crowdIn`) about 140, `runningToday` 20, i18n `formatToParts` about 45, `pulsesBetween` 18. Clock worker:
`moneyTiming.between` 131, `lagged` 41, `regionLines` and `runTail` (workers/clockMoney.ts, clockState.ts: another agent's, not touched).

V8 counts a double returned from a call that is not inlined as an allocation (JSC does not), so the `TrainGuard.update`
self figure (profileS, arriveS, push of doubles) reads high on Chromium; what is real in both is arrays, objects, Maps,
Sets, closures and strings, which is what was cut.

## Cut (display only)

- `game/palette.ts`: `rampColour` parsed both stops' hex into arrays, mapped, `toString(16)`, `padStart`, joined on each call.
  Stops are parsed once (`rampRgb`), the hex digits come from a table. `crowdRgb` gives the numbers without a string.
- `game/today.ts` `stretchColour`: summed through scratch numbers instead of a string and an array per stretch; same rounding
  (each stretch's colour is rounded to whole 0-255 first, as the string was). A NaN load now gives the ramp's end colour
  (was a garbage string).
- `map/platformCrowds.ts`: the building halls (objects and their Sets) are kept and emptied each update; the one-sided
  station's `c.set([...])` array is four assignments.
- `game/moneyTiming.ts` `between`: a loop in place of `PERIODS.findIndex` with a closure per period step.
- `map/trainGuard.ts`: the per-track sort's comparator is one function over module variables (a closure per track per frame).
