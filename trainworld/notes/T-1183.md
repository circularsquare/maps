## fixedrate agent, 2026-11-20 (worktree tw/fixedrate)

### Save finding (stops the Option removal)
Saves read and write the Option, so `LineData.trains` stays an Option for now:
- `save.rs` writes the flag (`trains.is_some()`), then the rates only when there are no counts.
- the reader takes flag 0 as `None`; `line_auto`/`line_tph` reads gate on `line_trains[i].is_some()`.
- `TrackWorld::allocate_unallocated` (world.rs) gives flag-0 lines whole trains after load. That is how a TWT4 save with rate-only lines still loads.
Not removed: the Option, the flag-0 read, `allocate_unallocated`, and capacity's `continuous` rounding (a line that has not been allocated yet runs it). Needs a decision on dropping old rate-only saves.

### Why the test conversion is not mechanical (tried 2026-11-20)
First try: made `tests::line(w, stops, tph)` build whole trains (rate x round trip, rounded). 36 sim tests failed (plus `demand::api::tram_tests::a_tram_carries_at_least_the_bus_it_replaces`, not through this helper, so probably tramerr's or a stale baseline: check on an unedited tree). Causes:
- A rate-only line has an exact rate; a counted line has a rate of trains x 3600 / round trip, so literal expectations (`8.0 * occ / 3600`, `[10.0, 6.0, 3.0]`, "5 an hour") need the settled `line_tph` as the expected value. Fixed this way in capacity tests.
- Counts come from the round trip when the line is made; adding a second line on the same track lengthens the first's round trip, so its rate drops. `set_rate` again after all lines exist.
- A line with 1 train on single track takes the lone-train allowance (`occ_at`), so "5 an hour on 2 km" became 2 trains.
- Counted lines in a world where several lines share track came out with a lower tph than counts x 3600 / round trip (seven_express: counts [27, 20], tph 10.25 and 4.7), so "the shared track is busy, rho > 0.8" cannot be had by asking for 20/h. Not understood; needs a look at how `TrainCounts` sets tph when no settle has run.
- `tiny_reversal_does_not_couple_independent_through_directions` asks for 0.001 trains an hour; one train on a 3 km line is about 5/h. The subject (a rare fractional-rate reversal) goes with the path; decide whether to drop or redesign.
- `a_frequency_line_is_given_trains_on_load` (tests.rs) tests the legacy flag-0 load and must keep a rate-only line.
- Other failures not examined: boarding (6), overtake, spacing `lines_on_shared_track_leave_apart`, tests.rs (a_circle..., a_line_reversing..., a_line_runs_with_times_and_fleet, junction_delay_matches_the_spec_example, merge_waits..., schedule_change_dirties..., station_links_save_and_load (bytes), sparse_and_reversing..., the_middle_of_a_long_line..., whole_line_counts... expects None after undo), timing (2).
