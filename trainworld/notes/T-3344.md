# T-3344: single ends at a node where a double is drawn later

Agent t3344, 2026-11-12. Status: Rust fix and tests done; browser check and ARCHIVE entry pending (gates).

## What the diagnosis missed
Two singles cannot end at one node from the same side by drawing: a node with one track end only lets the next
route leave away from that track, so the second single loops round to the double's side (checked in a test).
So "two opposite singles, then a double up to their node" is not reachable as described. What can happen:
- a single with a way set, then a double drawn on from its end: the single's join stayed 0 (no crossover drawn,
  the set way ignored on the map). Fixed.
- single, double, then a second single: already joined both correctly (`own` and `theirs` in `end_joins`); tested.
- a single with no way set, then a double: join stays 0 on purpose (T-3171, a double off a single end is two-way).

## Fix
`end_joins` (draw.rs) now also runs when the route is double and the node has no double yet, and
`ends_before_double` gives each single end on the far side with a set way the join that carries that way
(`join_for`, as `set_edge_oneway` does). Tests (lanes_tests.rs, `t3344_*`): one-way single then double, both
hands, both ways; lone unset single stays unjoined; single, double, second single joins both tracks.

## Second single refused (5174140f)
Reproduced, but not a join problem. With a double at a node whose axis is slanted (the first single came in at
an angle, the double was drawn tangent to it), a second single to a close target on the other side must also
leave tangent to that axis and gets `RadiusTooSmall(1)` (e.g. single from (2900,-40) into the node, double east,
second single to (2950,50): refused; with the double first, on a straight axis, it passes). 6x6 target grid on
both hands: only these slanted-axis, short-stub cases fail. Fixing it means letting a route leave a node of two
ends within a cone between the ends' headings instead of exactly along the node axis (`lead_in`/`nearer_dir`
in draw.rs), which changes every junction's geometry: a design call, about 4-6 h, P3. Not done.
