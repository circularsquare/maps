# T-1617 globe slits: not reproduced (2026-10-28)

Anita: "on globe mode there are sometimes like vertical darkened slit areas where it looks like
they're getting darkened twice." No code changed; no cause found in headless Chrome.

## Tried (port 6153, headless Chrome with ANGLE d3d11), all clean

- Full map, globe, light and dark, zoom 0-6, longitudes all round incl. 180, lat -80 to 80,
  pitch 30/60 with bearing, 1920x1080 at 2x pixel ratio, Terrain (hillshade) on and off.
- Only the shades drawn (`tw-realms-inactive`, `tw-city-outside`, `tw-zone-loading` over white):
  every pixel is one of exactly two colours, shaded or not, never a third darker one. Done for a new
  New York game, the real save, and a game with 14 realms shown (China, Europe, Canada, Japan,
  India, Brazil...). Also captured 60 ms after each jump, to catch transients.
- `tw-city-outside` alone at 50% black: no doubled seams (geojson-vt's wrap buffer is clipped).
- Hillshade alone, 150 ms after each jump: no long straight vertical edges (column-step detector).
- The real save's realm-shade triangles (1,120, read from the layer) rasterised on a 2000x2000
  world grid: no point covered twice.
- Mouse-wheel zoom-out and drag of the real save on the globe, shots mid-motion: nothing.
