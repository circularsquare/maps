# T-101: map text and clutter

Done 2026-10-10, Anita's screenshot feedback: too many station names, inconsistent fonts on
map text, and redundant commuter summary in the top left corner.

- Hide all station names below zoom 12, including the invisible shadow symbol layer, so names
  that are not drawn cannot suppress basemap place labels at regional scale.
- Above zoom 12, retain transfer/line/constructed priorities but inflate collision rectangles.
  Names need a 48 px horizontal or 28 px vertical gap before zoom 14, then 20 px / 12 px at
  closer views. T-074's pan translation and padded viewport still operate; labels return when
  zooming back in and the Station names display switch remains available.
- MapLibre's container font was Helvetica, inherited by station labels, tool tips and other
  DOM text. `#map` and its controls now explicitly use the project `--font` (Zen Maru Gothic),
  and inputs/selects/textareas inherit the UI font too. Existing glyph tiles already use it for
  the basemap. The debug-only timing panel keeps its deliberate monospace font.
- Remove the commuter legend component, its mounting point, CSS and unused signal. Commuter
  bubbles, modes, hover, selection, settings and inspector remain; city shares are in the top bar.
