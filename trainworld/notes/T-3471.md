# T-3471 intercity tests skip when the packs are missing

Agent icskip, 2026-11-17, tree `.tw-trees/icskip` (branch tw/icskip), not landed.

## Cause

Confirmed: missing packs. With `data/` replaced by an empty folder in the icskip tree only (the junction to the main
tree's data was removed and put back; main's data untouched), `cargo test --release --features demand --lib` gave
792 passed, 8 failed. The 8, all in `sim/src/demand/intercity/tests.rs`, each read `data/packs/{tyo,gnm[,osa]}.market.json`
through `real_world()` and unwrap or assert on an empty world:

- a_streamed_pass_is_the_pass_to_the_bit
- the_window_keeps_every_trip
- a_window_keeps_its_pairs_trips
- fare_factors_weigh_trips_by_their_origin
- the_explorer_counts_commutes_as_the_selection
- sampled_pairs_keep_each_zones_trips_with_each_place
- far_chunk_pairs_keep_each_place_pairs_trips
- sampled_selection_rail_stays_within_trips

Plain `cargo test --release` with no packs already passed (609).

## Change

One helper, `have_packs(root, ids)`, beside `real_world()` in the same file. A test starts with
`if !have_packs(root, &["tyo", "gnm"]) { return; }`. The helper prints one line:
`skipping: data/packs/tyo.market.json is missing (packs are not in the open-source copy)`.

Also guarded: `eachway_with_its_curves_is_eachway`, the ninth test that builds from the same packs. It did not fail
without packs because it asserts on an empty world, so it passed without testing anything.

## Results

| | packs absent | packs present |
|---|---|---|
| `--features demand --lib` | 800 passed, 0 failed | 800 passed, 0 failed |
| `cargo test --release` | 609 passed, 0 failed | 609 passed, 0 failed |

Master with packs: 800 passed (same count; no tests added or removed). Without the change and without packs: 792 + 8 failed.
