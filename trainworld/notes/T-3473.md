# T-3473: PR 12's demand CPU speedups, measured (2026-11-17, agent prspeed)

CinnamonVII's PR 12 (circularsquare/trainsworld, closed), commits 98a47717 (baseline optimizations), 9a9eb33a (4-lane
row split), 86503c56 (gravity interleave and threads), 4c83118e (debug_assert guard). Scripts and per-run JSON:
`scratchpad/prspeed/` (`prtime.mjs` drives one load: the save imported into `?new=1&paused=1`, load to final,
then the busiest line's trains +1 on every level and undo, each to its final; figures and the worker log's
`periodMs` each time).

## What landed

- **Gravity** (`sim/src/demand/kernel/gravity.rs`): the Furness row and column passes four rows at a time
  (each sum in its own order), the one-region fast path, and `gravity_threads(.., threads)` splitting the passes
  over a thread count the caller passes (native only; `gravity` is `gravity_threads(.., 1)`). `pack_gravity
  --threads N`, default 1, so nothing takes cores it has not claimed.
- **mode.rs**: only the PR's `debug_assert!(!rule || n_all <= till_w)` (it fired in debug builds with the walk rule off).
- **Left out**: the mode choice changes (band-major `eg_e`, hoisted buffers, `Logit`, F4/F8 helpers, pads sharing
  one dummy) and the 4-lane row split. Neither was faster, natively or in the browser (tables below), so they are
  code with nothing to show for it. The 4-lane drift itself is invisible.

## Figures

- Order-keeping parts: calib output identical to master in every field (stations, lines, operators, areas, periods).
- 4-lane split: natively six commute figures (the walking total per period and the day's) moved by about 2e-9 of
  their value; in the browser the mode split's walk and drive moved in the 11th digit (2.340731357821833% to
  2.340731357860941%). Rail trips, every line's riders and loads, stations and points identical. Invisible, but
  it bought nothing, so it stays out.
- Landed build: NYC and all-China loads and both edits identical to master in rail trips, trips, mode split,
  every line's riders, boardings and loads (hashed), stations, intercity and points.
