acknowledgement, or the save can outrun it (seen once on the reverted code).

## Plan for stages 2-4

**Stage 2: one write-block answer (T-2843 machine C), takes in T-3698 and finding 4.** In `workers/clock.worker.ts`
add `writeBlock(): null | "noLease" | "otherTab" | "otherDevice" | "newer" | "testPage" | "storage" | "switching"
| "failed"` from `activeLease`, `leaseTaken`, `cloudTaken`, `newer`, `testPage`, `storageReady`, `saveFailure`,
`switching`, `viewing`. Then, in this order: `writableNow` becomes `writeBlock() === null`; `publishSlots`'s
`reason` chain maps the block to its message; `autosave`'s guard uses it; `flushBeforeSwitch` refuses only when
`edited` (a player change) is blocked, not `dirty` (fixes finding 4: a second tab with the clock running can leave).
`saveByHand`: a write refused because another tab wrote the slot takes it back as the no-lease branch does
(`keepOtherTabs`, then write) or says "saved in another tab"; which one is the stage 2 agent's call (taking back
loses nothing, since `keepOtherTabs` moves the other tab's change to a slot of its own). Checks: the T-3698 line
becomes a PASS; add a finding-4 case to `t3734-two-tabs.mjs` (tab B read-only, clock running, Save and quit reaches
the start menu); all three t3734 checks and `t1826-saves` pass. About 1-1.5 h.

**Stage 3: every message about a game carries one stamp.** A load counter taken when the worker starts a game
(`loadGame` / `intoNewSlot` / `intoView` / restart), sent on `loaded`, `state`, `money`, `saveSlots`; the page's
edits carry the stamp they were made under. `protocol.ts` gets the field; `clockClient.arrive` keeps the current
stamp; only a different game drops a message. It replaces `MoneyState.slot` (account.ts `sendScores` and
`gameForShare` compare the money's stamp with the slot list's, coordinate with whoever holds account.ts then) and the
stop clicks' `gamesLoaded` capture in `map/tools.ts`. Count the message kinds that carry game state first (not done
here). Checks: `t3734-load-gap` and `t3734-stops-out` pass unchanged. About 1.5-2 h.
