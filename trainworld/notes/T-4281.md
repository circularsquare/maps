What a later click waits behind, from the code: the worker takes a click only between tasks. After an edit the
follow-up's boarding steps go a task each, then the first block (rows and samples, unbroken), then the network a piece
a task, then its post with the trips (unbroken). An edit arriving between pieces goes ahead (`goesAhead`,
`standAside`) and the follow-up begins again after it; any query but the delete question's (`today`,
`blueprintQuote`, `lineCost` and the like) and `epoch` run what is left of it whole first (clock.worker.ts
`processMessage`). T-4267's run saw such blocks of 371-2,595 ms ahead of later clicks; since T-4272 the money
messages pass and riders wait, so the queries are what is left. Not separated in this run: no instrumented page run
(budget).

## What changed

- Rust (service.rs): `note_moved` also records, per moved run, where it moved (`Span`): from the first entry unlike
  the old run's (or on an edge the edit touched) to the start of the alike end, whose entries moved along by the run's
  length change alone (to 1e-6 m); the length changes add up as `drift`. Several rebuilds before a take make one span
  over all (the earlier one widened by the later drift), none known (a global pass, a bus or ferry line, a line that
  stops being ok) makes the run whole. Taken with `take_moved`, put back with `moved` after a trial.
- Rust (wasm): `take_moved_spans` (`[line, run, lo, hi, drift, len]` each), `run_polyline_range` and
  `run_bends_range` (`bends::bends_in`), which give the whole run's numbers bit for bit there.
- Worker (clockMain.ts `forget`, `spliceRun0`): a moved line's run 0 with kept samples is sampled again only from one
  sample before its span to one after it, its bends for every interval with a sample sampled again, the rest kept; it is
  named in `touched.paths` only where they differ (T-4280's rule). Whole as before when nothing is kept, no span is
  known, the count of samples changed, its summed drift would pass 5 cm (`DRIFT_MAX_M`), or under `?patch=walk`.
  `?patch=check`'s sample check compares a drifted line within its drift (ground m) and its bends not at all.
- Test: changed_tests.rs `a_station_on_a_lines_track_moves_its_runs_only_around_it` (a station on a curved line's
  track, then two before one take: spans for both runs, the stations inside, samples outside within the drift of a
  whole resample, bends outside alike; the ranged calls equal the whole run's slices bit for bit).
