# T-4005 Bookmark community saves

Anita (11-21): "maybe add bookmark feature to community saves to save cool ones".

## What it does
- A bookmark button (icon, filled when on) on each Community card and on an opened network; a Bookmarked tab
  beside Most liked. Bookmarked has no place picker, search or shuffle.
- Browser: `tw.community.bookmarks` in localStorage (newest first, try/catch). Works signed out.
- Account: shonei-server commit 04369d6 adds `PUT/DELETE /trainworld/community/<id>/bookmark` and
  `list?view=bookmarked` (auth, newest first, no paging; cap 500 an account; test in
  trainworld_community_bookmark_test.go). Stored as `BookmarkedBy` on the share, like likes, so a deleted share
  or account takes its bookmarks. Docs: docs/trainworld-api.md (edited in the shonei-server tree, NOT committed:
  the file already held another agent's uncommitted changes).
- Client (game/community.ts): signed in, the first time an account is seen it merges (browser's pushed up, the
  account's pulled in); after that the account's list is the list on each load. A bookmark made signed out clears
  the "merged" mark so the next sign-in merges again. An older server (404 `not found` on the PUT, 400 on the
  view) sets a flag for the page; bookmarks stay in the browser and the next page load tries again.
- Gone/hidden: the Bookmarked list fetches each card of the page; a 404 drops the id from the list and storage
  (dropped, not shown as gone; the server keeps a hidden share's mark, so it returns for the account after the
  next merge only if the share is back and the account is the source).
- Needs a server deploy for the account side; the client is fine against today's live server.

## Strings (en)
- community.bookmarked: Bookmarked (tab)
- community.bookmark: Bookmark (hover and label)
- community.unbookmark: Remove bookmark (hover and label once on)
- community.noBookmarks: No bookmarks yet
