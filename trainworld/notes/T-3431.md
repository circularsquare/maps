# T-3431 Seattle to Victoria ferry (bug-b, 2026-11-16)

Not a small fix. The study in notes/T-3435.md measured it: Seattle - Victoria, built on its own with default
service, carries 0 riders. Seattle and Victoria sit on two landmasses with no car or plane link under 250 km, and
the regional market never offers such pairs to the player's network ("fixed, never solved"; `solvable` needs
`has_alt`). The "no route" the player sees in the trip explorer is the same: a pair that is never solved has no
route row. Fix is T-2216 (ground-only solve with rail as the only ground mode between landmasses), an intercity
task in its own worktree, and T-3435 (Fast ferry) after it. Nothing in the ferry line itself looks broken; I did not
build the line in a browser, the 0 comes from T-3435's runs and the code path.
