Display only. memBudget, deviceGB, budgetKnown and demand worker logic untouched (memA owns those).

## What changed

- ui/SettingsTab.tsx MemoryRow: cap shows "x GB / 8 GB+", unknown shows only "x GB" (and never turns red, since there is no total), known as before. Three hovers.

- Shots: artifacts/trainworld/t3494_{before,after}_dm{8,4,none}.png (Chrome headless, deviceMemory faked to 4 and undefined).

## Why the figure jumps (not changed)
- liveGB = 1.15 + 1.76 x (sum over workers of WASM memory + allocator live bytes) / 1024. WASM linear memory never shrinks, so
  it steps up to the peak of the busiest solve. It only comes down when an idle worker restarts (quiet 20 s, at least 384 MB and
  15% over its need, demandClient overNeed/memCheck): the figure then drops by a step, later than the player's action.
- Opening or closing zones changes live heap (x1.76) at once; solving raises WASM in steps of the allocator.
- The 'heap' number is wasm_heap_bytes (Rust allocator live bytes, inside the linear memory), so WASM + heap counts live data twice;
  T-3329's fit absorbed it into the 1.76 slope. Dropping it would need a refit on its raw runs: not done. The T-3329 note calls it "JS heap", which is wrong.
- The reading updates only when a worker posts a message (ready, opened, closed, done), polled every 2 s; the clock worker, main thread
  and GPU are the fixed 1.15 GB.
- Pool size changes (memA) change the figure in whole workers (about 0.5-1 GB each).
- Shrinking the pool splices the per-worker records, so removed workers are not counted. No stale counting found.
- performance.memory (Chrome only) is the calling thread's JS heap, rounded; it misses the workers and WASM, which are the growing part.
  measureUserAgentSpecificMemory needs cross-origin isolation (the game has none) and undercounts WASM. Not used.
- 3.5/8 GB yet slow: demand solving is CPU bound; memory is not the limit. 11/8 GB yet fine: the budget is the game's rule, not a limit
  (T-3329 error about 0.2 GB, and the browser pages memory out). Hence the hover.
- Dropped from the old hover: "About 0.6 GB more per 1,000 stations" (kept only on the saved-game cards).
