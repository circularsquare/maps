# T-4607: a city served only by buses counts as built

Her call 11-28: "yes city served by only buses (or any mode of transport) should count as built".

Cause: game/worldTotals.ts builtCities read only world.save.stations; bus stops live in stopsById / busStopsById (game/world.ts), not in save.stations. Everything that asks "is this city built" goes through it, so a bus-only city was missing from the Cities tab, the city panel's Built state and Stations row, the top bar totals and the All cities view.

Fix: one rule, builtCitiesOf(w) in game/worldTotals.ts (builtCities() is it on the current world). A city is built if any built station or any built bus stop (busStopsById: bus, tram-as-bus, ferry stops as the world holds them) lies in its zone. The value is the number of built stations, so a bus-only city shows 0 stations (no string changes; the Stations column counts stations).

Readers now on the one rule:
- Cities tab, city panel (CityInspector, CityDetails), top bar (TopBar, worldTotals), intercityView: through builtCities.
- achievements.ts demandFiguresOf: its own station loop replaced by builtCitiesOf(w.w), so the trips figure and the Cities tab's All cities row agree.
- ui/inspector/AllCitiesView.tsx lines count: looks stops up with stopsById, so a bus line counts.
- game/realms.ts followStations: built realms also take built bus stops.

Not changed, listed:
- game/places.ts nearestStation / stationNameNear: display names of stations, left.
- CityDetails CityNetwork station rows: station list only (a bus stop is no station row).
- achievements "cities served" (T-4049) counts by the zone's transit trips, already any line kind.
- shared save previews: sharedSave.ts holds the sender's own city list (cities: arr(str)), no built rule. Unchanged.
- shonei-server: trainworld_achievements.go only names the tier ids ("cities:10"); the score and tiers arrive from the client; the savecheck and previews hold no city-built rule. Nothing to change in the server.

Strings changed: none. Changelog c042 (tree item): "a city served only by buses, trams or ferries now counts as built" (area track).
Docs: ui-panels.md (top bar and Cities tab), zones.md (realm shown). DECISIONS Map and UI entry added in the main tree.
