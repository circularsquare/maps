# T-4254 — Port PR #31: keep a bus route's trunk stretches when it is edited

- **Source:** `xoaninc`'s PR #31 on `circularsquare/trainsworld` (`artifacts/trainworld/gemini/prs-2026-11-25/pr31.diff`, `pr31.json`), fixing open-source issue #28.
- **What was ported:** Applied the single hunk to `trainworld/app/src/map/busDraw.ts` inside `BusDraw.begin()` (verbatim — no deviations from the PR; the target lines matched master).
  - Previously, `begin()` rebuilt each saved road leg from `routeLL` and `kinds` reading only `K_CORNER` and `K_ROAD`, leaving `Leg.fast` unset. Because only legs adjacent to moved corners are re-searched during an edit, saving the edit wrote `kinds` back without `K_TRUNK` on every untouched leg, silently slowing those stretches down to city-street speed.
  - Now, `begin()` reconstructs `fast` for each saved road leg (`Array.from({ length: i - from }, (_, j) => !!((kinds[from + 1 + j] ?? 0) & K_TRUNK))`) and attaches it to the leg when `fast.some(Boolean)`.
- **Code verification:**
  - Indexing matches `BusDraw.build()` (`leg.fast?.[k / 2 - 1]` written to `kinds[from + k / 2]` for `k = 2, 4, ..., 2 * (i - from)`).
  - `reversedLeg()` already reverses `leg.fast`, so loop-back routes (`begin` folding + `build` unfolding) and `loopBack` with `head === true` preserve per-segment trunk flags.
  - Undo/redo (`snap()`) shallow-copies `legs` and legs are replaced immutably on drag/insert/delete.
  - Pre-T-2904 saves without `K_TRUNK` have `fast.some(Boolean) === false`, so `fast` is omitted as before.
