# T-4329, T-4331 (linestab)

Closed groups: game/groupsClosed.ts keeps them in localStorage `trainworld-closed-groups`, per save slot key (a viewed network and a ?new=1 game keep nothing), reloaded when the slot or game stamp changes. Not in the save: that would touch the worker files buytrains has. A new game in the same slot reuses group numbers, so a stale closed number can close a new group.
Double click on the arrow: the click with detail 2 does nothing, so the first click's toggle stands and the dblclick sets every group in the tree to that group's state (closed closes all, open opens all). No flicker.
Profit %: MoneyText.profitPercentRow, used by lineMoneyTip (Lines tab, line and bus panels) and Cities moneyTip (also the city panels). Fares / (running + upkeep), whole percent; the row is left out when costs are 0. The group row's hover is unchanged. The Cities hover was not seen in the game (no ledger at day 1); same function as the line hover, which was.
