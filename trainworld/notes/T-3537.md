## T-3537: street snap merged a double's split

Cause: the tram street route's request (`tools.ts` `streetReq`) never carried `RouteAsk.join`, so the track model got no join
point at either end and `end_joins` took neither track (both merged into the single). The hover's dot was right because
`joinPoint` runs on the pointer whatever the snap; only the request dropped it. Rail on roads and the real snap already
passed `joinReq`. Fix: the street request passes `joinReq(at)` too, start and end. Checked at zoom 15 with the pointer 5 px
off the centre line: a single off each track, the second from the no-longer-loose end, each ending on the far double's
matching track; one turning at the first corner; a click at a loose end's centre still merges.

## T-3538: turn-back mark at the split line's far end

Reproduced on edit-built track (double, two one-way singles 500 m apart, double): an open line run both ways cannot stop on
a leg 500 m from its pair (`NoWayBack`; the per-direction stop rule's walk is 300 m), and an open line over the pair has no
reversal at all. The mark comes from a loop: the line closed on its first stop (right click on an end) runs out on one leg
and back on the other, a balloon whose first stop's turn is the loop's closing (never marked) and whose far end is a
"reversal partway" (marked). Her line's actual state is not confirmed; this is the only state found that marks the SW end
and not the NE end.

Rule (display only, `partwayReversals` in `game/turnedLine.ts`): a balloon with exactly one stop reversal and no bare-end
turn has two ends; the map mark, the stop list's turn icon and the lap's "Reversing partway" row leave it out (it counts as
turning at the end). `LineStats.reversals` is unchanged for dwell maths and stop edits.

## T-3541: extending the turning end breaks the line

Her save (Downloads/trainsworld-caracas-copy-day-31.save, copied to artifacts/trainworld/t3541-caracas.save for the check).
Line 2 is an **open** line, stops Avenida Este 18, Avenida Arismendi, Calle Loyola, Pasaje Calzadilla I, Avenida Este 12,
El Silencio, `loop: null`, `reversals: [1]`. Avenida Este 18 is on one leg of the one-way pair and Calzadilla I on the
other (too far apart to pair, 300 m), so stop insertion made a J: trams start on a leg, run to Arismendi, turn back there
(a real reversal partway, which is her T-3538 mark; the T-3538 rule covers only closed loops, so her mark stays), then run
north up the other leg. Its return run, routed through the stops reversed, can only turn at stops or bare track ends, so it
laps: El Silencio, Este 12, Este 18, Loyola, Arismendi, out to the loose end 24 m past it and back, Arismendi, Loyola,
Calzadilla I, Este 12, El Silencio, the loose end past it and back, and round again. 5.3 km, 13 min out, round trip 66 min,
trains 3/2/1.

Cause of the break: that return run turned at the loose end past Arismendi (node 144). A node with any second edge end is no
track end (`bare_end` counted blueprint), so with the blueprint drawn on the run turned at the blueprint's far end instead,
over unbuilt track: the line went from running to planned. Deleting the blueprint put the turn back.

Fix (sim): `Network::bare_end` also takes a node with one constructed edge end and only blueprint beyond; `find_path_side`
turns back there the way the train came (charged only on that exit), and `reach_from` lets it. Once the extension is built
the node is no track end: `World::way_reroutes` now also routes again, in the same edit, a line the edit broke whose path
turned back at a touched node that is no longer a track end, through its same stops and never with more turns back (her
return run is derived on every edit and needs no reroute; a stored path, as the Rust test's, does). Built, her return run
goes out to the extension's far end and back without stopping.

Not fixed, a design call: what a line over a one-way pair should be when its leg stations are more than 300 m apart. Options:
pair the legs' stations further apart (the per-direction rule's walk), let a stop be served one way only (each run skips the
other leg's station), or keep the stop insertion from making the J (refuse, or put the leg station where the line passes it).
