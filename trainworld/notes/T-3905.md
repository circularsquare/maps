# T-3905 station names cut at a slash in the schematic

Cause: diagram/names.ts `pickName` ended with `best.split("/")[0]`, added in T-2162 with the first names pass (imported
names like "A/B" were meant to show the first part only). The map labels (map/stationLabels.ts) and panels use
`complexTitle` whole, so the schematic alone differed.

Fix: `pickName` keeps the whole name. `splitName` (the two-line wrap, used by the screen and `picture()` from the same
plan text) breaks at a "/" when the name has one (slash stays on line 1), else as before. Nothing else cut names.

Checked: real NYC save, "Whitehall St-South Ferry/South Ferry" shows whole in the schematic
(artifacts/trainworld/T-3905/after.png). No before shot taken (the old code showed "Whitehall St-South Ferry").
Changelog: slashname-1.
