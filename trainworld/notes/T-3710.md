# T-3710: count hover reads wrong for one vehicle

Found in T-3703 (notes/T-3703.md): `schedule.roundTip` read "1 bus on the line keep the headway ..." because the
verb did not follow the count.

## Change

`schedule.roundTip` is now an ICU plural on a new `count` value (the vehicle count; `schedule.tsx`, both call sites:
the weekday and the weekend cells). The repo's convention for counts is ICU plurals (docs/localization.md), so no new key.

- en: `{count, plural, one {{vehicles} on the line keeps the headway over its round trip of {trip}} other {{vehicles} on the line keep ...}}`
- de: one "hält", other "halten" (was "halten" for all).
- pt: one "mantém", other "mantêm" (was "mantêm" for all).
- ca, es, fr, id, ja, ko, ru, tr, zh-Hans, zh-TW: wording unchanged (no verb that agrees with the vehicle count, or the verb is
  singular after a numeral); wrapped in the same plural with identical text in each category the language has
  (the check requires `{count}` as a plural in every translation, and warns on a missing `one` / ru `few`, `many`).
- `sources/<lang>.json` updated to the new English for all 12, so none is marked stale (their meaning is unchanged).
- `context.json` note names `count`.

## Checked

- Game (New York sandbox, rail line, Headway mode, high demand stepped to one train): hover reads
  "1 train on the line keeps the headway over its round trip of 13m24s"; screenshot
  artifacts/trainworld/t3710-round-tip-one.png.
- Message formatting for bus and train, counts 1, 2, 5, 21, in all 13 languages (scratch script): en "1 bus ... keeps",
  "2 buses ... keep"; de "1 Bus ... hält", "2 Busse ... halten"; pt "1 ônibus ... mantém", "2 ônibus ... mantêm".
- `checks/i18n.mjs` clean, `npm run check` passes.
