# T-3634 Several pieces of track in one track panel

A player's request through Anita's pad (2026-11-18): "add view for multiple track selection, like single track view.
so that you can shift click to add to track selection and then rebuild just like you can rebuild a selected single
track section".

## What landed (agent multitrack, worktree tw/multitrack, uncommitted)

- `game/trackSet.ts`: the set is the selection, `{ kind: "tracks"; edges }` (types.ts). `shiftTrack(edge)` adds or
  takes out a built, non-crossover piece when the selection is such a piece or a set; a set of one becomes the plain
  `track` selection, of none null. An effect drops pieces that are gone after an edit.
- `main.ts`: `selectAt` with Shift tries `shiftTrackAt` first, hit-testing track directly (`topSeg` on `n.track`), so
  a piece with a line on it is added rather than the line picked. A `mousedown` listener cancels MapLibre's box zoom
  for a Shift press on track while built track is selected: the box zoom's mouseup calls `suppressClick`, which ate
  every Shift+click with the select tool unless the commuter bubbles' own box had turned it off. Shift+drag off track
  still zooms.
- `ui/inspector/TrackInspector.tsx` `TracksInspector`: title "N pieces of track", sub (length, kind if shared, level
  or range), `PieceRebuild` for all, Cost to construct and Upkeep summed, lines on any piece. No Remove (follow-up).
- `ui/inspector/PieceRebuild.tsx` takes `edges`. One piece keeps T-3408's probing (levels and family only where the
  piece alone can go); a set offers every level and type as the bar does, with own values null when mixed. The quote
  is published to `panelQuote` (game/rebuild.ts) and `map/blueprintBox.ts` draws its red refused pieces and ramps
  beyond, as for the bar; this also applies to one piece's panel now (before, one piece's quote drew nothing).
- Strings (en.json, context.json): `trackInspector.pieces`, `trackInspector.shiftAddTip`, `trackInspector.shiftSetTip`.
- Docs: ui-building.md "Several pieces in the track inspector"; SPEC clause; wiki levels-and-tunnels (read/ rebuilt);
  code-map line; DECISIONS line (main tree).

## Undo

rebuild is final (Anita, 2026-11-10; t3408 asserts undo is cleared after it), so the set's is final too: one
question, one charge, undo cleared.
