# v0.3.3 changelog draft

Anita's edits 2026-11-12 applied (her wording, typos fixed). v0.3.1 and v0.3.2 were hotfixes off v0.3, so v0.3.3
carries everything landed on master since v0.3 (3a442a6e). Held out: two pairs on quad (behind ?pairs), T-3346 stage
2. 350 km/h dropped (she keeps 320).

## Her list

- one way stations! for single track or double track lines
- single track for high speed and tram (if it lands)
- timetables!
- follow a train as it moves
- different line bullet shapes
- left-hand train running! applied globally per save
- S-Bahn and light rail and some other rail cases added to real-world network
- drag a bus route to reroute
- can slow game speed down to real time
- show estimated memory use per save
- attach up to 4 screenshots to feedback (needs the server deploy)
- new zones! filling in gaps in Spain, Portugal, France, Romania...
- added north korea!
- universities, airports, and long trips handle cross-city trips better
- resort towns / long distance attractions get higher traffic
- schematic improvements: more room drawn in city centers, better ocean drawing, cities keep real orientation
- stations within a station complex share a name by default

## Dropped by her
single track on quad / beside passing stations; turn single into double; flags; CJK browsers' currency; money
rates x100.

- zoom buttons

- terrain drawn as squares again
