(`save::convert_frame`), which drops settled rates, so every real-network start is a full settle from the
saved trains. A save written today would not help for that reason (London's fresh save converted:
110 s natively).

**Repeat skip** (branch tw/lonslow, `sim/src/track/world.rs`): a settle round depends only on the rates,
round trips and swing state it starts from, so when that state equals one 1-4 rounds back, the settle
runs only the rounds that leave it where the 80-round cap would, then stops (the swing counter now stops
at `SWING_TURNS`, the only value read). Output byte-identical for the seven cities; both test suites
pass. It catches exact repeats only; London's drifting period-3 group still runs to the cap (a 1e-6
tolerance caught it too, 78 s, with two lines' rates off by under 0.001%, not kept).
