## Where the lag is (2026-10-26)

Measured with a copy of `checks/t1020-click-latency.mjs` (scratch: CPU throttling by CDP, clicks 150 ms
after the last move so the next segment's moves start while the click is worked on, the ghost's
latency in the 700 ms after each click) on the real save, track tool at Staten Island.

| Build | Throttle | Click to drawn p50 | Ghost p50 / p90 / max | Clock worker per edit |
|---|---|---|---|---|
| 8800 (40593370) | 1x | 180 ms | 28 / 37 / 607 ms | 160 ms (buffers 67, boarding hour 54, state 16) |
| 8800 | 6x | 548-916 ms | 80-242 / 470-929 / 1.6-2.6 s | 264-319 ms |
| 1e57b60e (before the round) | 1x | 422 ms, 2 of 8 placed | 4.7 s p50 | 154 ms; edits stuck behind T-1283's 80-round loop |

The round did not slow placing; 40593370 is faster than the build before it. The machine was at
100% CPU from other agents during most runs, so 6x figures swing by 2x between runs of one build.

After a click the ghost stalls 0.2-0.6 s at 1x, and that is what Anita feels:
1. The clock worker works the edit (about 160 ms at 1x: stroke buffers 67, the boarding hour 54);
   the previews asked meanwhile wait behind it. Filed as T-1407 (clock worker, after T-1028/T-1029).
2. The new network has no snap or pick grids until they are built in idle time, so the first moves
   scan all 108k segments (snap, and the hover's pick). T-1030 (done 2026-10-26, not on 8800 yet)
   carries the grids over an edit.

Not the cause: the terrain tint (a "terrain" message once per zone, never per state; the tint redraws
on moveend only; and Terrain was off for Anita), `map/moving.ts` (camera moves only), T-1209/T-1348's
caches (not on this path).

With the grids built, a pointer move costs the main thread about 3 ms (synthetic moves timed
synchronously, 1x). Trimmed anyway: the track tool's placer read the map container's size and the
hover read its rect on every move, each laying the page out again after the move's writes (now the
overlay's size and a rect kept until a resize or scroll); with a build tool on, the hover no longer
looks for a train under the pointer (a pass over every train). Effect within the run-to-run noise.
