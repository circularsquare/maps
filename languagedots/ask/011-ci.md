# Name the 18% of Ivorians on national-only languages by modelling them into regions?

status: closed
country: ci
summary: Tableau 4.20 names 13 languages by region; 82 more (3.85M, 18%; two thirds of Bafing and Hambol) are national-only and drawn as Niger-Congo unnamed. A model could place them by region; that changes counts, so yours.

## The decision I already took

Côte d'Ivoire is drawn from RGPH 2021 Tableau 4.20 (ANStat thematic report, tome 1), which
gives the Ivorian language each Ivorian speaks most by région for 13 languages only (Baoulé,
Dioula, Senoufo, Malinké, Agni, Dan, Bété, Attié, Lobi, Gouro, Abbey, Koulango, Guéré). Its
"Ensemble des autres langues nationales parlées", 3,850,778 people or 18.1%, is drawn on
`nigercongo`, washed out as "language not named". That is most people in Hambol (67%), Bafing
(67%), Worodougou (50%) and Grands-Ponts (46%). Annex 20 names all 82 labels inside it
nationally (Mahou 260,034, Tagbana 261,418, Abron 269,660, Koyaka 274,612, Dida 235,373, Wobé
197,477, Djimini 192,723 ...) but not by région, so nothing is guessed out of it.

This is ask 009 (Indonesia) again, with a weaker cross-table. The same volume has Ivorians by
région x 5 ethnic macro-groups (annex 25: Akan, Krou, Mandé du Nord, Gur, Mandé du Sud) and
language x macro-group nationally (annex 27). Sharing each région's remainder by those would put
every "other" Kru language (Dida, Wobé, Kroumen, Godié...) in the same proportions in every Kru
région, which is wrong in a way anyone from there would see. Indonesia's 31 groups mostly were
languages; these 5 are families. A better seed would be where each language is spoken (its
Glottolog point, CC BY), fitted so each région's remainder and each language's national count
both come out exact; that is a second kind of proxy (a reference location, not a census table).

## What reversing it would cost

About two hours: parse annex 27 (already downloaded), place 80 languages (Glottolog points, a few
by hand), fit, new tree nodes for perhaps 60 leaves, rescatter. The 13 measured languages would
not change; the new rows would be `tier="modelled"` and `note_public` would say so.

## What I need from Anita

One of: keep it unnamed (as now); share it by the census's own ethnic cross-table only (the 009
rule, but coarse here); or share it with Glottolog locations as the seed, fitted to the census's
région remainders and national counts (my preference, if any). `sources/ci.md` §"The remainder"
has the numbers.
