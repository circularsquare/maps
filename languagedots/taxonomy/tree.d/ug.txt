#   the survey's card names it apart (Kenya's Bajuni precedent). Tagwenda, Songora and Nyara
#   have no Glottolog entry; each is a name the survey's respondents gave for their own speech,
#   so each gets a Bantu leaf rather than a guess at the neighbour it is closest to.
#   Nilotic: Lango lang1324, Alur alur1250 (Jonam jona1239 a dialect), Adhola adho1243, Kumam

#   of Acoli; the survey names it apart, so it is a sibling of Acholi.
#   Central Sudanic: Lugbara lugb1240, Aringa arin1244, Ndo ndoo1242 (Okebu), Lendu lend1245,
#   Mvuba mvub1239. Ma'di stays on au.txt's `nilosaharan.madi`.
#   Chope (Jopalwo, Dhopaluo) has no Glottolog entry; a Southern Luo variety, a Nilotic leaf.
#   Kuliak: Ik ikkk1242 ("vulnerable" in Glottolog's endangerment field). Glottolog has Kuliak
#   as its own family; it sits under Nilo-Saharan as most readers know it (spec §3, asks
#   001-003). Soo sooo1256 ("moribund") and Nyang'i nyan1313 ("nearly extinct") get no node:
#   the Tepeth, Nyangia and Napore are drawn on Karamojong, which they speak (sources/ug.md).
#   Nubi nubi1253: Glottolog files it under Afro-Asiatic (an Arabic-based creole); under Arabic.
#
# Colours. Every Ugandan node is hand-picked off its parent's generated grid (chroma 0.05-0.10 or
