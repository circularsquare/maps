# Solomon Islands, 2019 census (taxonomy/sb2019.py): first language learnt as a child. The report
# names Pidgin and 58 local languages (Tables 9.6.1-9.6.3); everything else is one remainder on
# `other` (sb2019.py says why).
#
# Middle levels, checked against Glottolog (data/raw/glottolog, classification paths):
#   * Northwest Solomonic (Glottolog: Oceanic > Western Oceanic > Meso Melanesian > ... >
#     Northwest Solomonic): Choiseul, New Georgia, Santa Isabel, the Shortlands (Mono-Alu).
#     Dororo and Guliguli have no Glottolog classification (extinct, unclassified); the report
#     calls them variants of Kazukuru, which Glottolog puts in New Georgia, so they go here too.
#   * Southeast Solomonic (Glottolog's own node): Gela, Guadalcanal, Malaita, Makira, Ulawa.
#   * Temotu (Glottolog's own node): Reefs-Santa Cruz, Utupua and Vanikoro languages.
#   * The Polynesian outliers (Rennell-Bellona, Anuta, Sikaiana, Tauma) sit directly under
#     Oceanic, as Samoan, Tongan and the other Polynesian languages already do on this map.
#   * Bilua, Touo and Lavukaleve: the Central Solomons languages, non-Austronesian. Glottolog
#     leaves each one unclassified (an isolate); the usual reading (Ethnologue, Wikipedia,
#     Terrill's work) is a small Central Solomons family, and readers know them as Papuan, so
#     they go under the existing `papuan` root as `papuan.central_solomons` (the brief's
#     "families as most readers know them").
# Colours: Northwest Solomonic blue-violet and Southeast Solomonic cyan-teal either side of
# Oceanic's 225, so Isabel and Gela, which face each other across a strait, differ by family as
# well as by language; Temotu greener; the Central Solomons languages yellow-green, apart from
# the Oceanic blues around them in Western Province.
