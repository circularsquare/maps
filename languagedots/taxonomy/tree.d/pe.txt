# Peru, Censo 2017, mother tongue (taxonomy/pe2017.py). Families from Glottolog
# (data/raw/glottolog): Chicham (Awajun, Wampis, Achuar), Cahuapanan (Shawi, Shiwilu), Harakmbut,
# Zaparoan (Arabela) and Tacanan (Ese Eja) are new roots. Glottolog puts Tacanan inside
# Pano-Tacanan; br.txt already has Panoan as a root of its own, so Tacanan gets one too, the
# split most readers know. Kandozi-Chapra and Urarina are Glottolog isolates; Tikuna joins br.txt's
# isolate.tikuna. Where the census names a language another fragment already has (Cashinahua =
# Kaxinawa, Yaminahua = Yaminawa, Matses, Kukama kukamiria = Kokama, Murui-Muinani = Witoto,
# Ocaina, Yagua) the mapping reuses that node; nodes other fragments define are repeated here only
# as parents, with the identical label and no colour.
#
# Colours, for contrast on the ground: Spanish (red-orange) against Quechua across the Andes is
# the map's main edge, and Quechua was a salmon only slightly lighter than Spanish; its colour is
# raised to a light peach in br.txt, which defines it (see sources/pe.md). Aymara stays lavender.
# Chicham is violet, apart from the isolates' pinks it borders in Loreto (Kandozi, Urarina,
# hand-picked away from Achuar). Cahuapanan is lime beside Chicham and Kichwa's amber. Shipibo
# is a teal set off from Ashaninka's olive; the Campa languages (Matsigenka, Nomatsigenga,
# Kakinte) and Yine and Yanesha step through the Arawakan greens around Ashaninka.
