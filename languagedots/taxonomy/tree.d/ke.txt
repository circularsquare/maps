# Bantu. Dholuo luok1236, Turkana turk1308, Teso teso1249, Samburu samb1315, Maasai, Pokoot
# poko1263, Sabaot saba1262, Okiek okie1245 and the Kalenjin subgroup kale1246: Nilotic
# (Nilo-Saharan as most readers know it). Somali soma1255, Borana-Arsi-Guji Oromo bora1271,
# Orma orma1241, Garre garr1259, Rendille rend1243: Lowland East Cushitic.
#
# Luhya, Kalenjin and Mijikenda are leaves although Glottolog files each as a subgroup: the
# survey's card offers the cluster as one answer, and a group node would draw a named answer
# washed out. Pokot, Sabaot and Okiek are Kalenjin languages but sit beside Kalenjin, not
# under it, for the same reason. Sheng, Nairobi's Swahili-based urban vernacular, has no
# Glottolog entry; it sits under Bantu beside Swahili.
#
# Colours, for neighbours on the Kenyan ground. Every Kenyan node is hand-picked off its
# parent's generated grid (chroma 0.04-0.10 or 0.18-0.20, or lightness outside 0.55-0.82), so
# no generated sibling elsewhere moves; Gikuyu and Kamba are pinned to the colours they had
# before this fragment (diffed against a build without ke.txt: nothing outside Kenya moved).
# Central: Gikuyu orange, Meru vivid red, Embu pale pink, Kamba yellow. West: Luhya red-orange,
# Kalenjin violet, Luo blue (existing), Gusii gold, Kuria dark red, Teso pale periwinkle, Sabaot
# grey lilac. Coast: Mijikenda crimson, Swahili orange (existing), Taita brown, Pokomo pink,
# Bajuni olive. North: Turkana cyan, Pokot lilac, Samburu deep blue, Rendille pale mint, Orma
# teal, Garre dark green beside Somali's lime.
