# Guatemala, Censo 2018 (taxonomy/gt2018.py): the language each person learned to speak in. INE
# prints 22 Mayan languages, Xinka, Garifuna, Spanish, English, sign, other. Every one gets a node.
# Mayan subgroups as mx.txt has them (Kaufman's; `mayan.kichean` there already holds Q'eqchi', so it
# is read as Greater K'iche'an and takes Uspanteko and the Poqom pair too). Checked against
# Glottolog (data/raw/glottolog): Achi achi1256, Ch'orti' chor1273 (Cholan), Itza' itza1241 and
# Mopan mopa1243 (Yucatecan), Poqomam poqo1253 and Poqomchi' poqo1254 (Poqom), Sakapulteko
# saca1238, Sipakapense sipa1247, Tz'utujil tzut1248, Uspanteko uspa1245, Garifuna gari1256
# (Arawakan). Glottolog has no Chalchiteko: it files the speech of Aguacatan's eastern half under
# Awakateko, but INE prints it as a language (recognised in 2003), so it is its own node beside
# Awakateko under Mamean. Xinka is a small family to Glottolog (xinc1237, four varieties, all but
# extinct); INE prints one "Xinka" and most readers know it as one language, so it sits under the
# shared `isolate` root, as mx.txt does with Huave and P'urhepecha.
#
# Colours, for neighbours on the ground (sources/gt.md): the Mayan blues, cyans and violets, the
# big neighbours pulled apart by lightness as well as hue. K'iche' mid blue; Q'eqchi' light cyan;
# Mam violet; Kaqchikel pale sky; Tz'utujil dark teal at Atitlan between those two; Achi dark
# blue-teal against Q'eqchi' and Kaqchikel; Poqomchi' indigo against Q'eqchi'; Ixil pale lilac;
# Q'anjob'al light teal against Mam and Chuj's lavender; in Aguacatan, Awakateko dark blue and
# Chalchiteko teal-green (the generator gave Chalchiteko and Mopan the Mayan root's own colour). Mexico (mx.txt) uses these nodes bare
# for its few speakers, mostly Chiapas; Mam stays away from Tsotsil's 272.
