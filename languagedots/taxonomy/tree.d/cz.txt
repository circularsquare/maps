#   Moravian: Glottolog has Czecho-Moravian (czec1259) and Lach (lach1246) as dialects of Czech
#     (czec1258). It is a sibling of Czech under West Slavic here, not a child, because a child
#     would turn Czech into a group, drawn washed out (pl.txt's Lemko, the same reasoning).
#   Montenegrin: Glottolog's Montenegrin Standard (mont1282) is a dialect under South Slavic's
#     Serbian-Croatian-Bosnian; a leaf beside Serbian, Croatian, Bosnian and Serbo-Croatian.
#
# Colours. Czech is the colour of the whole country, so it is hand-picked here instead of
# generated (a generated colour moves with the set of siblings in the build: it was a dark teal
# one build and a yellow-green, next to Ukrainian and Silesian, the next). A mid teal: apart from
# Polish's green (the Polish minority of Třinec and Karviná lives among Czech speakers), Slovak's
# cyan and German's blue. Moravian lives among Czech speakers all over Moravia, so it is a pale
# mint, the same corner of the wheel but far lighter.
