# Azerbaijan, 2019 census mother tongue (taxonomy/az2019.py). Checked against Glottolog
# (data/raw/glottolog/languages.csv):
#   Nakh-Daghestanian (nakh1245) is a new root. Lezgic (lezg1248) holds Lezgian (lezg1247),
#   Tsakhur (tsak1249), Udi (udii1243), Kryts (Kryz, kryt1240) and Budukh (budu1248); Haput
#   (hapu1234, "Haput-Ismaili") is a dialect of Kryts in Glottolog, but the census counts Haputs as
#   a nationality of their own and their own language as theirs, so it is a sibling of Kryts, not a
#   child (a child would turn Kryts into a group, drawn as "language not named"). Avar (avar1256)
#   sits under the conventional Avar-Andic branch; Khinalug (khin1240) is a branch of its own.
#   Talysh (North-Central Talysh, taly1247) and Tat (Muslim Tat, musl1236) are Iranian.
#   Ingilo (ingi1240) is a Georgian dialect in Glottolog; the census prints the Ingiloys' own
#   language apart from Georgian, so it is a sibling of Georgian under Kartvelian.
#   "Jewish": the census's own-language column for Jews names no language (Juhuri, Hebrew and
#   Yiddish are all possible), so it is a named leaf under `other` (as Ethiopia's unclassifiable
#   labels are), not guessed into one of them.
#
# Colours: the north (Gusar, Guba, Gakh, Zagatala, Balakan) is where these languages meet on the
# ground: Lezgian beside Azerbaijani (Turkic red) and Tat; Avar and Tsakhur beside Georgian and
# Ingilo (Kartvelian violet). Nakh-Daghestanian takes the blue-cyan band nothing else uses here;
# Lezgian, Avar and Tsakhur are hand-picked apart inside it. Talysh (the south, Lankaran, Lerik,
# Astara) is a saturated sand so it does not read as Azerbaijani's red or Russian's green.
