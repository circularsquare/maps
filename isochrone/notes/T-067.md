# T-067: the page reads the land danger band

Design: docs/hazard.md 4. Scripts used for the figures below were one-off (scratchpad); the
standing checks are `checks/smoke.mjs` (the Sahara survival hover) and `notes/T-042/trips.mjs`.

## What changed

- `js/tiles.js`: `loadHazardWorld` (L10), `loadHazardWindow` (L3, L1 tiles through the shared
  cache, missing tiles 0; an L0.1 window cuts an L1 window and takes the L1 pixel under each cell).
- `js/levels.js`: `HZ_RATE` (code to rate) and `setHazard`, which keeps `L.hq` = rate x hours per
  km, per cell, 0 on water.
- `js/session.js`: the L10 band loads once (started at `init`, awaited by the first click, both
  modes). `js/windows.js`: each window loads its band beside its speeds.
- `js/search.js`: land moves add dh = length x f x mean of hq over the cells the move averages;
  getting in or out adds 0.25 h x the land cell's rate (hq / inv) plus the land part of the step.
  A walking start runs the general search; `solveWalk` stays for hazard off.
- `index.html`: survival in the hover from 0.5% risk; a danger paragraph with its sources in the
  info panel; "Danger" dropped from the "not counted" line.
