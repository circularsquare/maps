# T-022 working notes: the search with layers

2026-10-26. The design is docs/canoe.md 5 and 7; code in `js/search.js`, `js/canoe.js`,
`js/canoedata.js` (code-map). Bench scripts were in the agent's scratchpad (`bench.mjs`,
`prof.mjs`, `simple.mjs`, `bigwin.mjs`, `check_split.mjs`); what they did is described here.

## Checks

- **Walking unchanged**: the new search against the old one (git HEAD's `js/search.js`) on the
  L10 grid from Cluj, Lisbon, Jakarta, Nairobi: 0 cells differ. Windows use the same seed
  arithmetic.
- **Hazard path**: with `cfg.hazard` on (separate time and hazard arrays) and every rate 0, walking
  and canoe times equal the shared-array path on every node.
- **Predecessor codes**: 2,000 random reached nodes per run (walking, canoe from Cluj) all trace
  back to the start through `pred`, through transfers and river steps.
- Real data (T-020, T-021), L10, from Cluj: Black Sea off Constanta 19.6 days, Vienna 22.2,
  Lisbon 87.5; from Lisbon, off Brest 29.3 days; from Jakarta, Surabaya 15.1 days.

## Speed (node 22, same V8 as Chrome)

The machine was shared with other jobs, so each figure was taken beside a fixed reference:
`simple.mjs`, T-005's bench rebuilt (one node a cell, 16 moves, no currents or rivers). When it
ran 230 / 431 / 352 ms (Cluj / Lisbon / Jakarta; T-005 had 231 / 518 / 500), the canoe search on
real data took:

| Start | 16 moves at sea | 8 moves past 20 km | headless Chrome, 8 moves |
|---|---|---|---|
| Cluj | 0.95 s | 0.84 s | 0.76-0.80 s |
| Lisbon | 1.05-1.11 s | 0.81 s | 0.83-0.93 s |
| Jakarta | 1.00-1.06 s | 0.77 s | 0.72-0.81 s |

Work per click (real data, 16 moves): ~1.0-1.1 M nodes settled, 7.8-9.3 M edges tried (Lisbon:
sea 5.6 M, land 2.6 M, get in 0.4 M, get out 0.6 M, rivers 0.1 M), ~20% more than T-005's
estimate; the per-edge cost is ~2x the simple bench's (more tables read per edge, the current,
links, transfers). Tried and kept: the walking loop apart, the heap keys beside the entries, a
4-ary heap, one packed word per cell, relax inlined, time sharing the weight array while
hazard is off. Tried and dropped: a heap with no index (stale entries; no gain).
