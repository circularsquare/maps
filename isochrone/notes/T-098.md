# T-098: land hazard band rebuilt on T-011's L1

`data/hazard/` (2026-11-06 02:39) was built before T-011's tiles (22:43), so its L3 and L10 rates
were weighted by the old L1 speeds (docs/hazard.md 4). Rebuilt 2026-11-07 (318 s, one core, peak
5.1 GB), into `data/hazard_next/`, compared, swapped in by renames, old band deleted:

    HAZARD_OUT=hazard_next python isochrone/tools/hazard/build.py tiles

No land pixel lacked a distance, so T-011 did not change the land and `dist` did not need a rerun.
