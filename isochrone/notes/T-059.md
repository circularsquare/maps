# T-059 Globe

MapLibre GL JS 4.7.1 to 5.24.0 (the last 5.x, 2026-04-23; 6.x was at 6.16.0 and not tried),
`map.setProjection({ type: 'globe' })` on `style.load`.

## How the time layers draw on the globe

Read from the 5.24.0 source (`maplibre-gl-dev.js`): `drawRaster` draws an `ImageSource` (and so a
`CanvasSource`) with `drawTiles(..., source.tileCoords, ...)` on `projection.getMeshFromTileID`,
the same subdivided tile mesh raster tiles use. The raster vertex shader places each mesh vertex
at `mix(corners, a_pos / 8192)` in tile space and samples the texture at `a_pos / 8192`, so the
canvas stays linear in Mercator within its tile and the globe projects every mesh vertex onto the
sphere. The Mercator-y canvases from `js/paint.js` need no change; holes and corridor cuts are in
degrees, so they still line up. Poles are not drawn for image sources (`allowPoles` false), which
does not matter with the canvas at 85N-60S.

The internals `upload()` relies on (`src.tiles`, `src._playing`, `play()`) are the same in 5.24.0.

## Breaking changes that touched the page

- 5.0's list: `map.on` returns a Subscription (no chains here), `geometry-type` and Multi
  (no filters on it here), WebGL options moved (none set). None needed a change in the page.
- `GeoJSONSource._data` is now `{ geojson }`; smoke.mjs read `_data.features`, now the public
  `await getData()`.

## View handling

Globe `getBounds()` samples eight screen points (off-planet ones snap to the rim) and, when a pole
is on screen, returns every longitude and lat 90. MapLibre keeps the centre within ±85.05, so at
zoom 5+ a pole never shows; the full-longitude case only happens below zoom 5, where no windows are
solved. A tilted view reaches far: `viewBox()` clamps each side to 1.5x an untilted view's half
size at the centre (`360 / (512 * 2^zoom)` degrees of longitude a pixel, times cos(lat) for
latitude, true on both projections since the globe's zoom keeps Mercator's scale at the centre).
The river lines pick tiles from the same box.

## Hover and click

Off the globe `unproject` gives the nearest rim point; `onPlanet()` projects it back and drops the
hover or click when it lands more than 2 px away. Checked: no tip and no solve off the globe at
zoom 1.5; a hover near Cluj at zoom 1.5 gives a time; a corridor hover at zoom 3.2 gives
"walked, 4.0 km/h" (`lineAt` uses `map.project`, which is right on the globe for the front side).
