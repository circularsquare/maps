# T-092: the canoe's `cfg.access` on the T-011 walking tiles

2026-11-06. Outcome: **kept at 0.5**. Coarse canoe times did move against L1 (L1/L10 0.95 -> 1.04
over all 25 starts), but the move is walking's own (0.91 -> 1.02, T-011); the canoe's part on top of
walking is centred at 1.00 with 0.5 and got more accurate, not less. A larger figure only buys a
small headline gain by offsetting walking's +2%, and trades forest for lakes.

## How

T-088's measurement (`notes/T-088/measure.mjs canoe`: T-080's 25 starts, destinations 20-300 km on
L1 land, hazard on, L10 the world and L3 and L1 a box round the start, each solved from the start
alone), on a copy of its harness that reads T-011's direction planes the way the page does
(`notes/T-092/lib.mjs`: `setDirs` on L10 and on each box, `TILES=pre_t011` for the old walking
tiles, `ACC=` for the knob). Run from `notes/T-092/`, about a minute a run on one core:

    TILES=pre_t011 TAG=pre05 OUT=<scratch>/ node measure.mjs canoe
    ACC=0.75 TAG=now075 OUT=<scratch>/ node measure.mjs canoe
    TAG=now OUT=<scratch>/ node measure.mjs walk
    OUT=<scratch>/ node cmp.mjs canoe pre05 now05 ...      (medians per kind and start)
    OUT=<scratch>/ node excess.mjs now now05 ...           (canoe L1/L10 over walking L1/L10)

`pre05` gives T-088's built column to the hundredth at every start (all 0.95 (0.74-1.17), mean abs
ln 0.153), so the harness is the same measurement.

Why 0.5 stays:

- Past walking, every figure from 0.5 to 1.0 is equally good (0.124-0.125, median 1.00). The raw
